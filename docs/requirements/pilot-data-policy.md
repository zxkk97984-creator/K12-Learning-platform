# 试用数据与 AI 记忆控制政策（试点）

> 日期：2026-09-07。任务 T24（先文档 S，再实现 M，依赖：T06、T09）。

## 目的与范围

本文件记录平台在**学生/第三方试用阶段**收集、使用、保留与删除各类数据的目的、可见范围、保留期负责人，以及删除/遗忘的实际效果。目标是对外试用前能讲清楚"收集什么、为什么、能看到什么、怎么退出"。

**本计划不对法律合规下结论**，也不默认新增身份证、人脸等敏感数据。目标年龄、监护与知情流程由试点负责人确定。

## 数据分类与要点

| 数据 | 收集目的 | 可见范围 | 保留期/负责人 | 删除/遗忘实际效果 |
|---|---|---|---|---|
| 账号资料（昵称/年级/语言/学习目标） | 个性化讲解与学段适配 | 仅本人 + 教学系统 | **由负责人决定**；不自行编造天数 | 删除账号后资料不可用于新上下文 |
| 阅读进度（BookProgress/学习会话） | 续读、统计学习时长 | 仅本人 | 由负责人决定 | 删除后不再出现在续读/首页；历史统计口径不变（诚实标注） |
| 学习事件（Events） | 规律挖掘、推荐、记忆 | 仅本人（匿名聚合除外） | 由负责人决定 | 删除事件后不再进入新推荐/记忆 |
| 对话消息 | 会话历史、总结、教师上下文 | 仅本人 | 由负责人决定 | 删除后不再进入新 TeacherContext；摘要随会话删除 |
| 测验答卷（Snapshot/作答） | 错题讲解、复习 | 仅本人 | 由负责人决定 | 删除后不再参与复习；Snapshot 快照保留原文（不覆盖旧答卷） |
| AI 生成记忆（StudentMemory） | 长期记忆、画像洞察 | 仅本人 | 由负责人决定 | **遗忘/否认（DISPUTED/REMOVED）后不再进入新 TeacherContext；pipeline 不再以同内容复活**（T24 已实现并测试） |
| 画像洞察（ProfileInsight） | 学习画像 | 仅本人 | 由负责人决定 | 失效（SUPERSEDED）后不再展示 |
| 知识资源/书库语料（后台） | 教材与检索 | 管理员/系统 | 由负责人决定 | 不属学生个人数据 |

> 保留期说明：**没有既定保留期，明确由负责人决策，执行 agent 不自行编造天数。**

## 删除/遗忘的实际语义（操作文案与真实一致）

- **遗忘/否认记忆**：`StudentMemory.status` 置为 `DISPUTED`（用户否认）或 `REMOVED`（遗忘/删除）。`teacher_context` 与 `agent_md` 只读取 `status='ACTIVE'`，故该记忆**不再进入新的教师上下文**；记忆后台任务（`pipeline`）按内容对全部状态去重，**同内容记忆已非 ACTIVE 时不新建 ACTIVE 行复活**（T24 修复，`test_memory_exclusion.py` 覆盖）。
- **证据派生路径受控**：记忆的 `evidence_ids` 指向真实证据；被否认记忆不因证据重新出现而复活（仅 ACTIVE 记忆累加证据）。
- **对话/答卷**：软删除或遗忘后不进入新上下文；`questions_snapshot` 快照保留原文（改题后旧答卷不变）。
- **正式删除另走受控确认**：本计划记录语义；用户侧"删除"需受控二次确认，不在本文件编造流程细节。

## 导出约束

- 任何导出须**不包含他人数据与密钥**；仅导出本人数据，并去除 token/秘钥/内部 request id 等敏感字段。
- 教学评测报告（T23）已明确"敏感信息不入报告"，用合成提示而非真实学生历史。

## 对外试用前置（待负责人）

- 目标年龄段、监护与知情同意流程、数据退出流程由试点负责人确定。
- 真实学生历史不用于合成/评测；演示用合成数据与自有教材。
- 无既定保留期时，保留期由负责人决策；本计划不擅自设置删除期限。

## 实现与验证

- `teacher_context.py` / `agent_md.py`：仅读 `status='ACTIVE'` 记忆与 `ProfileInsight.status='ACTIVE'`（既有，核查确认）。
- `memory/pipeline.py`：按内容对全部状态去重，不复活被否认/遗忘内容（T24 修复）。
- `tests/test_memory_exclusion.py`：验证非 ACTIVE 记忆不进 TeacherContext、不被 pipeline 复活。
- `MemoriesPage`：操作文案与上述语义一致（用户看到"遗忘/否认"即真正不再被引用，非仅隐藏）。
- BE 验证：`test_memory_exclusion.py` + `test_memory_api.py` + `test_memory_pipeline.py` → 20 passed。

## 遗留（外部）

- 正式删除流程、监护/知情/退出流程、真实保留期由试点负责人确定并补充。
- 匿名聚合（非个人）数据的收集口径未在本文件定义，如使用需另行说明。
