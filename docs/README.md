# 文档基线（docs）

本目录集中存放项目文档，按用途分为以下子目录：

| 子目录 | 用途 |
| --- | --- |
| `requirements/` | 产品需求基线（产品需求总纲） |
| `architecture/` | 架构设计基线（项目架构设计） |
| `contracts/` | 领域模型 / API 契约 / 数据库 Schema 等接口契约（由后续 Phase 0 任务填充） |
| `plans/` | 开发实施计划与路线图 |
| `acceptance/` | 验收标准与验收记录 |

## 文档入口

- 执行总控文件（仓库根目录）：`霜铃_V3_Hermes-Codex_多Agent协同开发总路线.md`
- 产品需求总纲：`requirements/产品需求总纲.md`
- 项目架构设计：`architecture/project-architecture.md`
- 详细开发实施路线图：`plans/development-roadmap.md`
- UI/交互原型：`../prototypes/shuangling-v3-prototype.html`
