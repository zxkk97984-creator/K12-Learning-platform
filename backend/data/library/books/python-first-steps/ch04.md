T: 循环：把重复的事交给计算机

S: 为什么需要循环
P: 假设班主任让你把「明天带跳绳」打印一百份贴在楼道里。你已经学会了 print，但写一百行一模一样的代码？光是想想手就酸了。计算机最擅长的恰恰是不知疲倦地重复——让重复代码自动执行的机制，就叫循环。|mark:循环
@kp=loop
KC: 循环 :: 循环让某段代码反复执行，直到满足停止条件为止。它把「做一百次」的辛苦交给机器，人只负责说清楚重复什么、何时停。:: 生活里的例子 :: 跑操绕操场五圈：操场是循环体，「满五圈」就是停止条件。
P: 先认识第一种循环：for 循环。写法是「for i in range(5):」，下一行缩进放要重复的代码。「range(5)」会依次吐出 0、1、2、3、4 五个数，每吐一个，缩进的代码就执行一次，所以「print("明天带跳绳")」总共被执行五次。字母 i 是循环变量，每一轮它都接住当前轮到的那个数。
P: range 还有更灵活的用法。「range(1, 6)」从 1 数到 5——注意第二个数本身不包含在内，就像「排队排到 6 号前面为止」；「range(0, 11, 2)」则每隔两个数取一个，吐出 0、2、4、6、8、10。帮你记个口诀：前两个参数是「从哪数到哪」，含头不含尾；第三个参数是步伐，决定每轮跳几个数。想打印 1 到 100，只需要「for i in range(1, 101):」加一行 print。
FIG: 流程图：方框「i 取下一个数」指向菱形「还有数吗？」，成立时箭头进入「执行循环体」再绕回开头，不成立时箭头离开循环去往“继续后面的代码” :: for 循环像发牌：range 准备好一叠数字，每轮发出一张，发完自动结束
CALL: 想一想 :: 「range(1, 101)」一共发出多少张数字牌？如果想让程序只打印偶数，该在 print 里输出 i 之外再加点什么条件？

S: while：看情况停下的循环
@kp=loop
P: 第二种循环叫 while，中文意思是「只要……就一直」。写法「while count < 5:」表示：只要 count 小于 5 成立，就反复执行缩进部分。和 for 提前知道次数不同，while 更适合「不知道要做多少次，做到某个时刻为止」的场景。|mark:while
KC: while 循环 :: while 先检查条件，成立就执行一遍循环体然后回头再检查，直到条件不成立才离开。条件里用到的变量必须在循环内被更新，否则永远停不下来。:: 试一试 :: 倒计时程序每打印一个数就把剩余秒数减一，减到零自然停止。
P: 使用 while 有一个保命细节：循环体里必须想办法让条件趋向不成立。比如「count = 0」之后写「while count < 5:」打印 count 并执行「count = count + 1」。每轮加一，加到 5 时条件变假，循环自动结束。要是忘了这行自增，条件永远成立，程序就会陷入死循环——转个不停直到被强行关闭。
P: 有一种正当用途的「无限循环」写法是「while True:」，配合 break 使用。break 的意思是「立刻跳出循环」：比如程序不断等待用户输入，一旦输入内容等于「退出」二字，就执行 break 结束循环往下走。这个组合马上会在第五章的猜数字游戏里大显身手。
P: 循环和上一章的条件判断组合起来威力巨大。想在 1 到 10 里找出所有偶数：外层「for i in range(1, 11):」负责逐个报数，里面套一句「if i % 2 == 0:」筛选后打印。百分号在这里是求余数运算，余数为零说明能被 2 整除。一层负责重复、一层负责挑选，这就是程序的基本节奏。
CALL: 想一想 :: 数学课上学过高斯巧算 1 加到 100。如果不许用公式，让计算机硬算，该怎么写？提示：准备一个装总和的变量，在循环里一轮一轮往里累加。

S: 动手试一试
P: 来验证高斯的故事。先建变量 total 等于 0，然后「for i in range(1, 101):」循环体里写「total = total + i」，结束后打印 total。你会看到熟悉的 5050。计算机没有聪明公式，但它一秒钟完成了三百次操作——这正是第一章说过的：把步骤说清楚，剩下的交给机器。
P: 再做一个倒计时练习：用 while 从 10 数到 1，每个数占一行，最后补一句「发射！」。参考思路：变量 t 从 10 开始，条件「t > 0」时打印 t 并把 t 减一，循环结束后打印发射。如果你打出了十行数字却没等到「发射」，八成是条件写错了边界。
P: 回顾本章：for 配 range 处理「知道次数」的重复，while 处理「看情况停」的重复；循环变量每轮更新，break 能中途跳出；循环套条件能边重复边筛选。到这里，顺序、分支、循环三大结构你已集齐——任何复杂程序，都是这三样积木搭出来的。
