T: 变量与数据类型：给数据安个家

S: 为什么需要变量
P: 上一章的程序像一位只出不进的喇叭：能喊话，却记不住任何东西。可真正的任务里，数据总要被反复使用——游戏要记住你的得分，聊天软件要记住你的昵称。这一章我们就给计算机装上「记忆」，主角的名字叫变量。|mark:变量
P: 变量的道理和学校的储物柜一模一样。柜子上贴着一张名字标签，柜子里放着你的书包；下次想拿书包，只要找到写着这个名字的柜子就行。变量就是这样一个贴了标签的格子：标签是变量名，格子里放的是数据，而且随时可以换新的进去。
@kp=variable
KC: 变量 :: 变量是给数据起的名字。程序把一个值存进变量之后，就可以随时通过这个名字把它取回来使用或修改。:: 生活里的例子 :: 「身高 = 160」就像在柜子上贴好「身高」标签、放进数字 160，以后提到身高，指的就是这个数。
P: 把数据放进变量的动作叫赋值，写法用一个等号：「age = 13」。这行代码要读成「把 13 装进名叫 age 的盒子」，而不是数学课上的「age 等于 13」。等号左边永远是变量名，右边永远是要放进去的值，方向千万别搞反。|mark:赋值
P: 存进去之后就能随时取用。「print(age)」会显示 13，「print("年龄", age)」还能把文字和变量拼在一起输出。注意一个重要区别：print(age) 打印的是盒子里装的东西，而 print("age") 打印的是 age 这三个字母本身——有没有引号，含义完全不同。
FIG: 图解画着一排储物格：第一格贴着标签「name」，里面放着一串文字“小明”；第二格贴着标签「age」，里面放着数字 13；一只手正把新数字放进第二格，替换旧值 :: 变量就像贴了名字标签的储物格，格子里存放的数据可以随时更换

S: 四种常用的数据类型
P: 盒子里的东西五花八门，计算机给它们分了类，这就是数据类型。为什么要分类？因为不同类型能做的事不同：数字可以做加减乘除，文字只能拼接，真假值用来做判断。分清类型，才知道对一个数据该用什么操作。|mark:数据类型
@kp=data-type
KC: 数据类型 :: 数据类型描述数据的种类，决定它能参与哪些运算。初学阶段最常见的四种：整数 int、小数 float、字符串 str、布尔值 bool。:: 试一试 :: 输入「print(type(13))」，屏幕会显示 <class 'int'>，这是查看类型的工具 type。
P: 整数不带小数点，比如 13 和 -7；带小数点的叫浮点数，比如 3.14。它们都属于数字家族，可以直接做算术：「print(6 * 7)」会显示 42。但有一个容易踩的坑：包在引号里的「"13"」不是数字，是两个字符组成的字符串，它没法参加减法运算。
P: 字符串最擅长的是拼接。用加号可以把两段文字连起来：「print("你好，" + "小明")」显示「你好，小明」。可如果你写「"3" + "5"」，得到的不是 8，而是字符串「"35"」——加号遇到字符串时表示首尾相连，不再表示算术加法。这个区别一定要刻在脑子里。
P: 第四种类型叫布尔值，全世界只有两个成员：True（真）和 False（假）。它听起来朴素，作用却极大——下一章的条件判断，全靠它来回答「成立还是不成立」。比如「print(5 > 3)」会显示 True，因为五大于三这件事确实成立。|mark:布尔值
CALL: 想一想 :: 先别运行代码，动笔猜一猜：「"我" + "13岁"」的结果是什么？「13 + 1」呢？写下答案后再运行验证，看看和你的直觉差在哪里。

S: 动手试一试
P: 变量还有一个重要本领：更新。同一个盒子可以先放旧值再换新值。「score = 90」之后再来一句「score = score + 5」，计算机先把右边的 score 取出来算出 95，再把 95 放回盒子里。一行看起来有点绕的代码，拆成「取出、计算、放回」三步就一目了然了。
P: 用变量前必须先赋值，否则计算机会一脸茫然地报 NameError，意思是「我没见过这个名字」。另外，给变量起名也有规矩：只能用字母、数字和下划线，且不能以数字开头；score、my_age 都合法，1st_place 就不行。更重要的是名字要见名知意，半年后回看代码也能一眼读懂。
P: 现在轮到你了。请完成一个小练习：创建两个变量 name 和 age，分别存入你的名字和年龄；然后用一次 print 把它们一起打印出来；最后把 age 更新为明年生日的数值，再打印一次。做完你会发现，程序终于有了记忆。
P: 回顾一下：变量是贴标签的储物格，赋值是把数据装进格子；数据分为整数、浮点数、字符串和布尔值，类型决定了能做的操作。你已经能让计算机「说话」并「记事」了，但它现在还只是从头到尾老实执行，遇到不同情况不会拐弯。
