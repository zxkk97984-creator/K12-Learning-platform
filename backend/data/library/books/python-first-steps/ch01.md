T: 你好，世界：第一次让计算机听话

S: 程序是什么
P: 欢迎来到编程的世界！这一章只有一个目标：让计算机在屏幕上显示一句「你好，世界」。这句话看起来毫不起眼，但它是全世界程序员公认的起点。当你亲眼看到屏幕上蹦出这四个字时，你就完成了人与机器之间的第一次完整对话。|mark:程序
P: 在动手之前，先想清楚一个问题：到底什么是程序？想象你要教一位从没进过厨房的朋友煎鸡蛋。你会把动作拆成一步一步：打开火、倒油、磕蛋、翻面、关火、装盘。只要步骤写得足够清楚，任何人照着做都能得到差不多的结果。这种写给计算机的「步骤清单」，就是一份程序指令。|mark:指令
@kp=program-instruction
KC: 程序 :: 程序是一串按顺序写给计算机执行的指令。计算机会不折不扣地照做，既不会偷懒跳步，也不会自己脑补你没写的细节。:: 生活里的例子 :: 一份菜谱就像给人看的程序：先热锅再倒油，顺序乱了味道就全变了。
FIG: 图解分为四步：左边一个人在纸上写下几行代码，箭头指向中间一台计算机，代码被逐条翻译并执行，最右边屏幕上显示出运行结果 :: 程序的旅程：你写代码，计算机逐条执行，最后给出结果
P: 不过计算机和人有一个巨大的差别：人能听懂「随便炒一下」，计算机却只认精确的指令。「炒到差不多」对人来说没问题，对计算机来说等于什么都没说。所以学编程练的不只是打字，更是把你脑子里的想法拆成清清楚楚的步骤——这也是编程最有趣的思维训练。

S: 认识我们的新语言
P: 人和人交流要用语言，人和计算机交流也要用语言，这种语言叫编程语言。全世界有几百种编程语言，我们这本书选的是 Python（读作「派森」）。它最大的优点是长得接近英语，规则简单直接，特别适合作为人生的第一门语言。学校里的人工智能课、科学家的数据实验，都常用它完成。|mark:Python
P: 光有语言还不够，计算机怎么才能看懂你写的 Python 呢？这要靠一位不知疲倦的「现场翻译」——解释器。你每写完一段代码，解释器就从上往下逐行阅读，边读边执行。你说的每一句话，它都会立刻照办，这正是我们马上要做的事。|mark:解释器
@kp=python-print
P: 万事俱备，来写下你的第一行代码：「print("你好，世界")」。把它输入运行环境后按下回车或点击运行按钮，屏幕下方就会跳出四个字：你好，世界。恭喜，你已经会指挥计算机了！|mark:print
KC: print 函数 :: print 是 Python 里用来在屏幕上显示内容的工具，也是我们调试程序的好帮手。括号里放什么，屏幕就显示什么。:: 试一试 :: 输入「print("我爱上学的每一天")」，运行后屏幕就会原样显示这句话。
P: 把这行代码拆开看，每个部件都有名字：print 是函数名，可以理解为一个工具的名字；后面的小括号用来装你要交给它的东西；双引号圈住的文字叫字符串，也就是一串字符。记住一个关键规矩：想让计算机原样显示文字，就要给它套上引号。
CALL: 想一想 :: 如果去掉引号，直接写 print(你好)，计算机会怎么反应？大胆猜一猜，再亲手试一次——下一小节我们就聊聊这种「报错」。

S: 报错不可怕
P: 大多数人第一次都会在这里碰壁：屏幕上没有出现「你好」，反而冒出一大段红色英文，比如 SyntaxError。别慌，这不是考试扣分，而是计算机在举手提问：「你这句话我没看懂。」报错信息其实是编程路上最好的老师，它会指出哪一行出了问题、大概是什么性质的问题。|mark:SyntaxError
P: 和报错同样常见的还有「手滑」。初学者最容易犯的两个错误是：把中文引号“”当成英文引号""，以及漏掉半个括号。计算机对这些差别极其敏感——中文引号和英文引号在它眼里是完全不同的符号。以后遇到莫名其妙的报错，先检查一遍符号用的是不是英文半角。
P: 现在轮到你动手了。请依次完成三件事：第一，把引号里的文字改成你想说的任何一句话；第二，再写一行新的 print，让屏幕连续显示两句话；第三，故意删掉一个引号再运行，认真读一读报错提示，然后把引号补回来。做完这三步，你对 print 的理解就超过大多数只看不练的人了。
P: 最后再教你两个 print 的实用技巧。想在括号里放好几段内容，可以用英文逗号隔开，例如「print("我的名字是", "小明")」，屏幕会用空格把它们连起来显示；而「print()」什么都不放，会打印出一个空行，适合给输出内容分段留白。
P: 回头看这一章：你认识了程序就是精确的步骤清单，认识了 Python 和它的解释器，还亲手运行了第一个 print，甚至提前体验了报错。工具箱里已经有了第一件工具，但现在的程序只会「说话」，还不会「记事」——总不能每次都现打现说吧？
