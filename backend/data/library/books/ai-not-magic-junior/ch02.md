S: 从填空题说起
P: 先玩个小游戏：「白日依山尽，黄河入海——」，你几乎不用想就能接出「流」。再比如「今天天气真——」，十个人里九个会说「好」。人为什么能接得这么顺？因为你读过大量中文，脑中装着语言的统计规律。生成式 AI 的核心本领，和这个游戏一模一样。|mark:生成式 AI

KC: 下一词预测 :: 下一词预测是语言模型的基本工作方式：读进前文后，给词库里每个候选词打一个「出现概率」，选出合适的词接上，然后再预测下一个。:: 试一试 :: 对模型说「床前明月」，它接「光」的概率会远远高于其他字。
P: 你在聊天框里看到的长篇回答，就是这样一词一词接出来的：模型读完你的问题，预测一个词；把这个词接到句子后面，再预测下一个；如此循环直到收尾。它并不是先在脑子里打好完整草稿再一次性说出来，而是像我们说话一样，边说边决定下一个词。
FIG: 流程图展示一句话逐词生长的过程：「今天天气」→ 预测出「真」→「今天天气真」→ 预测出「好」→「今天天气真好」，每一步上方都画着一个概率条形图，最高的柱子被选中 :: 模型每一步都在做同一件事：根据前文，挑出概率最合适的下一个词
P: 有个细节值得注意：模型选词时并非永远只拿第一名。写诗时它可能故意选概率第二、第三的词来制造新意，这叫随机性调节。所以同一个问题问两遍，回答常常不一样——不是它心情变了，而是掷骰子的方式不同。
CALL: 想一想 :: 如果把随机性调到零，每次都只选概率最高的词，AI 的回答会变得怎样？更可靠还是更死板？这个问题工程师也一直在权衡。

S: 为什么接龙能接出「智能」的样子
P: 你可能怀疑：只是接词，怎么就能写作文、讲数学题？关键在于规模。要准确预测各种语境下的下一个词，模型必须读懂语法、常识甚至逻辑——不弄懂「因为下雨，所以地面湿了」这类关系，就猜不准后面的词。为了把接龙玩好，语言规律之外的知识被迫一起学进来了——这样的模型就叫语言模型。|mark:语言模型
KC: 语言模型 :: 语言模型是通过阅读海量文本、学会词语统计规律的模型。规律学得足够深，它就能生成通顺连贯的新文字，看起来像理解了内容。:: 生活里的例子 :: 像一个读过整个图书馆的人玩接龙，词汇、句式、典故信手拈来。
P: 这也解释了它的强项和弱项从哪来。强项：凡是语言规律能覆盖的活儿——润色作文、翻译、总结要点——它都又快又稳。弱项：它对「事实本身」并没有一个可靠的仓库，它掌握的是「人们通常怎么写」，而不是「世界到底是什么样」。这个裂缝，正是下一章幻觉的源头。
P: 还有一个常见误解要澄清：模型并不真的「记得」训练时读过的每一篇文章。它记住的是压缩后的规律，类似你学完语文课不会背下所有课文，但写作文时处处用得上语感。所以问它「你训练数据里第 37 页写了什么」，它答不上来，也不该答上来。
CALL: 动手验证 :: 找一个 AI 聊天工具，让它把同一个故事分别写成童话版和新闻版。观察两次输出的风格差异，想想：变的是事实还是措辞？这说明模型学到的主要是什么？

S: 小结与预告
P: 回顾本章：生成式 AI 的引擎是下一词预测，长文是一个词一个词接出来的；为了让接龙接得准，模型顺便学会了语法、常识与逻辑，于是显得聪明；但它擅长的是「怎么说」，不是「什么为真」。能力与真相之间的这条缝，就是我们要认真对待的地方。
P: 既然它按概率说话，那它会不会信心满满地说错话？会，而且错得非常流畅，流畅到连大人都常常中招。这种一本正经的胡说八道有个专门的名字，已经成为 AI 时代的高频词。下一章我们就去现场抓几只现行，看看它们到底长什么样。
