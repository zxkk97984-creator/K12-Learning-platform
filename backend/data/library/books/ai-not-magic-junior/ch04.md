T: 看不见的陷阱：偏差与对抗样本

S: 偏差藏在数据里
P: 某国际大赛的人脸识别系统，对浅肤色面孔准确率极高，对深肤色面孔却频频认错。工程师检查后发现：问题不在算法本身，而在训练照片——浅肤色样本占了绝大多数。模型忠实地学会了它见得多的世界，也忠实地忽略了它见得少的——这股藏在数据里的偏心，叫作数据偏差。|mark:数据偏差
@kp=data-bias-source
KC: 数据偏差来源 :: 数据偏差来自收集数据的范围与方式：样本覆盖不均、标注标准不一、历史记录自带偏见，都会让模型学出偏心的规律。:: 生活里的例子 :: 只用城市道路图片训练的自动驾驶模型，第一次进乡村可能连土路都不认识。
P: 这类错误有个讨厌的特点：平时完全看不出来。模型整体准确率依然漂亮，只在特定人群、特定场景上悄悄失灵。所以负责任的 AI 团队会专门做「分组考试」——把测试数据按人群、场景拆开分别统计成绩，而不是只看一个总分。
FIG: 流程图：三个漏斗依次串联，第一个漏斗标着「谁被收集」，第二个标着「谁被标注」，第三个标着「模型学习」，每个环节都有小人在筛掉部分卡片，最后输出的模型对某些卡片总是判断错误 :: 偏差不是模型凭空产生的，它在数据收集和标注的每一关就被埋下了
P: 更麻烦的是历史偏差的循环放大。招聘模型从过去的录用记录里学习，而过去某些岗位女性偏少，模型便学着压低女性简历的评分；评分结果又成为下一轮的「历史记录」。如果不人为干预，偏见会像滚雪球一样越滚越圆滑、越藏越深。
CALL: 想一想 :: 如果让你给「好学生拍照数据集」定收集标准，你会怎么避免只拍教室里举手的孩子？说说你的三条规则。

S: 几个像素的恶作剧
P: 再看另一种更诡异的错误。研究者给一张熊猫照片叠加一层人眼几乎不可见的细密纹理，识别模型的答案瞬间从「熊猫」变成「长臂猿」，置信度还高达 99%。这种被精心设计的干扰输入叫对抗样本，它是模型的「视觉错觉」。|mark:对抗样本
@kp=adversarial-example
KC: 对抗样本 :: 对抗样本是在正常输入上加入人难以察觉的微小扰动后，能让模型稳定判错的特殊输入。它暴露的是模型学到的规律与人理解的方式并不相同。:: 生活里的例子 :: 贴几张特定花纹的小贴纸在路牌上，自动驾驶系统可能把限速牌看成禁行牌。
P: 为什么几个像素有这么大威力？因为模型看图的方式和人不同：它读的是像素数值的统计模式，而不是形状的语义。扰动恰好顺着模型敏感的方向推了一把，就能把它推过决策边界。换句话说，这不是模型「笨」，而是它的聪明和我们不在同一个维度。
P: 对抗样本提醒我们两件事。安全上，人脸门禁、自动驾驶这类高风险系统必须专门做对抗测试，就像建筑要做抗震试验。认知上，「准确率 99%」从来不等于「万无一失」，那 1% 可能恰好集中在攻击者最想突破的地方。
P: 把本章两个陷阱放在一起看：数据偏差是「无意的偏心」，对抗样本是「有意的欺骗」，它们共同说明——模型的强大能力与可靠程度是两回事。评价一个 AI 系统，不能只看它在考卷上的分数，还要看它在刁钻角落里的表现。
CALL: 动手观察 :: 用手机人脸解锁试试戴口罩、侧脸、强光下的成功率变化。这些日常「翻车」瞬间，和实验室里的对抗样本有什么本质不同？

S: 小结与预告
P: 回顾本章：偏差随数据进入模型，需要分组测试才能现形；对抗样本用微小扰动骗过模型，暴露了机器规律与人类直觉的差异；两者都指向同一个结论——AI 需要被持续审视，而不是一次性信任。
P: 审视之后呢？总不能因为会出错就把 AI 关掉吧。正确的姿势是建立一套使用守则：哪些事放心交给它，哪些事必须自己把关。最后一章，我们把这套守则完整搭起来。
