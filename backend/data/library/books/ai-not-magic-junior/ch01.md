T: 魔法背后的统计：AI 是怎么「学」的

S: 两种让计算机变聪明的路
P: 打开视频软件，它猜你想看什么；对着手机说话，它能听懂并回答。这些能力常被形容成魔法，但 AI 不是魔法，它的每一个本领背后都是数学和大量数据。这一章我们先拆掉「魔法滤镜」，看清智能的第一层真相：聪明是可以被制造出来的，而且不止一种造法。
P: 第一种造法你已经在编程书里见过：程序员把规则一条条写清楚。「如果收到含『中奖』二字的邮件，就归入垃圾箱」，这就是规则程序。它的优点是清清楚楚、可以解释；缺点也很明显——骗术稍微换个说法，比如把中奖写成中獎加表情符号，规则就失灵了。|mark:规则程序
@kp=model-training
KC: 模型训练 :: 模型训练是让程序反复对照大量例子、不断微调内部参数的过程：先猜一次答案，对照标准答案看差多少，再朝更准的方向调一步，循环成千上万次。:: 生活里的例子 :: 就像练投篮：投出、看偏了多少、修正姿势，练得越多手感越准。
KC: 泛化能力 :: 泛化指模型对训练时从没见过的数据依然能做出正确判断的能力，它是区分「背题」和「真学会」的关键标尺。:: 试一试 :: 用上周的旧照片测试人脸相册，再用今天刚拍的测一次，两次都准才是真学会了。
P: 第二种造法反着来：不写规则，而是给程序看成千上万个已经标好答案的例子，让它自己找规律。垃圾邮件识别不再靠关键词清单，而是读几百万封邮件，慢慢体会哪些特征和「垃圾」相关。这样训练出来的程序叫模型，「找规律」的过程就是模型训练。|mark:模型
FIG: 对比图分左右两栏：左栏是程序员在白板上写下一条条 if 规则，箭头指向一台按规则执行的机器；右栏是一大摞标注好的例子卡片输入机器，机器内部齿轮转动后输出一个模型图标 :: 左边是人工写规则，右边是从例子中学规律，这是两种不同的「聪明生产线」
P: 两种路线各有用武之地。计算工资该扣多少税，规则写死反而可靠；而判断照片里是不是猫，猫的姿态千变万化，人根本写不全规则，只能靠学习。今天我们说的 AI，主要指第二种：从数据里学规律的模型。理解了这一点，很多新闻就不神秘了。
CALL: 想一想 :: 你能想到一件「规则程序做得更好」和一件「必须从例子学习才做得到」的事吗？下一节我们把训练过程放大给你看。

S: 训练现场：猜测、对照、调整
P: 把镜头拉近到训练现场。假设我们要教模型认手写数字。一开始它的参数是随机的，等于闭着眼瞎猜：看到一张「7」，它可能说这是 1。猜完立刻对照正确答案，发现错了，就计算一个「错得有多离谱」的分数，然后朝着让这个分数变小的方向，把参数轻轻挪一点。
P: 这个「猜测—对照—调整」的循环会重复几万甚至几百万次。每一次调整都微小到看不出变化，但累积起来，模型的准确率会像爬坡一样稳步上升。工程师把这个误差分数叫损失，把整个爬坡过程叫优化——名字唬人，本质就是「错了就改，越改越准」。|mark:损失
P: 训练完成后还有一场大考：用一批模型从没见过的数据测试。为什么？因为只考课上讲过的原题，可能是死记硬背；换新题还能答对，才算真学会了规律。AI 界管这叫泛化能力，它是区分「背题」和「学会」的关键标尺。|mark:泛化
P: 现在你可以解释很多现象了。为什么 AI 公司都要收集海量数据？因为例子就是教材，教材不够好，学生再努力也学不正。为什么同一个模型有时灵有时不灵？因为它学到的是统计规律，规律覆盖不到的地方就会露怯。AI 的聪明有来处，也有边界。
CALL: 动手观察 :: 找一个 AI 绘画或识图工具，故意输入非常冷门、少见的东西，看看它的表现和常见事物有什么差别。把你观察到的差距记下来，第三章我们会解释这类现象。

S: 小结与预告
P: 回顾本章：让计算机变聪明有两条路，一条是人写规则，一条是让模型从例子里学规律；训练的本质是猜测、对照、调整的无限循环，最终目标是能在没见过的题目上依然可靠。记住这句话：AI 的智能不是凭空来的，是数据和计算喂出来的。
P: 你可能会追问：聊天机器人又不会看图，它怎么也显得那么聪明？它学的其实是语言本身的规律——下一个词最可能是什么。这门「超级文字接龙」的手艺，就是下一章的主角。
