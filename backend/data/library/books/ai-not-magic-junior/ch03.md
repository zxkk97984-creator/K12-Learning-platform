T: 一本正经地胡说：幻觉从哪来

S: 幻觉长什么样
P: 有人问 AI「推荐几本关于海洋的科普书」，它流利地列出了五本，作者、出版社、出版年份一应俱全——可惜其中两本书根本不存在，作者是它拼出来的名字。回答读起来毫无破绽，事实却是编的。这种流畅但失真的输出，就叫幻觉。|mark:幻觉
@kp=ai-hallucination
KC: 幻觉 :: 幻觉指 AI 生成的内容看似可信、实际与事实不符的现象。它不是故意撒谎，而是模型按语言概率续写时，把「像真话」当成了「是真话」。:: 生活里的例子 :: 问一个没听过的故事，人也会顺着编下去；AI 的特殊在于编得毫无心理负担且格式完美。
KC: 高危提问 :: 冷门细节、精确数字、诱导性问题，是三类最容易触发幻觉的提问方式。识别高危问题，就等于提前给回答装上了警报器。:: 试一试 :: 分别问「水的沸点是多少」和「某位小众学者的生卒年」，对比两答的可靠程度。
FIG: 对比图：左边是一份排版工整的书单，每行都有书名和年份，其中两行被红圈标出并打上问号；右边是一个放大镜照着红圈处，放大后显示「查无此书」 :: 幻觉的危险恰恰在于外表完美：不逐条核对，很难发现哪一行是编造的
P: 为什么会这样？回忆上一章：模型的引擎是下一词预测，它天生追求「接得顺」，而不是「说得对」。当被问到训练数据里很少见的问题时，它没有「我不知道」的本能退路，只会继续按概率把最像答案的话接完。于是知识空白被流畅的文字填平了。
CALL: 想一想 :: 人考试遇到不会的选择题也会硬猜一个，这和 AI 的幻觉有什么相同、什么不同？提示：想想人知不知道自己在猜。

S: 什么样的提问容易踩坑
P: 第一类高危问题是追问冷门细节：小众人物的生卒年、不知名论文的具体结论、某家小店的开业日期。训练数据里这类信息本来就稀薄，模型最容易在此处开编。第二类是要求精确数字：统计百分比、引用原文页码，模型对数字的把握远不如对句式的把握。
P: 第三类更隐蔽：诱导性提问。「为什么吃冰激凌会导致溺水？」——问题本身预设了假前提，很多模型会顺着你的框架一本正经地解释原因，而不是先纠正你。学会识别这类问题，既是防 AI 出错，也是防自己被带偏。
P: 那怎么防？给你三个实用习惯。第一，重要信息要求它给出处，然后亲自点开核对——出处本身也可能是编的，所以必须验。第二，换种问法再问一遍，两次答案明显打架的地方就是危险区。第三，凡是「具体的事实」默认存疑，凡是「帮你改写、总结、出主意」可以放心用。这三招合起来就是一套核查流程。|mark:核查流程
P: 有个类比能帮你记住：把 AI 当成一个博览群书但偶尔记混、又特别好面子的学长。让它帮你列提纲、改病句，非常靠谱；让它背你的身份证号，那就是灾难。分工清楚，幻觉的伤害就能降到很低。
CALL: 动手实验 :: 让 AI 介绍一个你非常熟悉的领域（比如你的学校、你最爱的动画），专门检查细节有没有错。对比它在通用话题上的表现，体会「越冷门越危险」。

S: 小结与预告
P: 回顾本章：幻觉是概率引擎的副产品——追求接得顺而非说得对；冷门细节、精确数字、诱导提问是三大雷区；应对靠三个习惯：要出处、多验证、分场景。AI 不是不能用了，而是需要一位清醒的使用者。
P: 不过，错误还不止幻觉这一种。有些错误藏在数据里，连模型自己都察觉不到：某些人群总是被看错，某些照片总被标错标签。下一章我们挖更深一层的两个陷阱：数据偏差与对抗样本。
