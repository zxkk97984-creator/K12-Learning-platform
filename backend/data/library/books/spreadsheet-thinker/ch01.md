T: 认识表格：格子里的世界

S: 每个数据都有自己的门牌
P: 打开电子表格软件（Excel、WPS 或免费的 LibreOffice 都可以），你会看到一片由小格子组成的海洋。横向的叫行，纵向的叫列；行用数字编号，列用字母命名。任何一个格子都是行与列的交点，它的名字由「列字母加行号」组成：B3 就是 B 列第 3 行。这个名字叫单元格地址。|mark:单元格地址
@kp=cell-address
KC: 单元格地址 :: 单元格地址由列字母和行号组成（如 C5），是每个格子的唯一门牌号。公式与函数都靠门牌号找到数据的位置。:: 生活里的例子 :: 电影票上的「5 排 3 号」就是座位在影院里的单元格地址——先说列再说行。
KC: 一行一记录 :: 建表守规矩：一行放一条完整记录，一列放一种属性；规整的结构是后续排序、筛选、统计顺畅的前提。:: 试一试 :: 把挤在同一格里的「周三 小李 擦黑板」拆成三列。
FIG: 一张放大的表格截图：顶部是字母列标 A、B、C，左侧是数字行标 1、2、3，一个高亮的格子被红框圈出并引出标注「C5 = C 列第 5 行」，旁边画着一张电影票 :: 表格里的每块数据都有唯一门牌：先字母后数字
P: 表格软件里还有两个导航神器：名称框和冻结窗格。名称框位于左上角，直接输入 B200 回车就能瞬间跳到第两百行；冻结首行后往下滚动时表头始终可见，数据再多也不会对不上列名。这两个小设置一分钟搞定，幸福感却贯穿全程使用体验。
P: 门牌号为什么重要？因为整本电子表格的魔法都建立在「按位置找数据」之上。你不需要记住某个数据在哪，只需要知道它在哪个格子——数据换了内容，门牌不变，引用它的计算自动跟着变。这是表格比纸质记录高明的地方：它存的是位置关系，不只是数字本身。
CALL: 想一想 :: 如果把 A1 的内容剪切粘贴到 D10，原来指向 A1 的东西会发生什么？带着这个疑问往下学，第二章见分晓。

S: 先建一张自己的表
P: 空谈不如动手。我们来建一张最简单的班级值日表：第一行输入表头——A1 输入「星期」，B1 输入「值日生」，C1 输入「负责区域」。然后在 A2 到 A6 竖着填周一到周五，B、C 两列随手填几个同学的名字和区域。五分钟不到，一张能用的表格就诞生了。
P: 建表时有个值得养成的好习惯：一行一条完整记录，一列一种属性。比如「周三是小李负责擦黑板」不要挤进一个格子，而是拆成三列分别填写。这种规整的结构会让后面的排序、筛选、统计全都顺畅——乱结构的表格，工具再强也帮不了你。
P: 再教你两个编辑基本功：改错字时双击格子直接修改；换位置时选中格子拖动边框移动；删错内容按 Delete 清空重来。还有撤销键 Ctrl+Z（苹果电脑用 Command+Z）这位手滑救星坐镇，你就可以放心大胆地折腾整张表格。
CALL: 动手实践 :: 在你的值日表里故意把「周三」输成「周三值日：小李擦黑板」，体验一下这种写法会给后面想单独统计「每人值日次数」带来多大麻烦。

S: 小结与预告
P: 回顾本章：表格由行列组成，每个格子有唯一的单元格地址；建表要遵守「一行一记录、一列一属性」的规矩；双击修改、拖动移动、Ctrl+Z 撤销是三大基本操作——掌握门牌号思维，表格里的一切操作就有了坐标。。
P: 表格搭好了，但现在的它只是个安静的记事本。让它活过来的咒语是一个小小的等号——下一章我们学习公式，让表格自己算数——等号的魔力下一章马上揭晓，值得期待。。
