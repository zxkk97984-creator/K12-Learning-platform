T: 公式：让表格自己算

S: 第一个公式：从等号开始
P: 在表格里做计算，不用心算也不用计算器，只需要记住一个开头符号：等号。在空格里输入「=B2+C2」再按回车，表格立刻显示两个数之和。所有公式的共同规矩：以等号开头，后面是你要的计算。从此这个格子里住的不是死数字，而是一条随时待命的算式。|mark:公式
@kp=spreadsheet-formula
KC: 电子表格公式 :: 公式以等号开头（例如 =B2+C2 或者求和函数 SUM），表格自动算出结果；被引用的格子数据一有变化，所有相关结果立即即跟着更新。:: 生活里的例子 :: 像在菜谱上写「盐=酱油×2」，酱油换了牌子，咸淡自动跟着调。
P: 魔法不止于此。把 B2 的 85 改成 95，回车的一瞬间，所有引用它的公式全部刷新。这就是第一章那个悬念的答案：改门牌里的住户，不拆门牌，依赖这门牌的计算纹丝不乱地更新。手算一百次都可能漏改一处，表格一次都不会。
FIG: 左右对照图：左边一张成绩单，B 列五个分数，B6 格写着「=SUM(B2:B5)」显示总和 320；右边 B3 的 88 被改成 95，B6 瞬间变成 327，旁边一个刷新图标 :: 数据一变，结果全变——这就是公式与普通数字的区别
P: 函数输入时表格还会主动帮忙：打出等号和函数名的前几个字母，屏幕会弹出候选列表和参数提示，选中回车即可。记不住完整拼写完全没关系——让软件替你记住，你只需要知道想算什么。这种智能提示同样适用于后面要学的所有函数。
P: 除了四则运算，表格还内置了大量现成的函数——写好的常用公式包。最常用的五位：SUM 求和、AVERAGE 求平均、MAX 找最大、MIN 找最小、COUNT 数个数。写法如「=AVERAGE(B2:B5)」，其中 B2:B5 表示「B2 到 B5 这一整段」，冒号读作「到」。
CALL: 想一想 :: 用「=B2+B3+B4+B5」和「=SUM(B2:B5)」都能求和，后者好在哪里？想象一下如果是五百个数据呢？

S: 拖出来的效率
P: 一行行输入相似公式太累，表格早就替你想好了：自动填充。选中写了公式的格子，右下角有个小方块，抓住它往下拖——公式被复制到每一行，而且地址自动跟着变：拖到下一行的公式变成了 =AVERAGE(C3:C6)。这种随位置变化的引用叫相对引用，正是填充能一拖到底的原因。|mark:自动填充
@kp=autofill-handle
KC: 自动填充 :: 自动填充指拖动单元格右下角的填充柄，把公式或序列复制到相邻区域，其中的相对引用会按新位置自动平移。:: 试一试 :: 在 A1 输入 1、A2 输入 2，选中两格拖动填充柄到 A10，看看发生了什么。
P: 自动填充对规律序列同样灵光，这是它名字里「自动」二字的另一层含义——输个星期序列拖一拖，整周排班表自动出现——试试输个星期序列往下拖，整周安排自动出现。
P: 自动填充对规律序列同样灵光。输个「一月」往下拖，二月三月排着队出现；输个周一拖出整周。数字、日期、星期、自定义序列都认得。配合公式，一张五十人的成绩统计表，真正需要你动手输入的只有原始分数和第一行公式而已。
P: 公式写错了怎么办？最常见的三种报错值得认识：名称错误说明函数名拼错了；取值错误说明参与计算的内容不是数字；引用错误说明引用的格子被删掉了。看懂报错比记住公式更重要——它会告诉你往哪修。
P: 动手升级你的值日表：加一列「劳动次数」，用 COUNT 函数统计每位同学本周上岗几次；再用 SUM 统计全班总人次；最后试试把某个同学的值日安排换人，观察统计数据如何自动重算。做完这一轮，你已经超过大多数只会用表格当纸用的人了。
CALL: 动手挑战 :: 新建一张月度零花钱表：日期列用填充拖出一整个月，金额列随手填，「当日累计」列用公式实现越加越多——提示：累计格等于上一格加本行金额。

S: 小结与预告
P: 回顾本章：等号开启公式世界；SUM、AVERAGE 等五大常用函数覆盖绝大多数需求；冒号表示区间；自动填充配合相对引用让公式一拖百应；数据的任何修改都会即时传导到全部结果。
P: 会算了还不够快——想在一千条记录里找出借书最多的同学，靠滚动条要滚到手酸。下一章请出两位检索高手：排序与筛选——学会这两招，检索效率立刻提升百倍。。
