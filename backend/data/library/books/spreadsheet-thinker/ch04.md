T: 图表：一键让数据说话

S: 选中、插入、完成
P: 表格软件画图快得离谱：选中想展示的数据（比如姓名列和借阅数列），点「插入」菜单里的图表，一张柱状图立刻出现在表格上方。拖动边框调大小，双击标题改文字，三十秒内，一张能贴进班级板报的图就完成了。|mark:图表
@kp=spreadsheet-chart
KC: 表格图表 :: 表格软件能把选中区域一键转成柱状图、折线图、饼图等；柱状比多少、折线看趋势、饼图讲占比，类型即视角。:: 试一试 :: 同一份数据分别生成柱状图和饼图，体会两种图讲述的不同故事。
KC: 图表联动 :: 表格图表引用的是单元格区域，源数据一改图形实时重绘；一套表加图因此成为可长期使用的工具而非一次性作业。:: 试一试 :: 改动一个分数观察柱状图即时变化。
FIG: 三联小图并排：同一份五人借书量数据分别呈现为五根柱子、一条起伏折线、一个切分蛋糕；下方标注各自适合回答的问题 :: 数据不变，视角随图变——选图就是选择讲故事的方式
P: 但「一键」不等于「随便」。图表类型选错会讲错故事：拿折线图连五个同学的名字，暗示了根本不存在的时间先后；给十几个类别做饼图，扇区多到没法比较。还记得数据侦探那本书的口诀吗？条形比多少、折线看趋势、饼图讲占比且块数要少——在表格里同样适用。
P: 图表不是做完就结束的静态作品，它会随着源数据不断变化，也要经得起读者的追问和检验。做出来的图还要过一遍美化三问：坐标轴从几开始？每根柱子代表谁？标题说的是结论还是内容？三问都过关，这张图才有资格出现在你的报告里。坐标轴从几开始？（纵轴被截断会夸大差距）每根柱子代表谁？（数据标签打开更清楚）图的标题说的是结论还是内容？「各同学借阅量」是内容，「小李是本月的阅读冠军」才是结论——好图表的标题直接替读者说出发现。
CALL: 想一想 :: 为什么把纵轴起点改成 95 能让两根几乎等高的柱子看起来差了一倍？动手试一次，亲眼验证这个魔术。

S: 让图表跟着数据活
P: 表格图表有个纸质统计图没有的超能力：联动。图表引用的是单元格区域，源数据一改，图形实时重绘。图书角今天新增了三条借阅记录，柱状图自动长高。这意味着你搭好一套表加图之后，它是一件长期运转的工具，而不是一次性作业。
P: 动手搭一组联动装备：在图书角表中选中姓名与借阅数两列，插入柱状图并写上结论式标题；然后修改某个同学的借阅数，观察柱子的即时变化；再新增一行记录，检查图表是否自动纳入新行（若没有，把图表的数据区域扩大一行）。做完这套操作，你对「工具」二字会有新的理解。
P: 最后补一句审美纪律：颜色别超过三种，网格线能淡则淡，三维效果一律不用——立体柱子会让长短判断失真。图表的目标不是炫技，而是让读者三秒抓住重点。朴素而准确的图，永远好过花哨而误导的图。
CALL: 动手挑战 :: 为你的图书角表配两张图：一张柱状图回答「谁的借阅量最高」，一张饼图回答「各类书籍占比如何」，并为它们各写一个结论式标题。

S: 小结与预告
P: 回顾本章：插入图表只需选中加点击；类型即视角，选错图就是讲错话；美化三问守住准确底线；图表与数据的联动让成果成为可持续运转的工具——这四个要点就是图表制作的完整心法。。
P: 单项技能全部集齐：建表、公式、排序筛选、图表。最后一章，我们把它们组装成一件真正有用的作品——一份能让全班用一学期的图书角管理系统——把它做出来，你会成为班级里的表格小达人。。
