T: 为什么 AI 需要规矩

S: 一个流传很广的误会
P: 「算法是中立的，它只看数据说话。」这句话听起来很有道理，却经不起推敲。数据是人收集的，标注是人打的，规则是人定的——每个环节都掺着人的选择与偏见。说算法中立，就像说菜谱的味道与厨师无关：锅铲确实不偏心，但放什么盐是人决定的。
@kp=ai-fairness
KC: 算法公平 :: 算法公平要求系统对不同人群给出同等质量的对待，不让某个群体因为身份、口音、外貌等特征而系统性吃亏。:: 生活里的例子 :: 语音助手能听懂标准普通话，却常常听不懂方言使用者的认真表达——被系统忽视也是一种不公平。
FIG: 一条流水线图：起点「现实世界」经过三个工人岗位「谁的数据被收集」「怎么打标签」「优化目标是什么」，每个岗位旁画着一个倾斜的天平图标，终点输出「模型」 :: 中立神话的破灭：流水线上每一站都有人在做带倾向的选择
P: 你可能觉得伦理离工程很远，其实它就藏在最普通的技术决定里。给照片打标签时选哪些样本？把「点击率」设为优化目标时，有没有想过耸动的内容更容易被点？这些看似纯粹的技术问题，每一个都连着价值判断。伦理不是贴在产品上的标签，而是浇筑在代码里的钢筋。
CALL: 想一想 :: 如果让你设计一个「自动筛选夏令营申请」的系统，你会在哪些环节做出影响公平的决定？试着列出至少三处。

S: 没有规矩的世界会怎样
P: 假如完全不管会怎样？想象几个场景：招聘系统悄悄压低女性简历评分；信贷系统给某些街区统一降分；新闻推送为了点击量不断喂养极端内容；换脸视频以假乱真地毁掉一个人的名誉。这些都不是科幻——它们全部真实发生过或正在发生。
P: 这些案例有个共同点：单看每一步技术都没「违法」，甚至都挺高效。伤害是系统性的、缓慢显形的，等发现时往往已经影响很多人。这正是 AI 伦理要提前介入的原因：等技术闯了祸再补救，代价太大。
P: 世界各国正在建立 AI 治理规则：欧盟出台了人工智能法案，我国也发布了生成式人工智能管理办法等规定，核心共识高度一致——高风险应用必须接受更严的审查，人不能把重要决定完全甩给机器。规则会随技术演进不断修订，但方向清晰：技术服务于人，而不是相反。
P: 当然，伦理不只是政府和公司的功课。作为未来的使用者和可能的开发者，你的每个小选择同样算数：不制作传播伪造内容、遇到可疑的算法决定敢于追问、设计作业里的「智能系统」时多想一层会不会伤到某些同学。伦理意识要从第一次写代码就开始练。
KC: 技术中立神话 :: 「算法只看数据说话」是一种误解：数据由人收集、标签由人标注、目标由人设定，每个环节都掺着人的选择与倾向。:: 生活里的例子 · 锅铲不偏心，但放什么盐是人决定的——说菜的味道与厨师无关显然不通。
CALL: 动手讨论 :: 小组辩论：「技术本身没有对错，错的是用的人」——正反双方各找两个论据，看看这场经典争论里谁更有说服力。

S: 小结与预告
P: 回顾本章：中立是神话，AI 的每个环节都藏着人的选择；缺乏约束的高效系统会造成系统性伤害；治理规则正在全球铺开，而个人层面的伦理意识同样从现在开始积累。
P: 接下来四章，我们逐一拆开四块基石：公平、透明、责任、隐私。它们不是四个孤立的口号，而是同一张价值地图的四个方位。先看第一块——当算法开始分配升学名额、工作机会与信用额度时，谁来保证天平不歪？
