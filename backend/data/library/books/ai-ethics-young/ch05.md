T: 我的脸我做主：AI 与隐私

S: 刷脸时代的便利与代价
P: 刷脸进站、刷脸支付、刷脸签到——你的脸正在变成万能钥匙。确实方便，但请想一层：密码泄露可以改，脸泄露了怎么改？人脸是不可更换的生物特征，一旦被采集存储，就永久有效。这就是为什么人脸数据的每一次收集都值得认真对待，而不是随手一勾。
@kp=informed-consent
KC: 知情同意 :: 知情同意指采集或使用他人数据前，用清楚的语言告知用途、范围和保存方式，并取得真正自愿的同意，而不是靠冗长条款默认勾选。:: 生活里的例子 :: 商场装了人流统计摄像头却没贴任何告示，这就不算知情同意。
FIG: 一台自助终端屏幕上弹出两份对比文件：左边密密麻麻的百行条款上压着「已默认勾选」；右边一张三行的明白纸写着「拍这张照片只用于核验本人，用后即删」，旁边一个勾选框 :: 真正的同意看得懂、可选、可撤回——藏起来的不算数
P: 学会看同意书是数字时代的基本功。抓三个关键词：用途（拿去做什么）、范围（给谁共享）、期限（存多久、如何删除）。我国个人信息保护法明确要求「最小必要」原则——要你手机通讯录才能点外卖的应用，本身就涉嫌越界。遇到索权过度的应用，拒绝并举报都是正当选择。
CALL: 想一想 :: 为什么企业偏爱把同意条款写得又长又绕？如果法律强制要求用小学生能读懂的三句话说明数据去向，行业会发生什么变化？

S: 以假乱真的新麻烦
P: AI 不只在收集你的形象，还能凭空生成你的形象。深度伪造技术可以用几张照片合成以假乱真的视频：让一个人「说」他从没说过的话，「做」他从没做过的事。普通人肉眼几乎无法分辨，这类技术已被用于诈骗和造谣。
@kp=deepfake
KC: 深度伪造 :: 深度伪造指用生成式 AI 合成的逼真图像、语音或视频。防范它的关键不是练眼力，而是建立核实习惯：多渠道确认信息来源。:: 试一试 :: 收到亲友的借钱语音时，回拨对方常用号码核实后再行动。
P: 应对深度伪造，练眼力不如立规矩。个人层面记住两条：涉及转账等重大请求，一律换到可靠渠道当面或电话核实；不轻易在网上发布高清正脸视频和声音样本，减少被模仿的素材。社会层面，平台正在部署检测工具并为合成内容加注标识，我国也已规定 AI 生成内容需要显著标注。
P: 更值得思考的是信任问题。当「眼见为实」失效，社会的信任成本会上升。解药不是回到怀疑一切，而是建立新的验证习惯：重要信息认准权威来源、交叉比对多个渠道、对情绪煽动性极强的内容保持一分冷静。这些习惯会让你在真假难辨的时代站得稳。
P: 还有一个属于你这代人的新课题：数字形象的管理。你的脸、声音、聊天风格都在成为可被复制的数据资产。谨慎授权、少发高清正脸视频、定期检查隐私设置，这些习惯越早养成成本越低——等形象被盗用再补救，往往为时已晚。
P: 全书五章至此收官：中立是神话所以要有规矩；公平靠分组检验；透明靠有意义解释；责任靠链条追溯；隐私靠知情同意与核实习惯。五块基石拼在一起，是一张完整的思考地图——下次再看到「AI 震撼」「智能革命」的新闻，你已经知道该问哪五个问题。
CALL: 动手总结 :: 把五章各浓缩成一条「追问」（例如「这个算法对不同群体公平吗？」），写成你的《AI 五问》随身卡。

S: 全书回顾
P: 伦理听起来宏大，落点却极其具体：一次勾选、一句追问、一次不转发。技术奔涌向前，而方向盘始终应该在人手里——在懂得追问的你手里。愿这本小书给你的不是答案清单，而是一副永远在线的价值罗盘。
P: 下次当你使用任何一个 AI 产品时，试着在心里快速过一遍五问。若每个设计者都这样自问，每个使用者都这样反问，公平与责任就不再是口号，而是日常。
