T: 大事化小：拆解的艺术

S: 为什么大问题吓人
P: 「组织一次班级春游」这个任务为什么让人头大？因为它同时混杂着太多性质不同的事：要选地点、算预算、订车辆、排活动、分组管理、准备应急预案。大脑不擅长同时握住六团乱麻，但对三四个清晰的小任务游刃有余。拆解的本质，就是把「一团乱麻」变成「几根清晰的线」。|mark:拆解
@kp=decomposition-strategy
KC: 拆解策略 :: 拆解策略把大问题沿合理的边界切成若干可独立解决的小问题，逐个击破后再组装还原；切分标准比切分动作更重要。:: 生活里的例子 :: 写作文先列提纲：开头、论点一、论点二、结尾——每个小块都不再可怕。
KC: 拆解检验法 :: 合格的拆解交给别人就能直接干活：块与块不重叠、无遗漏、先后依赖清楚，最难啃的那块要标出来优先处理。:: 试一试 :: 与同学互换复习计划清单并互相挑刺。
FIG: 一棵两层树状图：顶端是「春游计划」，向下分成四枝「选地点」「做预算」「排流程」「安全预案」，每枝再分出两三个小叶片写着具体任务 :: 拆解像长树：先粗干后细枝，直到每片叶子都能一口吃掉
P: 拆解的关键不在动手切，而在找对切的维度。同样是拆春游：按时间拆（出发前、当天、返回后）是一种切法；按事务类型拆（交通、餐饮、活动、安全）是另一种。好的拆法让各块之间几乎不打架，坏的拆法会让你发现两块任务里都包含「订车」。判断标准：每块能否独立安排人独立完成？
P: 拆解还有一个隐藏福利：它让估算成为可能。春游拆成交通、餐饮、活动、安全四大块之后，每块的费用范围立刻清晰起来——大巴八百、餐费人均二十、物料三百。不拆的时候，「春游要花多少钱」是个无从下口的问题；拆完之后它变成了四道小学算术题。
P: 拆解还要拆到什么程度为止？有个实用口诀：拆到「一眼可见怎么做」为止。「联系大巴公司」还能再拆吗？可以——查电话、询价、比较、预订——但如果这些步骤对你已经一目了然，就不必再画树杈了。拆解的颗粒度因人而异：新手拆细些，老手拆粗些。
CALL: 动手练一练 :: 把「期中考试周复习」按学科拆成子任务，再把最头疼的一科拆到「一眼可见怎么做」的程度。数数你一共得到了多少片树叶。

S: 拆解的进阶技巧
P: 技巧一：先搭骨架再填肉。先列出三大块主干任务，确认没有遗漏和重复，再逐块向下细分。上来就抠细节，很容易在枝叶里迷路。技巧二：给每块标注依赖关系。「印试卷」依赖「定好题目」，它就不能排在前面。画出先后顺序，执行时才不会卡壳。
P: 技巧三：识别「最难的一块」并优先处理。每堆任务里总有一块最不确定、最可能出幺蛾子——比如春游里的「天气突变怎么办」。把它拎出来最先解决或最早启动，剩下的都是顺流而下。高手拆解完的第一眼，永远在扫描哪块骨头最难啃。
P: 检验拆解质量的终极方法：把你的拆解结果交给别人看。如果对方看完就知道自己该干什么、什么时候干、干到什么程度算完成，你的拆解就合格了；如果对方一脸茫然，说明块与块的边界还没切干净。拆解不是给自己看的仪式，而是协作的共同语言。
CALL: 动手挑战 :: 和同学互相交换各自的复习拆解清单，用三个问题互评：有遗漏吗？有重叠吗？最难啃的骨头标出来了吗？

S: 小结与预告
P: 回顾本章：拆解把乱麻变清线；找对切分维度比勤快地切更重要；拆到「一眼可见怎么做」即止；先搭骨架、标注依赖、优啃硬骨；能被他人读懂的拆解才是合格的拆解。
P: 拆开之后你会发现一个惊喜：很多小块长得一模一样，或者和以前做过的事如出一辙。认出它们，就能省下一半功夫。下一章请出第三件法宝：模式识别。
