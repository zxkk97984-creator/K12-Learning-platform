T: 程序员的超能力：什么是计算思维

S: 一个反直觉的事实
P: 观察身边的程序员朋友，你会发现一件奇怪的事：他们一天里大部分时间并不写代码，而是在纸上画图、在白板前讨论、盯着屏幕皱眉思考。真正敲键盘的时间反而有限。他们最强的武器不是编程语言，而是一种想问题的方式——计算思维。|mark:计算思维
@kp=computational-thinking
KC: 计算思维 :: 计算思维是用拆解、找规律、抓重点、定步骤的方式分析和解决问题的思考方法，它借自计算机科学，但完全不需要计算机就能使用。:: 生活里的例子 :: 整理杂乱衣柜时先分类再定摆放规则，你已经在用计算思维了。
KC: 法宝流水线 :: 四大法宝是一条流水线：拆解负责切块，找规律认出老朋友，抓重点完成瘦身，定步骤串成方案，环环相扣缺一不可。:: 试一试 :: 用四个词概括你处理一件难事的完整思路。
P: 为什么要专门学它？因为面对复杂问题时，普通人的反应常常是焦虑、拖延或者硬着头皮乱试；而有计算思维的人会自动切换到另一套流程：这个问题能拆成几块？哪些块和以前遇到过的类似？哪些细节可以忽略？步骤怎么安排？四个问题问完，行动路线自然浮现。
FIG: 左右对照：左边一个愁眉苦脸的人面前立着一堵写着「大难题」的高墙；右边同一个人把墙拆成了四块带编号的积木，正轻松搬起第一块，头顶亮着一个灯泡 :: 面对难题的两种姿势：望墙兴叹，或把它变成四块可搬运的积木
CALL: 想一想 :: 回忆最近一次让你「不知从哪下手」的任务（比如准备考试、组织活动）。如果把它拆成四块积木，会是哪四块？

S: 四大法宝总览
P: 计算思维有四大法宝。法宝一叫拆解：把大象装进冰箱的问题，先分成开门、装象、关门三步。法宝二叫找规律：发现哪些问题和以前解决过的一样，直接复用老办法。法宝三叫抓重点：忽略无关细节，只保留影响结果的关键特征。法宝四叫定步骤：把方案写成任何人都能照做的明确指令。
P: 这四大法宝从不单打独斗，它们是一条流水线：先用拆解把庞然大物切成小块，再用找规律认出哪些小块是老朋友，然后用抓重点给每块瘦身减负，最后用定步骤串成可执行的方案。本书五章就是沿着这条流水线逐站深挖。
P: 学习之前先澄清一个最常见的误会：计算思维并不等于学计算机。它的名字来源于计算机科学家总结这套方法的过程，但它处理的是一切问题——医生诊断病情、导演分镜拍摄、厨师备菜出餐，背后都是这四步的变奏。不会编程的中学生，照样能把这门思维练得出神入化。
P: 动手做个热身小实验：用一句话描述「早晨怎样确保不带漏东西」。多数人会说「仔细检查」——这不叫方法。试试四大法宝：列出常带物品清单（拆解）、发现物品按出门顺序排列就不会漏（找规律）、只列当天需要的（抓重点）、睡前把非书本类先装包（定步骤）。感受一下两种答案的差距。
CALL: 动手实践 :: 选一件你本周要做的复杂小事，试着只用四个词写出你的处理思路：怎么拆、找什么规律、留什么重点、按什么步骤。

S: 小结与预告
P: 回顾本章：计算思维是一套不依赖计算机的通用思考法；四大法宝构成从分析到执行的完整流水线；它适用于学习、生活与未来职业的一切场景——四大法宝会在后续章节逐一登场。。
P: 流水线的第一站最重要——再聪明的规律识别和方案设计，都始于一次漂亮的拆解。下一章我们深入拆解的艺术：为什么有人三下五除二就把难题切得干干净净？
