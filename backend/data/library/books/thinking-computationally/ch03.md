T: 找规律：模式识别的力量

S: 「这道题我见过！」
P: 考场上最令人安心的念头是什么？「这道题我见过。」它意味着你可以直接调用熟悉的解法，跳过大量摸索。这种认出「新问题里的老结构」的能力就是模式识别——程序员靠它避免重复造轮子，医生靠它快速判断常见病症，你靠它把一百道题的功夫压缩成十道。|mark:模式识别
@kp=pattern-recognition-thinking
KC: 模式识别 :: 模式识别是在新问题中辨认出与已知问题相同的结构或重复出现的规律，从而复用既有方法加速解决。:: 生活里的例子 :: 认出应用题「相遇问题」的结构后，不管题目换成两辆车还是两只船，解法都一样。
FIG: 左右两组卡片：左边五张表面不同的题目卡片（火车、行人、轮船），中间一道光线把它们连向同一张标着「相遇问题」的核心卡；右边同样逻辑指向「工程问题」 :: 题海无边，模式有岸：认出结构，百题归一类
P: 模式识别的第一个用武之地是消灭重复劳动。写班级值日表时发现每周一到周五的流程完全一样，只是名字不同——那就做一张通用模板，每周只改名字。会找规律的人做事是「一次加微调」，不会找的人是「每次从零开始」。一周下来，差距惊人。
P: 第二个用武之地是预测。观察三个月的数据发现「每逢下雨天教室就特别挤」，就能在雨天提前占座；发现「自己晚上十点后背单词效率最高」，就能把最难的内容排在那个时段。规律不仅告诉你「这是什么」，还预告「接下来会发生什么」——这是从被动应对到主动规划的分水岭。
CALL: 想一想 :: 你有哪些「每次都重新发明轮子」的重复劳动？试着找出其中至少一个可模板化的场景。

S: 找规律的两种手法
P: 手法一叫横向对比：把几个相似的东西摆在一起找相同点。三道让你卡壳的数学题摆一桌，圈出每题的条件类型和解法第一步——相同点浮出来的时候，你就找到了这一类题的钥匙。孤立的题看不出规律，凑成一排才看得见。
P: 手法二叫纵向追踪：盯着同一个东西随时间的变化。记录两周内自己每天的学习效率，可能发现「周一低、周三高、周五崩」的波形；追踪自己的错题本，可能发现八成错误集中在三个知识点上。时间是最诚实的放大镜，单次行为是噪声，反复出现才是信号。
P: 但要警惕假规律。只凭两次经历就断言「我早上永远背不下书」未免草率；样本太少、忽略例外的规律比没有规律更危险。健康的做法是：找到候选规律后，主动寻找反例检验它，扛得住反例轰炸的才配称为规律。这也是科学思维和道听途说的分界线。
CALL: 动手实践 :: 翻开你的错题本（或作业），横向对比找出至少两个反复出现的错误模式，并为每个模式写一条针对性的防错规则。

S: 小结与预告
P: 回顾本章：模式识别让老经验解决新问题；它能消灭重复劳动、支持提前预测；横向对比与纵向追踪是两大找规律手法；警惕小样本假规律，扛住反例检验的才算真规律。
P: 不过，就算认出了模式和规律，处理时仍可能被海量细节淹没。哪些信息必须保留？哪些可以大胆扔掉？下一章讲第三件法宝：抽象——抽象的艺术会帮你化繁为简。。
KC: 真规律三关 :: 候选的规律必须连过三道关卡才算数：支撑例子足够多而不是两次巧合、主动寻找反例轰炸之后依然成立、还能对下一次的情况做出准确预测。:: 试一试 :: 用三关检验「我周末效率高」这条自我观察是否成立。
