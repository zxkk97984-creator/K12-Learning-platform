KC: 身边的 AI :: 语音助手、拍照识花、地图导航、相册自动分类这些天天在用的功能，背后都藏着一位从例子里学会本领的 AI 小帮手。:: 生活里的例子 :: 相册能自动把照片分成「人物」「美食」「风景」，靠的就是学过海量照片的 AI。
FIG: 一张家庭场景插画：手机屏幕上语音气泡、客厅里的智能音箱、门口的扫地机器人、爸爸手机上的导航地图，每处都贴着一个放大镜标签写「AI 在这里」 :: 家里的 AI 藏宝图：四个常见据点，个个都能对上「从例子学本领」
P: 第二站：客厅。会听懂「播放一首儿歌」的智能音箱是真 AI——它听过无数人说话才学会了听懂。扫地机器人算半个：它自己规划打扫路线很聪明，但多数型号还不会「认出」地上的东西，更像按规则跑的程序。你看，同一个家里的选手也有段位差别。
P: 第三站：路上的汽车和街边的店铺。导航软件会预测哪条路堵车，因为它消化了成千上万车辆的真实路况；一些停车场抬杆自动识别车牌；部分小区门禁刷脸开门。它们都在做同一件事：从大量例子里学会辨认和预测。
CALL: 想一想 :: 为什么说「会自动感应亮灯」的楼道灯不算 AI？用「是不是从例子里学的本领」这个标准判断一下。

S: 校园里也有一只
P: 第四站可能出乎意料：学校。英语跟读软件给你的发音打分，是它听过大量标准发音后学会比较的；数学练习软件推给你「最容易错」的题，是它分析了千万份答题记录找规律；还有把作文拍照就能查出疑似抄袭的工具。学习软件是 AI 最密集的地方之一。
P: 还有一个地方天天见到却容易被忽略：购物和视频软件的推荐。你刚看完动画片，它就推更多动画片；你搜过一次球鞋，满屏都是球鞋。这背后是 AI 在分析千万用户的行为规律，猜你可能喜欢什么。猜得准是它的本事，但只看你爱看的也有小坏处——世界那么大，别被推送圈在小小的角落里。
P: 不过要提醒一句：软件里有 AI，不代表它说的全对。发音打分偶尔误伤方言口音的同学，作文查重有时冤枉原创的好句子。工具只是参考，最终判断权在你和老师手里。这个提醒先记在心里，第四章我们展开讲。
P: 找 AI 的过程也是练眼力的过程。见得多了你会发现规律：凡是需要「认出什么东西」或「猜你喜欢什么」的功能，背后多半是 AI；凡是只会按固定步骤执行的，多半是普通程序。这个判断标准简单好用，连爷爷奶奶一听就懂。
P: 现在轮到你当侦探了。任务：在接下来的一天里，找到至少三个 AI 小帮手，并回答两个问题——它帮什么忙？它可能是看什么例子学会的？把你发现的清单画成一张藏宝图，贴在书桌前。
CALL: 动手挑战 :: 和家人比赛找 AI：晚饭前各报出三个例子，谁找到的更冷门谁赢。提示：厨房、电视遥控器、购物软件都可能有惊喜。

S: 小结与预告
KC: 按规则跑的程序 :: 不是所有聪明的机器都是 AI：只会按固定规则执行的程序没有学过例子，也不会越用越聪明，楼道感应灯就是典型。:: 试一试 :: 用「有没有从例子学本领」判断家里的电器。
P: 今天你带着「从例子里学本领」这把钥匙，在家里、路上、学校各抓到了好几只 AI。世界比你以为的更智能化，也更有趣——但抓得越多，疑问也越多：那位会聊天的音箱朋友，到底是怎么听懂人话的？
P: 找了这么多 AI，最会聊天的一位还没介绍呢。下一章我们凑近观察语音助手：它听话的三段小秘密、它的聪明与迟钝，以及跟它说话的正确姿势——学会这些，它会更听你的话哦。
