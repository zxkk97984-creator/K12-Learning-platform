T: 圆圈与花朵：circle 的魔法

S: circle 的两个秘密参数
P: 画圆的命令是「t.circle(100)」，一百是半径。但这里藏着两个新手必知的秘密。秘密一：海龟画的不是「以自己为圆心的圆」，而是「圆心在自己左手边一百像素处的圆」——画完之后海龟的位置在圆的最右端。秘密二：第二个可选参数是弧度范围，「t.circle(100, 180)」只画半个圆。半圆加旋转，就是通往花世界的钥匙。|mark:circle
@kp=circle-drawing
KC: circle 画圆 :: circle(半径, 弧度) 按指定半径画圆或圆弧；半径为正时圆心在海龟左侧，负值时反向；第二个参数省略时画完整圆。:: 生活里的例子 :: 像用圆规：针脚扎在海龟左边固定距离处，笔头绕一圈。
KC: 花朵公式 :: 循环内先画一小段圆弧再旋转固定角度，弧度与次数共同决定花瓣形态：次数多弧度小花更密，反之疏朗。:: 试一试 :: 改动两个参数生成三种不同的花朵。
FIG: 两幅对照小图：左图画完整圆并标注「圆心在海龟左侧 100」；右图只画了上半段弧线，旁边标注「第二个参数 180 = 只走半圈」 :: 半径定大小，弧度定长短——两颗旋钮调出所有圆与弧

S: 花朵公式：弧加转角
P: 见证魔法的时刻。「for i in range(8):」循环里放两行：「t.circle(100, 45)」「t.left(45)」。运行！八片花瓣绕着中心绽放，一朵八角花诞生了。原理拆开看极简：每次画四十五度的小弧，再原地转四十五度换个方向接着画——八段弧首尾相接又各自外翻，花瓣自然成形。
CALL: 想一想 :: 把循环次数改成六、把弧度改成六十，还是一朵花吗？片数和每片的大小分别由哪个数字控制？动手验证你的推理。
P: 想让花朵出现在画面中央也有讲究：画每朵花之前先用抬笔加 setx、sety 把海龟送到预定坐标，再落笔开工。坐标的原点在窗口正中心，x 向右为正，y 向上为正。掌握这套定位系统后，你的画面布局就从「碰运气」升级成了「看图纸施工」。
P: 想让花朵出现在画面中央也有讲究：画每朵花之前先用抬笔加坐标跳转把海龟送到预定位置，再落笔开工。坐标的原点在窗口正中心，x 向右为正，y 向上为正。掌握这套定位系统后，你的画面布局就从「碰运气」升级成了「看图纸施工」。
P: 参数游戏正式开始。循环次数不变、弧度减半，花瓣变密变薄；半径加大，花朵整体放大；弧度超过九十会怎样？试试看——图形开始自我交叠，产生意想不到的曼陀罗效果。这里没有标准答案，只有无数种可能的组合，每一次改动都藏着新的惊喜——这正是生成艺术最迷人的魅力。

S: 曼陀罗：对称的极致
P: 把花朵玩法推到极致就得到曼陀罗。配方：多层结构，每层是一组「小图形加旋转」的循环，层与层之间换颜色、换尺寸。比如最内层八个小实心圆，中层十六根短线条，外层二十四段小弧——三层叠加，一幅对称华丽的曼陀罗就完成了。
FIG: 一幅完成的曼陀罗作品截图：中心一圈黄色小圆，中层蓝色放射线条，外层紫色相接弧线，三层同心对称；旁边代码约十几行，标注「三层嵌套循环」 :: 复杂来自简单的叠加：三段循环各管一层，秩序生出华丽
P: 写这种多层作品前先在纸上打草稿：几层？每层几个元素？什么形状？颜色怎么分配？规划五分钟，代码十分钟一气呵成。直接上手盲写的结局通常是大改三次。先设计后编码——这个习惯从画图阶段就该养成。
P: 动手完成本章作品「我的曼陀罗」：至少两层结构、两种颜色、整体对称。完成后截屏导出（绘图窗口自带截图功能即可），它将是你数字花园的核心展品之一。
CALL: 动手挑战 :: 给曼陀罗加一层「旋转的正方形」：每转四十五度画一个空心正方形，共八个。观察方形与弧线的碰撞效果。

S: 小结与预告
P: 回顾本章：circle 的圆心在海龟左侧，第二参数控制弧长；「小弧加转角」的循环是花朵公式的全部秘密；多层多色的嵌套循环能堆出曼陀罗；先草稿后编码是好习惯。
P: 单项技法全部集齐：直线、多边形、色彩、填充、圆弧、曼陀罗。最后一章，我们把它们组合成一件完整的作品——属于你的数字花园——综合运用才能创作出真正的大作品。。
