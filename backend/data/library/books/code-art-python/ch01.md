T: 你的第一支画笔：认识小海龟

S: 召唤一只听话的小海龟
P: 编程书里的代码大多变成屏幕上的文字，这一本书不一样——我们要让代码变成画。Python 自带一位画师，名叫小海龟（turtle）：你写指令指挥它前进、转弯，它爬过的地方就留下笔迹。这个工具上世纪六十年代就诞生了，专门为初学者设计，五十多年来一直是无数程序员的艺术启蒙。
P: 打开 Python 环境，输入三行代码召唤它：「import turtle」请出模块；「t = turtle.Turtle()」造出一只小海龟，起名叫 t；「t.forward(100)」让它向前爬一百步。运行！一个窗口弹出来，一条横线出现在屏幕中央——恭喜，你的第一幅数字作品完成了。|mark:turtle
@kp=turtle-graphics
KC: 海龟画图 :: 海龟画图是 Python 内置的绘图工具：屏幕上有一只带方向的小海龟，用前进和转弯指令指挥它爬行，爬过的路径就是画出的线条。:: 生活里的例子 :: 像在纸上推一辆只进不退的玩具车：车头朝哪、走多远，全听你的口令。
FIG: 一个绘图窗口截图：中央一只小箭头形状的海龟，身后拖着一条一百像素的水平直线；右侧代码框列出三行命令与注释「导入 / 造海龟 / 向前走」 :: 三行代码的第一幅作品：海龟走过的路，就是你画的线
P: 只有前进太单调，第二招是转弯。「t.left(90)」让海龟原地左转九十度，「t.right(90)」右转。方向感小贴士：海龟默认头朝右，左转是逆时针，右转是顺时针。转完再前进，笔迹就拐弯了——前进加转弯，这两招组合起来能画出任何由直线构成的图形。
CALL: 想一想 :: 「forward(100)、left(90)、forward(100)」跑完之后，海龟的朝向和位置分别发生了什么变化？先在脑中演一遍再看结果。

S: 用两招画出字母
P: 来画一个字母 L：前进一百、左转九十、前进五十，三行搞定。再挑战字母 T：先画横线（前进一百），抬笔回到起点——这里需要新知识：penup 让海龟悬空移动不留痕，pendown 落回纸面继续画。移动回起点后右转九十、前进五十画出竖线。一个 T 字完成！
@kp=pen-control
KC: 画笔控制 :: penup 抬起画笔让海龟移动时不留痕迹，pendown 放下画笔恢复画画状态；两者配合就能在画面任意位置自由起笔构图。:: 试一试 :: 抬笔前进五十再落笔，观察画面中间出现的空白段。
P: 小海龟还有几个贴心设置值得认识：speed 命令能让它以最快速度移动，零代表最快而不是停止；shape 命令可以把箭头图标换成真正的小海龟模样；画完后用隐藏命令收起海龟本体，作品会更干净。这些设置不影响笔迹，却让创作体验顺手不少。
P: 抬笔落笔看似不起眼，却是构图的核心技巧：没有它，所有线条都会连成一团乱麻；有了它，你可以自由地在画面任何位置起笔。试着画两个分开的正方形，你就必须用到这对搭档——中间的空格正是靠抬笔飞过去的。
P: 遇到画错的时候不用慌，两个补救键送给你：运行前可以用「t.clear()」清空画面但保留海龟位置，用「t.reset()」则连位置一起重置。另外绘图窗口如果不小心关了，重新运行一遍代码就能再开一个——代码在，作品随时可以重现，这正是数字创作的独特优势。
P: 动手创作第一幅命题作品：用前进、转弯、抬笔、落笔四招，画出你的姓名首字母。要求笔画连贯、大小合适。完成后截图保存——这是你的数字签名，第五章的花园作品里会用到它。
CALL: 动手挑战 :: 只用前进和左右转，画出一个「Z」字。提示：它的笔画顺序里藏着一次不需要抬笔的转折。

S: 小结与预告
P: 回顾本章：三行代码召唤海龟画师；前进与转弯是全部直线绘画的基础；抬笔落笔负责移形换位；你已经能用它们拼出自己的签名——这四招就是直线绘画的全部基础功。。
P: 不过你可能已经发现：画正方形要写八行重复代码，画八边形要十六行——手都要断了。程序员对重复劳动零容忍，下一章请出编程最强的偷懒神器：循环。
