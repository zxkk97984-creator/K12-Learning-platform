T: 正方形与多边形：循环画画

S: 重复的东西交给循环
P: 画正方形的代码是四段一模一样的结构：前进一百、左转九十，重复四次。手写八行又长又容易错。程序员的解法你早已见过——for 循环：「for i in range(4):」后面缩进两行「t.forward(100)」「t.left(90)」。八行变三行，画出来的正方形分毫不差。|mark:循环
P: 更妙的发现藏在角度里。为什么是九十度？想象沿着正方形边缘走一圈回到起点、面朝原方向——你总共转了三百六十度。四个角每个转九十，四九三百六。推广到任意正多边形：每次转的角度等于三百六十除以边数。这个「外角和」规律让循环变得万能。|mark:外角

KC: 多边形外角 :: 画正多边形时每步转弯的外角等于三百六十度除以边数；把边数换进 range 和除式，一个循环模板通吃所有正多边形。:: 试一试 :: 把边数改成 6 跑一次，再改成 12，观察图形越来越像圆。
KC: 外角和秘密 :: 沿多边形边缘走一圈共转三百六十度；边数越多每步转角越小，三十六边形已经酷似圆——极限思想的第一次触摸。:: 试一试 :: 依次画出三、六、十二、三十六边形并截图对比。
FIG: 三幅并列小图：正三角形内标注「转 120 度」、正方形标注「转 90 度」、正十二边形几乎成圆标「转 30 度」，下方一条公式带写着「外角 = 360° ÷ 边数」 :: 一个循环走天下：改两个数字，三角形秒变近似圆
P: 动手玩一把参数游戏。写好多边形模板后依次把边数设为 3、5、6、12、36 并分别运行截图。你会亲眼见证多边形向圆的进化——顺便理解了为什么圆可以看成无数条边的正多边形。数学课上的极限思想，就这样被你用代码摸到了。
CALL: 想一想 :: 边数改成 5 时画出的五边形方向有点歪（尖角不朝上），怎么让它摆正？提示：动笔之前先给海龟一个初始转向。

S: 星星与更狂野的玩法
P: 五角星是循环的经典彩蛋。画五角星每次转的不是七十二度而是一百四十四度——因为笔迹要跨越到对面顶点。「for i in range(5): 前进两百、右转一百四十四」，一颗标准五角星跃然屏上。试着把转角换成其他数字会收获大量奇形怪状：这就是著名的「天使魔鬼曲线」玩具，转角不同，图案天差地别。
P: 用循环画画时还有一个实用小技巧：画完一个图形后让海龟先抬笔、平移一段距离、再落笔，就能在同一幅画里摆出多个图形。位置参数可以自己随便定，也可以按规律递增——比如每个图形向右挪一百五十步，一行排开特别整齐。
P: 循环里还能套循环。比如先画一个小三角形，抬笔平移一段，再画下一个——外层循环控制位置，内层循环画图形。一行行代码不多，画面立刻丰富起来。嵌套循环是编程世界的万花筒，第四章的花朵全靠它。
P: 动手创作一幅「多边形烟花」：在画面不同位置画七八个大小颜色各异的正多边形。允许抄自己的旧代码改参数——程序员的美德就是复用。完成后你会拥有一面谁也猜不到是用几行循环画出来的作品墙。
CALL: 动手挑战 :: 把五角星的转角从一百四十四改成一百六十和一百二十，各跑一次。三个图形分别像什么？记录你的发现。
