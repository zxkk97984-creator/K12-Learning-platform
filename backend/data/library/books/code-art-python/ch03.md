T: 彩色世界：颜色与填充

S: 换一支彩笔
P: 黑白世界要变天了。给海龟换颜色的命令是「t.color("red")」——引号里填英文颜色名，red、blue、gold、hotpink 都认得。想更精细可以用数字写法「t.color(255, 0, 0)」，三个数分别代表红绿蓝的分量，零到二百五十五任调。想只改线条色还有专门的「t.pencolor("blue")」。画笔粗细用「t.pensize(5)」调节，数字越大线越粗。|mark:pencolor
P: 动手做一道彩虹实验：七种颜色各画一段弧或一条线并排摆开。用列表存七个颜色名，循环取出依次换色——「for c in ["red", "orange", "yellow", "green", "cyan", "blue", "purple"]:」。这个练习顺便复习了第二章的循环：循环不但能重复动作，还能轮流取值。
FIG: 一条由七段彩色弧线拼成的彩虹横跨画面，每段弧下方标注对应的英文颜色名；旁边代码框显示颜色列表与 for 循环两行代码 :: 列表加循环等于调色盘：七色彩虹只需几行代码

S: 油漆桶的正确用法
@kp=color-fill
KC: 填充上色 :: 在开始绘制封闭图形之前调用 begin_fill 开启填充模式，图形画完后再调用 end_fill 结束，内部就会被涂满指定颜色；起止之间必须构成封闭路径。:: 试一试 :: 画一个红色轮廓、黄色内芯的正方形，体会两种颜色的分工。
KC: 配色三分寸 :: 深色背景配浅色线条画面才够清晰，邻近色搭配显得和谐而对比色组合更加醒目，一幅作品的颜色控制在三种以内通常最耐看。:: 试一试 :: 同一个图形用三组配色各画一遍比较观感。
P: 填充有三条纪律必须遵守。第一，begin_fill 和 end_fill 必须成对出现，只开不关等于没关油漆桶盖子，什么都不会发生。第二，中间的图形必须封闭——抬笔跳走再落笔画别的，填充区域就乱了。第三，轮廓色和填充色可以不同：「t.pencolor("red")」管边，「t.fillcolor("yellow")」管芯。
P: 填充最常见的翻车现场是「图形没封闭」：如果 begin_fill 和 end_fill 之间的路径没有回到起点，填充区域就会以奇怪的方式补全，有时甚至涂满半个屏幕。遇到这种情况先检查路径是否闭合，再检查两条填充命令是否真的成对出现。
P: 填充色和背景色的配合也值得花心思：深蓝背景配亮黄填充的星星非常出彩，白底上则适合柔和的浅色系。改背景色要用屏幕对象的 bgcolor 方法，而且要写在创建海龟之前才生效。

P: 完整流程示范一个上色正方形：设置边框红、填充黄，「t.begin_fill()」开启，循环四次前进加转弯，最后「t.end_fill()」收尾。运行的一瞬间黄色灌进方框的体验相当解压。把这段封装成「画彩色正方形」的小函数后，你就能批量生产彩色积木了。
CALL: 想一想 :: 如果 begin_fill 之后先抬笔移动到别处再画图形，填充会变成什么样？动手验证你的猜想。

S: 配色的品味
P: 技术到位后聊聊配色品味，三个实用建议送给你。第一，深底浅字浅底深字：背景用深蓝时线条选亮黄或白色，对比才清晰——改背景的命令是屏幕对象的 bgcolor。第二，邻近色和谐、对比色醒目：橙黄搭配温柔舒适，蓝橙相撞活力四射，按情绪需求选。第三，克制：一幅作品三种颜色以内通常最耐看，彩虹虽美，遍地都是就俗了。
P: 动手升级旧作：把第二章的多边形烟花全部上色，要求相邻图形颜色不同、整体不超过四种颜色。完成后把新旧两张图并排截图——你会直观感受到色彩的表达力，也会第一次以「作品」而非「作业」的眼光看待自己的代码。
CALL: 动手挑战 :: 用任意三种颜色画出「红绿灯」：三个纵向排列的实心圆形，分别是红、黄、绿。提示：圆形怎么画？下一章马上揭晓——现阶段可以先用实心六边形近似代替，效果也很可爱。

S: 小结与预告
P: 回顾本章：color 换色、pensize 调粗细、RGB 数字可精调；填充三纪律为成对开关、路径封闭、边芯分色；配色三分寸是对比清晰、情绪匹配、数量克制——这些纪律与品味会让作品更上一层楼。。
