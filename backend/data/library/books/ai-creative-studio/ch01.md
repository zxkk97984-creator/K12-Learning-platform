T: 创意工作流的变化：生成式 AI 能做什么

S: 一间开进电脑里的工作室
P: 过去组建一个创意团队需要文案、插画师、配音员、剪辑师各司其职；今天打开电脑，一个学生也能调集一支「AI 创意小队」：文字模型写脚本，文生图模型出插画，语音模型配旁白。这就是生成式人工智能带来的变化——创作的门槛在降低，创意的产能被放大。|mark:生成式人工智能
@kp=generative-ai-overview
KC: 生成式人工智能概览 :: 生成式人工智能指能依据学习到的规律创作新内容的模型家族：写文章、画插图、作曲、配音、剪视频都属于它的射程。:: 生活里的例子 :: 输入一段描述就能得到一幅画——它不是检索现成的图片，而是现场「画」出来的。
FIG: 一个环形工作台插画：中央坐着创作者，四周四个工位分别标着「文案」「插画」「配音」「剪辑」，每个工位上有一只机械臂与创作者协作，产出汇入中央的成品框 :: 人机共创的工作室：你负责创意与判断，AI 负责加速执行
P: 但能力地图必须画清边界。文字模型的强项是组织语言：润色、扩写、总结、翻译、头脑风暴样样精通；弱项是事实可靠性，编造细节的毛病至今未根除。图像模型擅长风格化视觉：海报草图、概念设定又快又多；弱项是精确控制——想让它画出「左手拿着特定形状钥匙的角色」，常常不听指挥。
P: 音频与视频介于两者之间。语音合成已经以假乱真，配音和有声书效率飞起；但唱歌的情感表达仍显机械。视频生成发展最快也最不成熟：几秒钟的片段惊艳四座，长片的一致性（角色长相前后统一）还是难题。给每项技术标好成熟度，才不会抱有过高期待。
CALL: 想一想 :: 你最想用 AI 解放的创意环节是什么？对照上面的能力边界，判断它现在处于「成熟可用」「部分可用」还是「仍在进化」的哪一档。

S: 工作流的正确姿势
P: 高效的人机协作有一条经验法则：人负责方向与判断，AI 负责执行与变体。以做一张班级晚会海报为例：你定主题、情绪和信息层级（人的创意决策），让图像模型生成五版草稿（机器的批量执行），从中挑一版提修改意见再迭代两轮（人的审美把关），最后手工调整文字排版（精细活交给自己）。全程你可能十分钟搞定过去半天的活。
P: 注意这个流程里人类始终握着三样东西：品味（哪个版本好）、意图（要表达什么）、责任（发布前核对无误）。AI 是史上最快的执行者，但方向感和责任感无法外包——这两样恰恰是创意工作者真正的护城河。
P: 动手盘点一次真实需求。选一个你近期要做的东西（手抄报、演讲稿、视频作业），把它拆成环节清单，逐项标注「自己做」「AI 辅助」「AI 主力」三个等级，并说明理由。这张表就是你个人的 AI 工作流设计稿。
KC: 人机分工三原则 :: 人机协作中人要始终握住三样东西：品味（判断好坏）、意图（表达什么）、责任（发布前核对）；执行与变体可以外包，方向感与责任感不行。:: 试一试 :: 回顾一次你用 AI 的经历，标注哪些环节是人的贡献。
CALL: 动手实践 :: 用「AI 出三版草稿加人工挑选迭代」的方式完成一件小作品，记录总耗时并与纯手工方式对比。

S: 小结与预告
P: 回顾本章：生成式 AI 覆盖文字、图像、音频、视频四大创作域，各有明确的强项与短板；正确的工作流是人管方向和责任、AI 管执行和变体；为每项任务标注自动化等级，是新时代创作者的基本功。
P: 想驾驭这支创意小队，得先懂它们的心。下一章钻进文字模型的引擎室：那个「接龙」的本质之上，还叠着什么关键工艺——这一点值得每位学习者牢记在心。。
