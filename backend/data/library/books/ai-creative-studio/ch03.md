T: 文生图的魔法：从噪声到图像

S: 从一团雪花点开始
P: 打开文生图工具，输入「夕阳下的海边小镇，水彩风格」，二十秒后一幅画出现。它从哪来？答案出人意料：从一团纯粹的电视雪花噪声里来。生成图像的过程，本质是一场精心引导的「去噪之旅」。|mark:文生图
@kp=diffusion-intuition
KC: 扩散模型直觉 :: 扩散模型先学习给图片逐步添加噪声，再反过来学会每一步如何去除一点噪声；生成时从纯噪声出发，在文字引导下逐步「雕刻」出清晰图像。:: 生活里的例子 :: 像大理石雕像：米开朗基罗说他只是把多余的石头去掉——模型去掉的就是一层层噪声。
FIG: 从左到右五格连续图：第一格全是杂乱雪花噪点，第二格隐约浮现色块轮廓，第三格能看出海平线与房屋剪影，第四格细节渐显，第五格是完全清晰的夕阳小镇水彩画；下方标注「约二十步去噪」 :: 文生图就是雕刻：从混沌到清晰，一步一层皮
P: 训练过程分两幕。第一幕学加噪：把百万张真实照片逐步掺入随机噪声，直到变成纯雪花点——这一步教会模型「噪声是怎么长出来的」。第二幕学去噪：让模型观察「加了轻度噪声的图和原图的差别」，学会预测并移除那一点点噪声。两幕练熟后倒过来演：从纯噪声开始，一步一步减噪，画面就从混沌中浮现。
P: 你的文字提示词在这场去噪中扮演导演。每个去噪步骤都会参考提示词决定方向：是往「海边」靠还是往「雪山」靠？是水彩笔触还是油画质感？文字被编码成对去噪方向的持续牵引力——这就是为什么描述越具体，结果越贴合想象。
CALL: 想一想 :: 为什么同一段提示词每次生成的画都不一样？提示：回忆去噪的起点是什么，以及起点不同会导致什么。

S: 进阶控制：让画面听话
P: 基础提示之外还有几层精细控制。负面提示词：「不要出现文字、不要多余的手指」——明确列出不想看到的元素，出图质量立刻提升。参数调节：引导强度决定模型多严格地遵循你的文字（太高僵硬死板，太低自由发挥），步数决定去噪的精细程度。局部重绘：只重画画面某一区域而保留其余部分，适合微调细节。
P: 风格的一致性是进阶课题。想保持同一角色的形象跨图一致，可以用参考图功能：上传一张基准图，让新图沿用其画风或人物特征。商业插画师正是靠这些控制技术，才能用 AI 完成需要前后连贯的成套作品——绘本里的主角不能每页换一张脸。
CALL: 动手实验 :: 同一提示词分别配「高引导强度」和「低引导强度」各生成三张图，对比哪组更贴合文字、哪组更有意外创意，找到你的偏好平衡点。

S: 能力的边界与责任
P: 生成图像的能力边界要心里有数：手部和细小文字仍是经典翻车区（六根手指、乱码招牌）；空间关系容易混乱（「桌上放杯子和椅子旁边」可能摆错位）；事实性内容不可靠（让它画埃菲尔铁塔没问题，画「2024 年某天的具体新闻现场」就是在编造）。涉及真实人物、事件、场所的图像，务必标注为 AI 生成。
P: 还有一层创作伦理：训练数据的来源争议。模型的绘画能力学自人类艺术家数以亿计的作品，不少创作者认为未经许可的使用构成侵权，相关诉讼在全球进行中。作为使用者，至少做到两点：不生成模仿在世艺术家签名风格的商用作品；不把 AI 图冒充为纯手工创作参与评比。
P: 动手完成一次完整的文生图创作：确定主题后写第一版提示词，生成四张评估短板，加入负面提示词与参数调整再迭代两轮，选出最佳作品并在角落标注「AI 生成」。保存全部版本的提示词——它们是你视觉创作的配方档案。
KC: 负面提示词 :: 负面提示词明确列出不想出现的元素（如多余的手指、模糊文字、水印），是提升文生图质量最快的精细控制手段。:: 试一试 :: 同一提示词加与不加负面提示词各生成一次，对比差异。
CALL: 动手挑战 :: 挑战一个精确控制任务：生成「一只左手拿着红色雨伞的猫」，测试当前模型对手性和物体关系的理解极限。

S: 小结与预告
P: 回顾本章：扩散模型先学加噪再学去噪，生成即从纯噪声开始的引导式雕刻；提示词是方向导演，负面提示词与参数是精细旋钮；能力边界在手部、文字、事实场景；使用伦理要求标注来源、尊重艺术家。
P: 创作完成之后，一个更棘手的问题浮出水面：这幅画算谁的作品？能用吗？要署名吗？下一章进入版权的迷雾地带——这个细节常常被初学者忽略——参数与风格的组合实验，是文生图进阶的必修课。
