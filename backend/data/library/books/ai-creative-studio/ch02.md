T: 文生文的进阶直觉：从接龙到对齐

S: 接龙只是半程
P: 你已经知道语言模型的本职是预测下一个词。但纯接龙训练出来的模型有个毛病：它像一台复读互联网的机器——你说什么它顺着说，包括偏见、胡话和攻击性言论。让它变成今天这个「有礼貌、听指令」的助手，还需要一道关键工序：对齐。
P: 对齐分两道工序。第一道叫监督微调：人类写出大量高质量的问答示范，教模型「用户这样问时，理想的回答长这样」。第二道更进一步，叫人类反馈强化学习：让模型对同一问题生成多个答案，人类标注员按好坏排序，模型从这些偏好中学会追求更有帮助、更诚实、更无害的回答。
FIG: 一条流水线两道工序：上半段是「预训练」——海量书籍报纸流入模型，产出一位博学但口无遮拦的学徒；下半段是「对齐」——人类举着好差评分牌反复校准，产出一位既博学又懂规矩的助手 :: 预训练给学问，对齐教养养：今天的 AI 助手是两道工序的合体
CALL: 想一想 :: 为什么「人类觉得哪个回答好」这件事本身可能带来新问题？如果标注员的偏好有偏差，会对模型造成什么影响？

S: 上下文学习：不用重新训练的进步
P: 进阶使用者还要理解一个现象：上下文学习。你在对话里给出几个示例（还记得少样本示例吗），模型不经过任何重新训练就能立刻模仿其格式与风格继续任务——因为它把当前对话窗口里的所有内容都当作参考材料。这就是为什么同一个模型对不同人会表现迥异：会写提示词的人等于临时给模型上了一堂课。
P: 由此也推出一个重要限制：模型的记忆只限于当前对话窗口。关掉对话再开新的，之前的一切约定清零；对话太长超出窗口容量，最早的内容会被「挤出记忆」。所以重要约定（格式要求、角色设定）要么在每轮重复强调，要么放进系统提示里长期生效。
@kp=multimodal-generation
KC: 多模态生成 :: 多模态生成指同一模型能跨形式工作：看懂图片回答问题、按文字描述作画、把文字转成语音，形式之间可以互相转换与组合。:: 试一试 :: 给一张手绘草图让模型补全成完整场景，观察它如何理解你的线条意图。

S: 多模态：文字之外的创作力
P: 最新一代模型普遍具备多模态能力：不仅能读文字还能看图、听声，输出也不局限于文字。这对创作者意味着全新的工作流——拍一张白板上的草图，让模型整理成结构化笔记；哼一段旋律描述想要的氛围，请它推荐配乐方向；甚至对着一张旧照片提问年代细节。
P: 但多模态也放大了风险面：图像可能被误读、语音可以被克隆、视频可以被合成。能力越强，使用者的判断责任越重。这也是本书后面两章的主题——先搞清楚版权归属，再练辨别之眼。
P: 动手体验一次多模态协作：拍一张你的手绘或实物布局图，请模型描述它的结构并提出改进建议，评估它「看懂」了几成、误解了什么。多模态的能力边界，亲手测过才有数。
KC: 上下文学习 :: 在对话中给出示范或约定，模型无需重新训练就能即时模仿其格式与风格继续任务；但记忆只限当前对话窗口。:: 试一试 :: 在同一对话里先约定格式再提问，对比新开对话的效果差异。
CALL: 动手实践 :: 设计一个「文字加图片」的组合提示完成一个创意小任务，记录哪种信息用文字表达更准、哪种用图片更高效。

S: 小结与预告
P: 回顾本章：预训练给模型学问，对齐给它教养；上下文学习让示范即训练，但也带来记忆窗口的限制；多模态扩展了输入输出的形式，同时放大了使用者的判断责任。
P: 文字的原理清楚了，视觉创作的引擎还没打开。文生图模型是怎么凭一句话画出一张画的？下一章用一个雕塑类比讲透扩散模型——理解了它，后面的学习会顺畅许多。。
