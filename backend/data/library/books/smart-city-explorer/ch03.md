T: 红绿灯的大脑：交通如何被优化

S: 固定配时的时代结束了
P: 老式红绿灯的配时是出厂前定死的：南北向三十秒、东西向三十秒，一年四季不变。可车流是变化的——早高峰南北向挤爆、深夜空无一车还在傻等。智能交通系统的做法是让信号灯「看」实时车流：地磁和摄像头统计各方向排队车辆数，算法动态调整绿灯时长，车多的方向多给时间。

KC: 交通优化 :: 交通优化通过实时采集路口车流数据，动态调整信号灯的绿灯配时与相邻路口的联动节奏，减少全路网的等待时间。:: 生活里的例子 :: 家长分糖果：哪边孩子多就多分一点，而不是永远对半切。
KC: 绿波带 :: 绿波带把主干道上相邻红绿灯联动：以建议车速行驶，到达每个路口恰好赶上绿灯，像被绿色波浪推着前进。:: 试一试 :: 观察你家附近主干道是否常遇一路绿灯。

P: 绿波带的设计还要考虑不同车辆的差异：公交车速度慢、小轿车快、电动车灵活但不可预测。先进的系统会给不同类型的车计算不同的绿波速度建议，通过导航软件分别推送——同一条路，公交车和私家车收到的最优速度建议并不相同。

S: 绿波带：一路绿灯的秘密
P: 更高级的操作叫绿波带：把一条主干道上相邻几个红绿灯联动起来。以常见车速行驶，到达每个路口时恰好赶上绿灯——就像一波绿色的浪推着你前进。实现原理是协调计算：给定路段距离和建议车速，反推出各路口的绿灯启动时刻差。
P: 不过绿波带有适用条件：车速必须接近设计值。骑得太快或太慢都会「脱波」。这也解释了一个生活现象：为什么有的城市鼓励主干道保持特定车速——不是限速，而是在邀请你加入这趟绿色波浪。
CALL: 动手实验 :: 观察你家附近一条主干道，记录连过三四个路口是否常遇绿灯；如果总遇红灯，猜猜是车速不匹配还是该路段没有设置绿波带？

S: 治堵的组合拳
P: 红绿灯只是组合拳之一。完整的智慧交通还包括：潮汐车道（早高峰多留进城方向的车道，晚高峰反转）、公交优先（公交车接近路口时延长绿灯）、违章与事故的自动识别快速处理、以及面向市民的实时路况推送——让你出发前就能绕开拥堵点。
P: 这些措施共同依赖第二章的传感器数据。数据越全，决策越准：只看一个路口是「局部最优」，可能把拥堵推到下一个路口；把整片区域的数据放在一起算才是「全局最优」。智慧交通的进化史，就是从管理单个路口到统筹整个路网的视野升级史。
P: 动手做一次小型交通分析：选你上学路上的两个连续红绿灯路口，记录一周内每天在两个路口的等待秒数。分析数据回答：哪个路口更堵？两个路口的拥堵有没有关联？你的建议是什么？
CALL: 动手实践 :: 把你的分析结果整理成三条给交通管理部门的建议，想象自己是城市交通顾问——数据支持的建议才最有说服力。

P: 交通优化还有一个前沿方向叫车路协同：路侧设备把红绿灯倒计时、前方事故等信息实时推送给车载终端，车辆据此提前调整速度。当足够多的车辆接入系统后，整个交通流就像被一只无形的手指挥着，从无序竞争变成有序合唱。

S: 小结与预告
P: 回顾本章：智能信号灯按实时车流动态配时；绿波带靠相邻路口联动实现一路绿灯；潮汐车道、公交优先等组合拳共同治堵；全局数据的视野决定优化的上限。
P: 交通只是城市的一个侧面。水、电、空气这些看不见的城市命脉，同样被数据网络日夜守护。下一章我们看城市的体检报告是怎么生成的——数据越全，决策才越准。
