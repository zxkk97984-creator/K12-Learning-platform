T: 城市也会思考：什么是智慧城市

P: 智慧城市并不是未来概念——它已经在你身边运转。你刷交通卡坐公交、用手机扫码骑共享单车、在路灯下等红灯变绿，每一个动作背后都有数据在流动。只是这些技术太安静了，安静到你从未注意到它们的存在。这本书要做的，就是让这些看不见的系统显形。

S: 一天中的两次奇迹
P: 早晨七点半，你发现上学路上那个天天堵车的路口今天格外顺畅；深夜十一点，一盏路灯在你走近时自动亮起。这两件小事背后藏着同一个秘密：城市正在学会「感知」和「思考」。能感知环境、分析数据、自动做出决策的城市，就叫智慧城市。

KC: 智慧城市 :: 智慧城市用遍布各处的传感器收集城市运行数据，再用数据分析帮助管理者做出更聪明的决策，让生活更便利、资源更节约。:: 生活里的例子 :: 就像给城市装上了眼睛、大脑和手脚：眼睛看路况，大脑做判断，手脚调红绿灯。
KC: 三大目标 :: 智慧城市的三条衡量标准：让市民生活更便利、让资源利用更高效、让公共决策更加科学有据。凡是不能对准这三条的智能项目，都值得打个问号。:: 试一试 :: 用三条标准给一个你见过的智能设备打分。
P: 智慧城市的运行遵循一个简单循环：感知——用传感器收集数据；分析——用软件找出规律和问题；行动——自动或由人做出调整；然后再感知调整后的效果，循环往复。红绿灯根据车流自动配时、路灯按人流亮度调节、垃圾桶满了自动通知清运，全是这个循环的具体表现。

CALL: 想一想 :: 你还能想到哪些「自动做出调整」的城市设施？它们分别对应循环里的哪个环节？
P: 有个问题值得先想清楚：智慧城市到底是为了什么？答案不是炫酷的大屏，也不是更多的摄像头，而是三件朴素的事：让市民生活更便利（少排队、少等待）、让资源利用更高效（省电省水省时间）、让决策更科学（凭数据而不是拍脑袋）。记住这三条标准，就能分辨真智慧与假把式。
P: 还要澄清一个误区：智慧城市不等于到处装屏幕和摄像头。设备只是工具，数据流通与使用规则才是灵魂。一座只有硬件没有数据共享机制的城市，就像有一流球员却没有传球的球队——装备豪华，踢不出配合。

P: 想象一座只有硬件没有数据共享机制的城市：就像有一流球员却没有传球的球队——装备豪华，踢不出配合。设备只是工具，数据流通与使用规则才是灵魂，这条标准将贯穿我们接下来的每一站探索。
S: 小结与预告
P: 回顾本章：智慧城市靠感知、分析、行动的循环运转；它的目标是便利、高效、科学决策；设备是工具，数据流通才是灵魂——多观察一次，理解就深一层——智慧城市的每一个细节，都在这个循环里运转。
P: 循环的第一步是感知，而感知靠的是遍布全城的无数双「眼睛」和「耳朵」。它们藏在哪里？长什么样？下一章我们一起去把它们找出来——多观察一次，理解就深一层。
CALL: 下一章预告 :: 城市寻宝游戏 · 十字路口、公交站台、公园灯杆——传感器就藏在你看惯的地方。
P: 从传感器读数到实际行动，中间有一套标准流程：数据超标触发预警，平台自动分析来源方向，管理部门据此采取针对性措施，措施生效后数据回落形成闭环。这套流程最考验智慧的是阈值的设定——什么数值算正常、多少必须行动？定得太灵敏天天狼来了，太迟钝出了事才发现。
