T: 当数据库泄露时

S: 一封突如其来的短信
P: 设想这个场景：某个购物平台遭黑客攻击，几千万条用户记录被拖走——姓名、手机号、收货地址、消费记录一应俱全。两周后，你接到一通电话：「您好，我是该平台的客服，您上周买的商品有质量问题，我们给您办理三倍赔偿，请提供银行卡号……」对方连你买过什么都一清二楚。这不是巧合，这是一场数据泄露之后的精准诈骗。|mark:数据泄露
@kp=data-breach
KC: 数据泄露 :: 数据泄露指平台的数据库被窃取或误公开。泄露的信息会被用于精准诈骗、撞库登录和冒名注册，危害会持续很多年。:: 生活里的例子 :: 小区门禁名单丢了，冒充物业的骗子就能准确报出每户的门牌。
FIG: 一条时间线：数据库被攻破（第一天）→ 数据流入黑市（数周内）→ 精准诈骗电话开始（随后数月）→ 受害者陆续报警；时间线下方标注「泄露的影响以年为单位」 :: 泄露不是一次事件，而是长达数年的余震

S: 为什么密码泄露是连锁灾难的开端
P: 泄露信息里最值钱的是「账号加密码」组合。还记得第一章的连锁反应吗？多数人多个网站用同一个密码，坏人在一家网站得手后，会拿这套组合去批量尝试邮箱、社交账号、支付工具——这叫撞库攻击。一次泄露，全军覆没，说的就是这种场景。
P: 应对撞库有两道现成的防线。第一道：不同网站不同密码，从根上切断连锁（配合密码管理工具使用毫无负担）。第二道：给重要账户全部开启两步验证，就算密码泄露，没有你的手机也进不去。这两道防线在网络安全那本书里都练过，这里是它们真正发光的地方。
CALL: 想一想 :: 如果只能保住一样东西：所有网站的独立密码，或者重要账户的两步验证，你会选哪个？两者结合又是什么效果？

S: 事前预防与事后应对
P: 事前预防清单：注册不同的网站用不同的别名邮箱；能不填的真实信息就不填（收货人可以填化名）；定期检查账号异地登录提醒；关注官方渠道的安全公告。这些动作单看都不起眼，累积起来就是一道过滤网——让泄露的数据里属于你的部分尽量少、价值尽量低。
P: 万一确认自己中招（收到官方泄露通知或发现账号异常），按四步走。第一步改密码：先改泄露平台，再改所有共用此密码的平台。第二步查两步验证：没开的立刻开。第三步提高警惕：接下来几个月对自称客服的电话短信保持戒备，任何索要验证码的都是骗子。第四步留证据：如果遭遇实际损失，截图保存并报警。
P: 动手完成一次泄露应急演习。和家人一起假设「某购物平台泄露了两亿条记录」，逐项过一遍四步应对流程，再检查一遍全家人的密码是否重复、重要账户是否开启两步验证。演习一次的记忆深度，胜过听十遍道理。
KC: 撞库攻击 :: 拿泄露的「账号加密码」组合去批量尝试其他网站的攻击叫撞库；独立密码与两步验证是对抗它的两道核心防线。:: 试一试 :: 检查你的重要账户是否全部开启了两步验证。
CALL: 动手实践 :: 用「是否出现过泄露」查询服务（如相关安全网站提供的泄露检查工具）检查自己的常用邮箱，根据结果执行对应的加固措施。

S: 小结与预告
P: 回顾本章：泄露的危害以年为单位延续，精准诈骗是其主要变现方式；密码复用是连锁灾难的引信，独立密码加两步验证是最强防线；事前预防清单加事后四步应对，构成完整闭环。
