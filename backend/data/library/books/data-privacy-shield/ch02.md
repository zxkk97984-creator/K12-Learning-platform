T: 千人千面：个性化广告的原理

S: 一双刚看过的球鞋
P: 昨晚你在一个购物网站看了双球鞋没买，今天打开新闻客户端，第一条广告正是那款球鞋；换到社交平台，又是它的影子。是巧合吗？不是。这是个性化广告的定向投放：广告主指定「把广告给最近看过球鞋的人」，平台从画像库中筛出你，精准送达。|mark:个性化广告
@kp=personalized-ads
KC: 个性化广告 :: 个性化广告依据用户画像推测兴趣与需求，把特定广告投给最可能点击的人群，其精准度来自对行为数据的持续分析。:: 生活里的例子 :: 报纸广告人人都一样，互联网广告却是每人一份的私人订制。
P: 整条流水线分四步。第一步采集：浏览记录、搜索词、位置、停留时长被记录成原始数据。第二步打标：分析程序给你贴上标签——运动爱好者、数码关注者、价格敏感型，一个用户身上常挂着几十上百个标签。第三步匹配：广告主描述目标人群（如十八到二十五岁、关注球鞋、一线城市），系统从标签库里筛出匹配名单。第四步竞价展示：多个广告主争夺你的屏幕，价高且相关者得。
FIG: 四节车厢组成的列车：第一节「采集」装满点击与定位图标，第二节「打标」贴满兴趣标签贴纸，第三节「匹配」是广告主举着人群要求牌，第四节「竞价展示」亮出最终那条球鞋广告 :: 你看到的那条广告，坐了四站才到你面前

S: 它聪明，但也会犯傻
P: 个性化广告的精准度确实惊人：新手机用户会看到手机壳广告、婴儿用品广告总找上新爸妈。但它闹笑话的能力同样一流——你帮朋友搜了一次礼物，接下来一个月它天天向你推销那件礼物；家里老人随口聊到的话题（如果麦克风权限开着），也可能变成推送主题。算法只认数据，不懂数据背后的语境。
P: 更值得警惕的是「过滤气泡」效应：平台为了让你多停留，只推你喜欢看的内容，久而久之你的信息视野被自己爱看的观点包围，越来越难接触到不同的声音。这不是阴谋论，而是推荐算法追求停留时长的自然结果。破解方法是主动关注多样化的信息源，定期点开一些「不像你会看」的内容。
KC: 过滤气泡 :: 推荐算法为延长停留时间只推用户偏好的内容，久而久之视野被同类信息包围，难以接触不同观点，这叫过滤气泡。:: 试一试 :: 主动搜索一个平时从不关注的话题，观察推荐列表一周内的变化。
CALL: 动手实践 :: 如果两个好友用同一台设备先后登录各自的账号刷视频，推荐内容会发生什么变化？这说明画像绑定的到底是什么？

S: 反制手段清单
P: 面对个性化广告，你有几张可打的牌。第一张：关闭个性化推荐开关（各主流平台依法提供），广告仍会出现但不再针对你的画像。第二张：管理广告兴趣标签——不少平台允许查看和删除系统给你打的标签，删掉「母婴」「理财」这类标签，相关推送立刻减少。第三张：限制追踪权限，拒绝应用间的跨平台跟踪请求。
P: 第四张牌最根本：管住源头。回想第一章的数据流水线——没有原料就没有产品。少授权不必要的权限、不同网站使用不同注册邮箱、定期清理浏览器 Cookie 和广告标识符，原料少了，画像自然单薄。

P: 广告技术还有一面更隐蔽的镜子叫再营销：你看了某商品没买，它的广告会在接下来的几周里反复出现在不同应用中，像一位不知疲倦的推销员跟着你走街串巷。理解了这个机制，你就知道为什么「看了一眼就被追着跑」——这不是巧合，是设计。
S: 小结与预告
P: 回顾本章：个性化广告走采集、打标、匹配、竞价四步流水线；它精准但缺乏语境理解，还会制造过滤气泡；反制的四张牌是关推荐、删标签、限追踪、管源头。看清了对手的打法，防守就有了章法。
P: 广告只是数据的一种用途，更复杂的用途都写在那份你从来没读完过的文件里——《用户协议与隐私政策》。下一章教你十分钟抓住它的要害——动手试过之后体会会更深刻。。
