T: 隐私政策里藏着什么

S: 一份没人读的合同
P: 每个应用第一次启动时都弹出一份《用户协议与隐私政策》，几万字，密密麻麻。绝大多数人的做法是：直接点「同意」。可这份文件正是你与平台之间关于数据的全部约定——收集什么、怎么用、给谁看、存多久，答案全在里面。不读就同意，等于闭着眼签合同。
@kp=privacy-policy-reading
KC: 隐私政策解读 :: 读隐私政策抓四个问题：收集哪些信息、用于什么目的、与哪些第三方共享、如何撤回和删除；答不清这四问的服务要慎用。:: 生活里的例子 :: 签租房合同先看租期、押金、维修责任、退租条件——数据世界的合同同理。
KC: 最小必要原则 :: 合规的应用只收集实现功能所必需的最少数据；功能与索取权限明显不匹配时（如手电筒要通讯录），就是越界信号。:: 试一试 :: 检查五个常用应用的权限清单，找出至少一个越界索取。

S: 四个问题抓要害
P: 问题一：收集什么？重点找「设备信息」「位置信息」「通讯录」这类字眼，对照该应用的功能判断是否必要——手电筒应用要读你的联系人就是越界。问题二：用来做什么？合法用途如「提供服务和改进产品」可以理解；如果出现「与合作伙伴共享用于营销」，就要警惕信息流向了多少家你不认识的公司。
P: 问题三：与谁共享？这是最关键也最容易藏猫腻的一条。正规政策会列出共享的类型甚至名单；含糊地写「相关合作方」的，共享范围可能大得没边。问题四：如何删除？找「注销账号」「删除数据」条款：有明确删除流程且承诺限期完成的算靠谱；只字不提删除的，意味着你的数据可能被永久留存。
FIG: 一个放大镜对准一份长文档，文档上高亮四行关键字：「收集范围」「使用目的」「第三方共享」「删除方式」，旁边配四张对应的提问卡片 :: 万字政策抓四条：收什么、干什么、给谁看、能删吗

S: 快速阅读的三分钟技巧
P: 没时间通读全文？三分钟技巧帮你抓住八成要点。技巧一：用浏览器的页面搜索功能查关键词「第三方」「共享」「删除」「保存期限」，直接跳到相关段落。技巧二：优先读「我们如何使用您的信息」和「我们如何共享您的信息」两节，它们是全文核心。技巧三：对比测试——把同公司新旧版本的政策放在一起搜关键词，新增的条款往往就是要留意的变化。
CALL: 动手实践 :: 选一个你最常用的应用，用四问加三分钟技巧完成一次政策速读，把四个问题的答案各用一句话写下来贴在笔记本上。

S: 小结与预告
P: 回顾本章：隐私政策是你与平台的数据合同；四问框架为收集什么、用途是什么、共享给谁、如何删除；三分钟技巧是关键词搜索加重点章节精读。读懂合同，才有资格谈维权。
P: 不过，就算你把政策读得滚瓜烂熟、把权限关得滴水不漏，还有一类风险防不胜防——平台自己保管不善，数据库被一锅端。下一章直面所有数据焦虑的终极场景：泄露事件。
