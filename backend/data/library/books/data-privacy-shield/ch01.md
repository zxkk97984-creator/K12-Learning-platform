T: 你的数据值多少钱：看不见的生意

S: 一笔奇怪的交易
P: 先看一笔奇怪的生意：某视频网站让你免费看剧，某搜索公司让你免费查资料，某地图软件让你免费导航。它们不收你的钱，却都成了市值千亿的大公司。钱从哪来？答案藏在一个词里——数据经济。你每次点击、停留、搜索、定位，都在为它们生产一种值钱的原料：你的行为数据。|mark:数据经济
@kp=data-economy
KC: 数据经济 :: 数据经济指用户的行为数据被收集、加工成用户画像并用于广告投放和商业决策的产业模式，个人数据是其中的核心原料。:: 生活里的例子 :: 免费电视靠收视率拉广告，互联网免费服务的「收视率」就是你的每一次点击。
FIG: 一个循环流程图：你在中间使用免费服务，周围一圈箭头依次经过「行为被记录」「加工成画像」「卖给广告主」「广告收入维持服务」，首尾相连成一个闭环 :: 免费服务的商业闭环：你不是顾客，而是原料供应方
P: 这套模式有个专门的名字：注意力经济加数据经济的组合。服务吸引你的注意力，注意力产生行为数据，数据加工成画像卖给广告主精准投放，广告费反过来养活服务。整个链条里你是缺一不可的一环——不是顾客，而是供应商。
P: 明白了这个模式，很多现象豁然开朗。为什么软件总想拿到你的位置、通讯录、相册权限？权限越多，能收集的数据维度越多，画像越值钱。为什么短视频一刷就停不下来？算法不断优化就是为了延长你的停留时间，因为时间就是可出售的注意力。
CALL: 想一想 :: 「免费」的服务真的是免费的吗？如果让你选择：付每月十元使用无数据收集版本，或者继续免费用但数据被收集——你会怎么选？为什么？

S: 一条数据不值钱，一亿条价值连城
P: 单看你一个人的数据确实值不了几个钱，可能只值几毛钱的广告展示机会。但一亿人的数据汇聚起来就是金矿：可以分析出哪个城市的人爱熬夜、哪类人群对价格敏感、什么内容最容易传播。企业据此决定在哪里开店、给谁推什么价、如何设计产品——数据成了新时代的石油。
P: 汇聚也带来一个隐私悖论：单独看每条数据都做了匿名处理，似乎认不出是谁；但把多个来源的数据交叉比对，「匿名」的人很容易重新现形。研究人员曾仅用三条位置信息（时间地点）就从百万匿名数据中锁定了具体个人。所以「我们只是收集匿名数据」这句话，要打个大大的问号。
P: 动手感受一下自己数据的价值。打开常用应用的个人中心或隐私设置页，找找「我的数据」「下载我的信息」这类入口（不少平台依法提供）。看看平台存了你哪些信息：注册多久、常在哪些城市活动、兴趣标签有哪些。很多人第一次看到自己的画像时会大吃一惊。
KC: 匿名化悖论 :: 单一来源的匿名数据看似认不出个人，但多个来源交叉比对后重新识别出具体个人的风险很高，匿名不等于绝对安全。:: 试一试 :: 查查新闻里「匿名数据被还原身份」的真实案例。
CALL: 动手实践 :: 完成一次「我的数据盘点」：列出你最常用的五个应用，分别写下它们各自掌握了你的哪些信息，再标出哪些信息是你愿意交换服务的、哪些其实不想给的。

P: 有一个实验能让你亲身体会数据画像的深度：在搜索引擎里输入你的常用邮箱地址（用引号包裹精确匹配），看看会出现什么。很多人会发现自己在某个论坛的旧帖、某次活动的报名记录赫然在列。这些「遗忘的角落」正是数据经济最真实的注脚——互联网不会遗忘，除非你主动清理。
S: 小结与预告
P: 回顾本章：免费服务靠数据赚钱，你在链条中是供应商而非顾客；单条数据廉价、海量数据是金矿；匿名化存在交叉识别的漏洞，别轻易轻信。看清生意的本质，才谈得上保护自己的权益。
P: 数据最直接的变现方式是广告——而且是最懂你的那种广告。为什么刚聊完球鞋就看到球鞋广告？下一章拆解个性化广告的完整流水线——这个细节常常被初学者忽略。。
