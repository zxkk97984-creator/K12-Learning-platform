T: 小雨的故事：眼睛想休息啦

S: 眼睛罢工事件
P: 放假第三天，小雨创下个人纪录：从早上九点到中午十二点，连玩三小时平板。她站起来时眼前一黑，看什么都模模糊糊；脖子僵得像木头，手腕也酸酸的。更糟的是妈妈提议去公园，她竟然脱口而出：「不想去，我要接着玩！」说完自己都吓了一跳——我这是怎么了？她的屏幕时间，确实失控了。|mark:屏幕时间
P: 妈妈没有没收平板，而是带小雨做了个小实验：找来一个玻璃杯和一盒积木。「每块积木代表半小时的屏幕时间。」妈妈说，「你今天放了六块，杯子已经满了。可是一天还有运动、阅读、和朋友玩耍这些事，它们的杯子空着呢。」小雨看着两个杯子，第一次直观地看到自己的一天有多偏。

KC: 屏幕时间平衡 :: 屏幕时间要有度：每天约定好时长，每用三十分钟让眼睛休息一会儿，用运动、阅读和户外活动把一天填得丰富平衡。:: 生活里的例子 :: 就像吃糖：糖很好吃，但一顿全吃了牙疼又没力气玩。

S: 三个护眼小魔法
P: 第一招叫 20-20-20：每看屏幕二十分钟，就抬头看二十英尺（约六米）外的东西二十秒。窗外的树、远处的楼都行。这个动作能让一直紧绷的眼睛肌肉放松下来，就像跑完步要拉伸一样。
P: 第二招是给屏幕定闹钟。和小雨一起约定每天的游戏时段和总时长，设个提醒铃声。铃声响了不是「马上永远告别平板」，而是「先去做别的事，明天还能玩」。有约定的自由才是真自由——这是妈妈的原话，小雨觉得很有道理。
P: 爸爸还给小雨定了一个「屏幕自由日」：每周挑一个半天，全家一起完全不碰屏幕，去公园骑车或者逛图书馆。第一天小雨还有点坐立不安，第三次开始她竟然盼着这一天的到来——原来离开屏幕的世界，比想象中热闹得多。
P: 第三招最厉害：用更好玩的事填满生活。小雨后来发现，跳绳破了自己纪录的感觉、和同桌一起搭的超大积木城、读完一整本漫画书的满足感，都不比游戏差。屏幕是众多玩具里的一种，而不是唯一的玩具。
CALL: 想一想 :: 为什么连续玩三小时反而越玩越不快乐？回忆一次你自己「玩到后来只想硬撑着继续」的经历。

S: 制作我的时间披萨
P: 动手做一个好玩的时间规划工具：画一个大圆当成披萨，把它切成几块——睡觉、上学（或假期作业）、运动、阅读、和朋友玩、屏幕时间。给每块涂色并写上大概时长。看看你的屏幕那块占多大？如果超过四分之一，试着和它谈判：匀半小时给运动会怎样？
P: 管理屏幕时间最难的不是知道方法，而是执行的那一秒——铃声响起时手正停在精彩处。小雨的秘诀是给自己一个交换条件：关掉平板后立刻去做一件喜欢的事，跳绳、拼图或者吃个水果，让停止变得不那么难受。
P: 小雨的时间披萨改版后是这样的：屏幕时间两块（游戏一小时加动画片半小时），运动两块，阅读一块半，还多了一块「帮厨」。一周后的家庭会议上她宣布：跳绳从每分钟八十下进步到了一百零五下，而且——她主动承认——游戏其实也没那么非玩不可了。
KC: 眼睛的求救信号 :: 看东西模糊、眼睛干涩发酸、头疼脖子僵，都是眼睛在发求救信号；收到信号就该立刻休息，闭眼或远眺。:: 试一试 :: 连续看屏幕半小时后闭眼一分钟，感受有什么不同。
CALL: 动手实践 :: 画出本周的时间披萨，和家人约定一个屏幕时间的具体数字，写下来贴在冰箱上，下周开会检查达成情况。

S: 小结与预告
P: 小雨的第三段故事讲的是分寸：两个杯子实验让你看见失衡，三个护眼小魔法保护眼睛，时间披萨让一天变得丰盛。记住，管住屏幕不是失去快乐，而是把快乐分配给更多事情。
P: 不过就算时长合理、内容也要留心。网上有些内容看起来是好玩的游戏视频，其实是想掏空你零花钱的广告！下一集，小雨差点又中招……——辨别广告需要练就火眼金睛。。
