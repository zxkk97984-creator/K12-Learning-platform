T: 小雨的故事：屏幕里的坏心情

S: 一个跳出来的画面
P: 周六下午，小雨在平板上看动画片。视频播到一半，画面突然切到一个吓人的怪物镜头，还配着刺耳的声音。小雨「哇」地一下把平板扔到沙发上，心怦怦跳。她躲回房间，一整个下午都闷闷不乐，晚上还做了噩梦。
P: 第二天吃早饭，妈妈发现小雨眼睛红红的，问她怎么了。小雨一开始摇头说没事——她有点怕被说「看乱七八糟的东西」。妈妈温柔地说：「不管遇到什么，都可以告诉我和爸爸。我们不会责怪你，只会帮你。」——这句「告诉大人」后来成了小雨的口头禅。|mark:告诉大人
KC: 越保密越要说 :: 如果网上有人强调「这是我们俩的秘密，别告诉大人」，这句话本身就是危险信号，要第一时间告诉爸爸妈妈。:: 试一试 :: 和家人约定一个求助暗号，一说出口大家就知道你需要帮忙。
CALL: 想一想 :: 小雨一开始为什么不敢说？如果憋在心里不说，坏心情会自己消失吗？
P: 听完小雨的描述，妈妈做了三件事：先抱抱她说「这不是你的错，是那个视频不该出现在儿童内容里」；然后教她在平台上点了举报按钮；最后陪她设置了青少年模式，让吓人的内容以后很难再冒出来。小雨心里的石头落了地。
@kp=tell-a-grownup
KC: 告诉大人 :: 网上看到害怕、恶心、难受的内容时，做三个动作：马上关掉，深呼吸几次，尽快告诉爸爸妈妈或老师。说出来不是告状，是保护自己。:: 生活里的例子 :: 被烫到手要立刻告诉大人处理——心里受伤也一样需要大人帮忙。
FIG: 三个圆形图标排成一排：第一个是关掉的屏幕，第二个是一朵深呼吸的云，第三个是牵在一起的大手和小手；下方一行字「关闭 · 呼吸 · 找大人」 :: 三步急救法：先关掉，再平静，最后找帮手

S: 「说出来」是勇敢不是打小报告
P: 有的同学会犹豫：告诉老师，会不会被同学说是打小报告？这里要分清楚两件事。看到让自己受伤的内容来找大人帮忙，是自我保护，和打小报告完全是两回事。打小报告是为了让别人挨批评，求助是为了让自己好起来。勇敢说出「我需要帮助」，其实是大孩子才懂的做法。
P: 坏心情有时候不会马上出现，而是像小石子一样慢慢积累：今天看到别人晒礼物有点嫉妒，明天看到同学被起哄觉得好笑。每天睡前花一分钟问问自己「今天的上网时光让我开心吗」，就能及时发现心里的小石子，别等堆成大山才处理。
P: 还有一种情况也要警惕：有陌生人在网上发来奇怪的照片，或者说「这是我们的小秘密别告诉你爸妈」。记住！越是强调不能告诉大人的话，越要马上告诉大人。正常的大人从来不需要小朋友替他保守秘密。
P: 动手画一张「我的后援团地图」。在纸上写下三个遇到问题时可以找的人，比如妈妈、爸爸、班主任，再写上他们的联系方式和一句话理由。把这张图贴在你喜欢的地方。有了后援团，坏心情来了也不怕。
CALL: 动手挑战 :: 练习一句求助的开场白：「妈妈，我在网上看到了一个让我不舒服的东西，你能帮帮我吗？」对着镜子说三遍，让它变成你的顺口溜。

S: 小结与预告
P: 小雨的第二段故事告诉我们：网上遇到不舒服的内容，错的不在你；记住三个动作——关闭、深呼吸、找大人；越是让你保密的事越要说出来。心里的话说给信任的人听，坏心情就会变小。
P: 网络世界的问题不止来自内容本身，还有一样东西几乎每个小朋友都在面对：玩得停不下来！下一集，小雨的眼睛和大脑集体罢工了……——屏幕时间的管理其实也有小妙招。。
