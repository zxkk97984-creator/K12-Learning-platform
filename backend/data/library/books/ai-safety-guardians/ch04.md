T: 小雨的故事：广告捉迷藏

S: 「全网最火的玩具」
P: 周末，小雨看一个玩具开箱视频。视频里的大哥哥激动得声音都劈了：「这是今年最最最火的玩具！不买真的会后悔！」小雨立刻拉着妈妈要去买。妈妈却笑着问：「你觉得这是真心推荐，还是广告？」|mark:广告
P: 小雨愣住了。她从没想过这个问题。妈妈打开那个大哥哥的主页，往下一翻——好几条视频都带着「广告」「推广」的小标签，评论区还有不少人在说「又是恰饭视频」。小雨这才发现：原来那些「真心推荐」，很多是收了钱的表演。
@kp=spot-the-ad
KC: 辨别广告 :: 广告是花了钱想让你买东西的内容，它常常打扮成游戏奖励、博主推荐或精彩视频。看到「限时」「最火」「快抢」就要竖起天线。:: 生活里的例子 :: 包装上的卡通明星不是来交朋友的，是想让你掏零花钱的。
KC: 广告三件隐身衣 :: 广告常伪装成游戏奖励弹窗、博主的顺口推荐或者刷屏好评；满屏夸张好话却没有一条缺点时要格外留心。:: 试一试 :: 在十分钟的儿童视频里找出所有藏起来的广告。
FIG: 一个放大镜照向手机屏幕：屏幕上一条玩具推荐视频被照出了隐藏的尾巴——角落里一个小小的「广告」标签；放大镜旁边写着四个字「火眼金睛」 :: 广告最爱玩捉迷藏：找到它的小尾巴，你就赢了一半

S: 广告的三件隐身衣
P: 第一件隐身衣：游戏里的弹窗和奖励。「看广告领金币」「邀请好友解锁新关卡」——这些设计的目的是让你看更多广告或者拉更多人进来，而不是白送你好处。第二件：视频里的「顺口一提」。有些视频前半段是故事，后半段突然开始夸某个文具多好用——那半段就是换了衣服的广告。
P: 第三件最隐蔽：假装成普通人的好评。「我家孩子玩了再也停不下来！」这种话可能是商家自己写的。判断小技巧：满屏都是夸张的好话、没有一条说缺点时，反而要多个心眼。真东西有人夸也有人挑毛病。
CALL: 想一想 :: 为什么商家要把广告伪装起来，而不是大大方方写上「我是广告」？如果所有广告都诚实标注，会发生什么？
P: 认出广告之后该怎么办？第一步，深呼吸，问问自己：我是本来就需要它，还是被它煽动了？第二步，查证：问问用过的人，看看有没有差评。第三步，涉及花钱的事交给大人决策。记住，看到喜欢的东西不丢人，冲动掏钱才后悔。

S: 小雨的实战检验
P: 辨广告的本领还要在实战里打磨。学会辨广告后的一周，小雨经历了两次考验。第一次：视频里「三二一上链接」的限量文具套装，她心动了三秒，然后想起口诀——「限时」是催你冲动的魔法词，放弃。第二次：同桌真的带来一款好玩的桌游，没有广告、没有推销，纯粹因为好玩才传遍全班——这才是真正的好东西，靠口碑活着。
P: 动手玩一场家庭版广告捉迷藏：一起看十分钟的儿童视频或逛一次购物页面，比赛谁先找出藏在里面的广告，找到一处得一分。你会发现广告比想象中多得多——它们就藏在片头、贴纸、搜索结果的第一条里。
CALL: 动手挑战 :: 在最近看过的内容里找出三条广告，说说它们分别穿了什么「隐身衣」：是弹窗奖励、博主推荐，还是刷屏好评？

S: 小结与预告
P: 小雨的第四段故事练成了火眼金睛：广告是想让你花钱的内容，常穿三件隐身衣——游戏奖励、博主推荐、刷屏好评；认出口诀是警惕「限时最火快抢」；对付它的三步是冷静、查证、找大人。
P: 四段故事集齐了四样本领：守住小秘密、坏心情说出来、管好屏幕时间、认出广告。最后一章，我们把它们铸成一面属于你的安全小盾牌——盾牌合成的毕业典礼即将举行。。
