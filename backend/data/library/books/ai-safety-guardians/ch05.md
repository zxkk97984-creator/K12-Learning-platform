S: 毕业典礼开始啦
P: 小雨的四段故事讲完了，你也跟着经历了四次考验。现在到了最激动人心的环节：把学到的本领铸成一面安全小盾牌。先来个小测验热热身——下面五个情景，你能各说出应对办法吗？|mark:安全小盾牌
P: 情景一：游戏里有人问「你家住哪个小区呀？」——保密，不回答，告诉大人。情景二：视频里突然出现吓人画面——关闭、深呼吸、找大人。情景三：今天已经玩了两小时平板，眼睛发酸——休息，去做时间披萨上的其他事。情景四：博主喊着「全网最低价快抢」——认出广告，冷静查证。情景五：有人说「这是我们的小秘密别告诉爸妈」——这是危险信号！立刻告诉大人！

KC: 安全小盾牌守则 :: 五条守则组成安全小盾牌：一、小秘密不说；二、不舒服就说；三、屏幕有度；四、广告认得出；五、拿不准先问大人。:: 生活里的例子 :: 就像出门要检查钥匙钱包，上网前心里过一遍五条守则。
KC: 家庭公约 :: 盾牌需要全家守护：共同签署一份网络小公约，对大人和孩子都提出要求，互相监督的约定才最有力量。:: 试一试 :: 本周召开一次十分钟家庭网络小会议。

S: 和家人签一份公约
P: 盾牌想长期有效，需要全家一起守护。小雨家和爸爸妈妈开了一次家庭会议，签了一份《网络安全小公约》。公约里不光有对小雨的要求，也有对爸爸妈妈的承诺——比如吃饭时间大家都不看手机、爸爸答应不再睡前刷短视频到半夜。
P: 你的公约可以包含这些条款：每天屏幕总时长多少；哪些网站和应用可以去；遇到问题第一时间找谁；爸爸妈妈保证耐心听不打骂；每周开一次十分钟的家庭小会议聊聊本周的网上见闻。双方签字画押，贴在冰箱上。互相监督的约定，才最有力量。
CALL: 动手实践 :: 召集家人开一次十分钟小会议，共同起草你们的网络小公约，至少包含一条对大人的要求和一条对自己的要求。

S: 你已经是小卫士了
P: 毕业典礼的最后一个环节是授勋。请家人在你亲手做的盾牌上贴一枚星星贴纸——从今天起你就是持证上岗的安全小卫士了。最后认真地说一句：能读完这五段故事的你，已经比很多大人更懂得在网上保护自己了。安全小卫士不是不碰网络的胆小鬼，而是既能享受乐趣又知道边界的小能手。网络里有知识、有创造、有远方的朋友，带着你的盾牌去探索吧！
P: 小卫士的成长档案也值得记录：把每次成功应对的经历写下来——识破了一个假弹窗、忍住没买广告玩具、提醒了同学不要透露信息。这些小事攒起来就是一本英雄手册，翻一翻就会发现自己比一个月前厉害了好多。
P: 盾牌需要定期保养才永远闪亮。别忘了每隔一段时间就复习一遍五条守则，看看有没有新学到的本领可以加进去。比如以后你会学到更多识别骗局的方法、更多管理时间的技巧——盾牌会随着你一起长大。
P: 把这本故事书分享给你的好朋友吧。一个人是小卫士，一群人就是安全联盟。当班里的每个同学都戴上了盾牌、都记住了五条守则，骗局就再也没有钻空子的机会——分享让更多人变成安全小卫士。
CALL: 动手总结 :: 制作你的实体小盾牌（画出来或用卡纸做），写上五条守则和自己的名字，挂在书桌前宣誓上岗！

S: 全书回顾
P: 四段故事，四样本领，一面盾牌：小雨学会了守住小秘密、坏心情说出来、和屏幕做时间朋友、认出变装广告；而你一路同行，现在正式毕业成为安全小卫士。
P: 记住哦，真正的安全不是害怕网络，而是心里有数：知道什么该做、什么不该做、出了事找谁。愿你每一次打开屏幕，都带着这份从容、这份底气，还有满满的快乐——安全小卫士，毕业快乐！
