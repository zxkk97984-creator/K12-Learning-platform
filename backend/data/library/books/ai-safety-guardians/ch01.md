T: 小雨的故事：神秘的礼物弹窗

S: 弹窗说：免费领皮肤！
P: 小雨是个爱玩游戏的三年级学生。这天她正在玩最喜欢的搭积木游戏，屏幕角落突然跳出一个亮闪闪的弹窗：「恭喜你被选中！免费领取限定皮肤，只需填写姓名和爸爸妈妈的手机号！」小雨心动极了——那个皮肤全班只有三个人有。
P: 她的手指刚碰到键盘，家里的智能音箱突然开口了：「小雨，先别急！」原来是爸爸提前给音箱设置的安全提醒。音箱接着问：「你还记得安全课上说的吗？网上送东西的陌生人，就像街上递糖果的陌生人。|mark:陌生人
CALL: 想一想 :: 如果你收到「免费领皮肤」的弹窗，你的第一反应是什么？故事里的小雨和你想的一样吗？
P: 小雨想了想，跑去找妈妈。妈妈陪她一起看那个弹窗，发现了三个可疑的地方：第一，真正的游戏不会在弹窗里要家长手机号；第二，点开它的大字广告，下面藏着一行小字「注册即同意接收推广信息」；第三，妈妈在官方渠道查了查——根本没有这个活动。这是个钓鱼的假弹窗！

KC: 信息保密 :: 姓名、学校、家庭住址、照片、家长电话和支付密码都是小秘密。网上的陌生人问起这些，一律回答保密，然后去问大人。:: 生活里的例子 :: 就像不告诉陌生阿姨自己家的门牌号——在网上也一样。
KC: 信息拼图 :: 单条信息看着无害，拼起来却危险：姓名加学校加班级，陌生人就能在校门口准确认出你。小秘密一块也不能给。:: 试一试 :: 和家人玩信息分类游戏，把能说的和小秘密分成两堆。
FIG: 一面盾牌形状的信息卡片：中间写着五样小秘密（姓名、学校、住址、照片、电话），盾牌外面画着一只伸过来的手标着「陌生人想打听」，盾牌挡住了它 :: 五样小秘密装进盾牌：陌生人打听，一律说保密
P: 第二天，小雨把这件事讲给全班听。老师带着大家做了个分类游戏：把「最喜欢的动画片」「我家住在幸福小区 3 栋」「我今年九岁」「妈妈的手机号」这些信息分成两堆——可以说的和小秘密。同学们发现：越能找到真实你的信息，越是小秘密。

S: 为什么小秘密这么重要
P: 你可能会问：就说个学校名字怎么了？单独看确实没什么，可是拼起来就危险了：知道你的名字加学校加班级，坏人就能在校门口准确认出你；有了家长手机号，就能冒充熟人给你的爸爸妈妈打电话。小秘密像拼图，一块块凑齐，坏人就画出你的完整地图了。
P: 还有更隐蔽的一种打探：假装同龄人的网友聊天时问「你放学一般几点回家呀？」听起来像闲聊，其实也是在收集拼图。记住这个原则：网上的朋友再聊得来，小秘密也一个都不能说。真正的朋友不会追问你的家庭住址。
P: 动手做一张「小秘密清单」。和家人一起写下属于你的五样小秘密，贴在书桌旁。以后每次有人在网上问起清单上的内容，你就知道该怎么做——微笑拒绝，转身找大人。
CALL: 动手挑战 :: 和家人玩角色扮演：一人扮演网上问路的陌生人，一人练习三种礼貌拒绝的说法。比如「这是我的小秘密哦」「我要问问妈妈」。

S: 小结与预告
P: 小雨的故事讲完了第一段。她学到的你也学到了：免费的东西往往最贵——代价可能是你的小秘密；五样小秘密装进盾牌；拿不准的时候，大人永远是你的后援团。
P: 可是网络上的意外不止一种。如果哪天刷到了让人害怕或者难受的内容，该怎么办呢？下一集，小雨也遇到了这个问题——小雨的第二段故事会给你答案。。
