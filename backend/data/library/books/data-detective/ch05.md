T: 完整破案：从提问到结论

S: 立案：一个值得查的问题
P: 最后一章，我们把前四课的全部装备串成一次完整破案。案件来自真实校园场景：「食堂新套餐推出一个月，同学们真的更喜欢它吗？」注意这个问题的质量——具体、可测量、有时间范围。模糊的「食堂好不好」没法立案，「新旧套餐的受欢迎程度对比」就可以。
@kp=correlation-causation
KC: 相关与因果 :: 相关是两个量一起变化，因果是一个导致另一个。相关可能出于巧合或第三个隐藏因素，从相关跳到因果必须补上机制或实验证据。:: 生活里的例子 :: 冰淇淋销量与溺水人数同涨同跌，真正的原因是夏天气温高，而不是冰淇淋害人。
P: 破案前先立一份嫌疑清单：哪些因素可能冒充答案？新套餐受欢迎，可能因为它真好吃（真凶），也可能因为旧套餐那周恰好涨价（替身），还可能因为爱发言的同学嗓门大（假证人）。提前列出干扰项，收集数据时才知道要同时记录什么——这一步叫识别混杂因素。
FIG: 侦探板图示：中央钉着问题卡片「新套餐更受欢迎？」，周围连线连着三张线索卡「口味本身」「价格变动」「发声人群偏差」，每条线上挂着待核对的数据标签 :: 好侦探先画嫌疑地图再动手收集，免得被第一个跳出来的解释带跑

S: 取证与分析
P: 收集方案这样设计：连续两周，每天午餐后随机邀请二十位同学匿名打分，新旧套餐各收约七十份；同时记录每日价格和剩余量作旁证。随机邀请是为了避开「只问好朋友」的样本偏差，匿名是为了让大家敢说真话，旁证数据用来排查价格因素的干扰。
P: 数据到手，分析登场。打分均值：新套餐 4.1 分，旧套餐 3.6 分；中位数分别是 4 和 4，说明分布并不极端。再看旁证：两周内价格没变，涨价假设排除；剩余量与新套餐上线同步下降，支持「确实更受欢迎」。三条证据互相咬合，结论开始站得住了。
P: 但侦探还要做最后一次自我盘问：打分高就等于更喜欢吗？会不会有同学把「新鲜感」打了高分？于是补一条纵向证据——第一周与第二周分开统计，发现新套餐评分第二周略降但稳定在 3.9 以上，高于旧套餐。新鲜感效应存在，却不足以翻案。至此可以结案了。
CALL: 想一想 :: 如果第二周新套餐评分跌到 3.2，你的结案陈词要怎么改？「受欢迎」和「一时新鲜」在数据上分别长什么样？

S: 结案陈词的写法
P: 一份合格的结案报告有五要素：问题、方法、发现、局限、建议。问题一句话说清；方法交代对象、时间、工具，让任何人能照着重做；发现用数字加图表呈现，图表遵守第四章的五项检查；局限诚实列出——本次只调查了一所学校，样本以午餐时段为主；建议基于发现而非愿望。
P: 特别强调「局限」这一节，它是侦探品格的试金石。敢写「本调查无法代表全年级」「匿名自报的睡眠时长可能失真」的报告，反而更可信，因为读者知道作者分得清哪些话能说、哪些话不能说。夸下海口的完美报告，往往离翻案最近。
P: 把全书浓缩成一张随身卡：问题磨尖再动手；收集交代来源与缺口；分析带上中位数；读图必查零点与刻度；相关别急着说因果；结论永远附上局限。六条守则在手，你已经超过大多数只看标题下结论的人。
KC: 结案报告五要素 :: 一份可信的数据报告包含五个部分：问题、方法、发现、局限、建议。敢写清局限的报告反而更值得信任。:: 试一试 :: 给班级图书角借阅统计写一段「局限」，说明哪些话是数据说不出口的。
CALL: 动手结案 :: 选一个你真正好奇的校园问题（如「晚自习效率与座位区域有关吗」），完整走一遍四步流程，写一份含局限说明的结案报告。

S: 全书回顾
P: 五章一案：第一章教你把问题磨尖、对来源较真；第二章给你配齐三种放大镜；第三章拆掉平均数话术；第四章识破坐标轴魔术；第五章把它们拧成完整的破案流程。数据不会自动说话，但侦探可以让它开口——用对的方法，说真的话。
P: 这个时代人人都在生产数据、转发图表，缺的不是信息，而是对信息的审慎。愿你带着侦探的眼睛走进下一段阅读：看到惊人的数字先问一句——样本是谁？坐标轴从几开始？相关还是因果？这三次追问，就是本书留给你的全部家当。
