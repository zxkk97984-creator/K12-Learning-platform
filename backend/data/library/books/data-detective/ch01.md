T: 侦探的第一课：数据是什么

S: 数据就是留下的记录
P: 侦探破案靠证据，数据侦探的证据叫数据。清晨闹钟响起的时刻、你上学路上花的时间、全班同学的身高、便利店每天卖出的饭团数量——这些被记下来的事实，都是数据。一句话：数据是对世界的记录。单条记录像一枚指纹，看起来不起眼，攒多了就能还原出真相。|mark:数据
@kp=data-collection
KC: 数据收集 :: 数据收集是围绕一个明确问题，选择对象、确定指标并如实记录的过程。收集谁、收集什么、怎么收集，直接决定结论可不可信。:: 生活里的例子 :: 想知道「同学们喜欢哪类课外书」，就该问爱看书的同学各种类型都问，而不是只问同桌。
P: 但记录不会自动变成真相，中间隔着一个关键环节：问题。同样是记录全校同学的身高，「我们学校平均身高多少」和「六年级教室座位该不该按身高重排」需要的数据完全不同。侦探的第一课不是找数据，而是先把问题磨尖——问题越具体，需要什么证据就越清楚。
KC: 样本与总体 :: 总体是你想了解的全部对象，样本是实际调查的那部分人。结论只能代表真正被问到的人，不能随便推广。:: 生活里的例子 :: 只采访篮球队员的身高，推不出全校同学的平均身高。
FIG: 流程图：一个放大镜下写着「好问题」，向右箭头经过三张卡片「找谁」「记什么」「怎么记」，最后汇入一张表格图标，表格上方标注「能回答问题的数据」 :: 从问题出发倒推数据需求，而不是抓到什么算什么
P: 反过来，先有数据再硬凑结论，是数据侦探的大忌。有人翻遍一年的销售记录，总能挑出几段支持自己想法的数字——这叫先射箭再画靶。记住顺序：问题在前，数据在后；证据说话，而不是愿望说话。
CALL: 想一想 :: 「同学们更喜欢体育还是美术课」这个问题，可以拆成哪些更具体的小问题？试着写出两个，下一节它们会派上用场。

S: 从零开始做一次记录
P: 光说不练不是侦探作风。我们就用刚才的问题走一遍完整流程。第一步定指标：「更喜欢」没法直接量，改成可记录的信号——请每位同学在体育、美术两门课里投一票，并写下一条理由。第二步定对象：全班四十六人，一个不漏。第三步定工具：一张表格，三列，姓名、票、理由关键词。
P: 收集时立刻遇到第一个坑：有同学请假了。漏掉的人会不会恰好意见一致？侦探必须在报告里写明「46 人中收到 43 票，3 人缺席」——这叫交代样本情况。数字本身不说谎，但残缺的数字会误导人，把缺口亮出来是侦探的职业操守。
P: 第二个坑更隐蔽：投票当天的前一节恰好是体育考试，大家刚跑完八百米，情绪分全给了体育。换一天再投，比例可能就变了。所以严谨的调查会重复测量或错开时间。你看，还没谈任何图表，陷阱已经出现两个了——数据的坑从来不在计算里，而在收集里。
P: 把 43 张票整理成表：体育 27 票，美术 16 票。现在可以说「本班多数同学更喜欢体育」了吗？还差一步——这个结论只属于你们班，不能推广到全年级，更不能推广到全国。样本只代表它真正覆盖的人群，这是侦探守则第一条。|mark:样本
CALL: 动手试试 :: 用同样的三步法，设计一个「本班同学每天睡眠时长」的小调查。想清楚：问谁？记什么？怎么保证大家报的是真实数字？

S: 小结与预告
P: 回顾本章：数据是对世界的记录，好问题是收集的起点；收集要定对象、定指标、定工具，还要交代缺口与时机的影响；结论只能覆盖样本覆盖到的人群。你已经具备了侦探最基础的素养——对来源较真。
P: 四十三张票摆成表格，一眼看不出气势；但画成两根柱子，高下立判。这就是图表的力量。不过放大镜既能看清指纹，也能把灰尘照得吓人——下一章先学正着用，第四章再揭穿反着用的把戏。
