T: 三种放大镜：条形、折线与饼图

S: 每种图表有自己的岗位
P: 数据侦探的桌上永远摆着三件工具。条形图像一排高低不同的柱子，回答「谁多谁少」；折线图用一条起伏的线，回答「怎么变化」；饼图像切开的蛋糕，回答「各占几成」。它们展示的可以是同一份数据，但强调的重点完全不同——选图表就是选视角。
@kp=chart-choice
KC: 图表选择 :: 图表选择的原则是让形式匹配问题：比较类别用条形图，观察趋势用折线图，展示占比用饼图。先问「我想说明什么」，再挑图。:: 试一试 :: 「四个小组得分对比」用条形图，「本周体温变化」用折线图，「零花钱怎么分配」用饼图。
P: 为什么不能混着来？看一个反例：把「一周气温变化」画成五张独立的饼图，每天气温占最高温的百分比——完全看不出哪天热哪天冷；换成一条折线，走势立刻跳出来。反过来，用折线连「五个班级的人数」也很荒唐：班级之间没有先后顺序，连线暗示了根本不存在的趋势。
FIG: 三联图：同一份「图书馆一周借阅量」数据分别画成条形图（五根柱子比高低）、折线图（一条先升后降的曲线）、饼图（周五占最大扇区），下方标注各自适合的问题 :: 同一份数据，三副眼镜：柱子比多少，线看趋势，蛋糕讲占比
P: 饼图还有一条使用纪律：块数别太多。超过五六块的蛋糕，读者已经分不清哪片是哪片了，相邻的扇形大小也难以肉眼比较。类别多的时候，宁可改用条形图排个序——人眼比较长短远比比较弧度在行。
CALL: 想一想 :: 学校要展示「近五年近视率变化」，应该用哪种图？如果改成「本学期各年级借书量排名」呢？说出你的理由。

S: 读图的三个动作
P: 会选图只是半程，侦探还必须会读图。拿到任何一张图，按固定顺序做三个动作。第一看标题和坐标轴标签：这张图到底在说什么？单位是「人次」还是「人数」？第二看刻度范围：纵轴从几开始、到几结束？第三再看图形本身。多数读图错误都出在前两步被跳过。
KC: 读图三步法 :: 拿到统计图先看标题和坐标轴标签，再查刻度范围，最后才看图形本身。多数读图错误都源于跳过前两步。:: 试一试 :: 找一张新闻图表，先遮住图形只读标题和轴，猜猜图会长什么样，再放开手对照。
P: 为什么要专门强调刻度？因为图形的高低是相对坐标轴而言的。同一份数据，纵轴从 0 开始是一副面孔，从 90 开始又是另一副面孔。现在你只需要记住「先查刻度」这个动作，下一章我们会看到它如何被用来制造视觉骗局。
P: 再教你一招侦探的交叉验证：数字与图形互相翻译。看到「A 组是 B 组的两倍长」的柱子，就回表格核对原始数值是不是真的两倍；读到「增长了一倍」的文字，就在脑中画出柱子该有多高。文字、图形、数字三者对得上，才算过了第一道安检。
P: 最后留意一个容易被忽略的位置：来源和样本量。同样一张「九成用户满意」的饼图，基于 2000 份问卷和基于 9 份问卷，分量天差地别。正规的数据报告会注明调查时间、对象和数量，缺了这三样的图表，侦探应当自动调低它的可信等级。
CALL: 动手找茬 :: 翻开最近的报纸或公众号文章，找一张统计图，按「标题—刻度—来源」三步给它做个体检，把发现写进你的侦探笔记。

S: 小结与预告
P: 回顾本章：条形比多少、折线看趋势、饼图讲占比，选图先问想说明什么；读图三步走——标题轴签、刻度范围、再看图形；数字图形互相对照，来源样本必须交代。工具已经上手，接下来该见识它们被滥用时的样子了。
P: 下一章我们进入本书最刺激的部分：不是图表不会说话，而是有人教它说谎。截断的坐标轴、失踪的基线、错位的比例——学会识破这些魔术，你才算真正出师。
