T: 图表如何说谎：坐标轴的魔术

S: 魔术一：被砍掉的底座
P: 看两张图，数据完全相同：某产品月销量从 1000 台涨到 1100 台。左图纵轴从 0 开始，两根柱子几乎一样高，观感是「平稳」；右图纵轴从 950 开始，第二根柱子猛地蹿出两倍高，观感变成「暴涨」。差别只在纵轴起点——这就是坐标轴截断。|mark:坐标轴截断
@kp=axis-truncation
KC: 坐标轴截断 :: 坐标轴截断指纵轴不从零开始或刻度不均匀，使图形高度差异远大于真实数值差异。柱状图的柱子高度代表数量，底座被砍必然夸大差距。:: 试一试 :: 把 1000 与 1100 两根柱子的纵轴改成从 1090 开始，后者看起来是前者的十倍。
FIG: 左右两幅条形图画着同样的两根柱子（1000 和 1100）：左图纵轴刻度 0 到 1200，两柱等高；右图纵轴刻度 950 到 1150，第二根柱子显得极高，右上角配一个惊叹号 :: 同一份数据的两个面孔：截断的坐标轴把 10% 的增长画成了翻倍的气势
P: 必须说句公道话：折线图截断有时是合理的。气温从 21 度到 23 度的变化，若从 0 度画起，曲线平得像心电图，反而看不出细节；折线关注的是走势而非总量，允许放大。但柱状图不同——柱子的高度就是数量的化身，砍掉底座等于让柱子说假话。
P: 所以侦探的读图口诀第一条：柱状图必查零点。看到柱子先找纵轴最下沿是不是 0；不是的话，立刻在脑中把图形「压」回真实比例再下判断。正规报告若确需截断，会明确标注破折号或说明，这是诚实的做法；偷偷截断还不标注的，动机就值得琢磨了。
CALL: 想一想 :: 为什么广告商偏爱截断坐标轴，而监管机构要求药品疗效图必须从零画起？两种场景里，「视觉冲击」分别服务于谁的利益？

S: 魔术二与魔术三：变形的比例和失踪的样本
P: 第二种手法玩弄面积。比较两个数字，本该用高度表示，制图者却把整个图形的长和宽都按比例放大：数值差一倍，图形面积差了四倍——因为面积等于长乘宽。眼睛对面积的感知很迟钝又很感性，四倍大的图标天然显得「严重得多」。对付它只需一句：比大小，看高度，别看体积。
P: 第三种更隐蔽：让关键数据干脆不上场。某产品宣传「用户满意度 95%」，图表精美绝伦，唯独不提调查对象是从售后好评名单里挑的两百人。图本身没画错一个像素，但缺席的样本让整张图失去意义。这招叫选择性呈现，是样本偏差的图表版。|mark:样本偏差
KC: 选择性呈现 :: 选择性呈现指只展示对自己有利的部分数据：挑时间段、挑调查对象、隐藏失败案例。图没画错，但缺席的数据让结论失去意义。:: 试一试 :: 只统计体育课当天的心情打分来代表「全校学生每天的心情」，问题出在哪？
P: 三种魔术的共同点值得咀嚼：它们都没有伪造数字。每一个数值都真实，每一张图都「有据可查」，谎言藏在选择里——选哪个起点、哪种比例、哪批样本。所以数据侦探审查图表时，问的不是「数字对不对」，而是「为什么偏偏这样展示」。
P: 给你一张随身检查清单，五项各十秒：标题说的是这件事吗？柱状图从零开始了吗？折线的刻度均匀吗？面积有没有被双重放大？来源、时间、样本量交代了吗？五项全过，这张图才获得进入你大脑的资格。
CALL: 动手拆解 :: 用作图软件亲手做一次实验：同一组班级投票数据，分别用从 0 开始和截断的纵轴各画一张条形图，对比观感差异，把两张图贴进侦探笔记。

S: 小结与预告
P: 回顾本章：柱状图查零点防截断，比较看高度不看面积，警惕缺席的样本；图表说谎靠的是展示方式的选择而非伪造数字。至此，读图的内功已经齐备，但侦探最终要交付的是结论——怎么从证据走到让人信服的结论？最后一章走完全程。
