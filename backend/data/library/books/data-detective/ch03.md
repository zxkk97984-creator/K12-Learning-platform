T: 平均数的陷阱：谁拉高了工资

S: 一则可疑的新闻
P: 「某公司宣布员工平均月薪两万！」评论区一片羡慕。可细看员工构成：五名高管每人月薪八万，十五名普通员工每人八千。一算平均数：(5×80000 + 15×8000) ÷ 20 = 26000，还真不止两万。但二十个人里十五个拿的是八千——平均数说了个数学事实，却讲了个误导的故事。|mark:平均数
@kp=mean-median-mode
KC: 平均数、中位数与众数 :: 平均数是总和除以个数，容易被极端值拉扯；中位数是排序后站在正中间的值；众数是出现次数最多的值。三者都是「代表」，角度各不同。:: 试一试 :: 数据 2、3、3、3、100 的平均数是 22.2，中位数是 3，众数是 3——你更愿意用哪个代表这组数据？
P: 问题出在哪？平均数对极端值毫无抵抗力。一个天文数字混进来，就能把整锅汤的味道彻底带偏。而工资、房价这类数据恰恰天然含极端值：少数高收入者会把平均值抬到大多数人够不着的高度。所以统计学家说：收入类数据，先看中位数。
FIG: 十一个小人站成一排按身高排队，中间那个被圈出标注「中位数 1.62 米」；旁边一位巨人把右端压弯，标注「加入巨人后平均身高被拉到 1.9 米，但中位数几乎没动」 :: 极端值能轻松拽走平均数，却很难撼动中位数——这就是为什么新闻里该多看中位数
P: 中位数的脾气完全相反：它只关心排序后的位置，数值再夸张也影响不了它。回到那家公司：把二十份工资从小到大排，正中间落在第八、九位之间，约八千出头。中位数告诉你「典型员工的待遇」，平均数告诉你「总额除以人数」，两个都有用，但回答的问题不同。
CALL: 想一想 :: 房产中介说「本市平均房价三万一平」，开发商和刚需购房者分别会想用哪个数字说话？为什么同一座城市会有两套口径？

S: 三兄弟各显神通
P: 除了平均数和中位数，还有第三位代表：众数，出现最多的那个值。服装店进货不看平均身材也不看中间身材，而是看哪个尺码卖得最多——M 码卖爆了就多进 M 码。众数回答「最常见的是什么」，在类别数据上尤其好用，比如全班的生日月份、最受欢迎的社团。|mark:众数
P: 三个代表什么时候会打架？举个班级测验的例子：成绩为 90、85、85、80、10 五人一组。平均数 70，看着平平无奇；中位数 85，说明一半人考得不错；众数 85，暴露了最集中的分数。那个 10 分多半是缺考或失误，它一个人就把平均分拽下了 15 分。
P: 所以侦探的规矩是：报结论时至少带上两个代表值，并交代数据长什么样。「平均 70 但中位数 85」这句话本身就传递了重要信息——分布不均匀，有极端低分存在。单一数字的结论，天然值得怀疑；肯把三个代表都摆出来的报告，才配得上信任。
P: 现在你有了一套反话术装备。听到「平均」先问一句：「中位数是多少？」听到「大多数人都……」就追问：「这个『大多数』是众数算的还是拍脑袋说的？」不是抬杠，而是帮双方把话说准——很多争论其实源于用了不同的代表值还浑然不觉。
KC: 极端值 :: 极端值是远离大多数数据、特别大或特别小的个别数值，它对平均数影响巨大，却几乎撼动不了中位数和众数的位置。:: 生活里的例子 :: 一道题全班都考八十多分，只有一人缺考得零分，平均分立刻被拽低好几名。
CALL: 动手算算 :: 记录你和四位好友上周的每日屏幕使用时间（共五组数据），分别算出平均数、中位数和众数，再用一句话向家人解释三者为何不同。

S: 小结与预告
P: 回顾本章：平均数怕极端值，中位数站得稳，众数找最常见；收入房价等偏斜数据优先看中位数；下结论至少携带两个代表值。你已经拆穿了第一类常见话术，接下来是对付视觉层面的骗术。
P: 数字会说谎，图形更会——因为它绕过了你的理性思考，直接冲击眼睛。下一章进入本书的高潮：不是图表不会说话，而是有人教它说谎。坐标轴截断、比例失真、样本失踪，三大魔术逐一拆解，学会之后你将很难再被骗到。
