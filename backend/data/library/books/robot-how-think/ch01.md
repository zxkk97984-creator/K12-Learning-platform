S: 什么样的机器才算机器人
P: 电风扇通电就转，它是不是机器人？扫地机自己规划路线、没电了还能自己回去充电，它显然「更聪明」。区别在哪？电风扇只会一根筋地转，扫地机却能感觉环境、自己做决定。科学家给机器人下定义时，看的就是这三样东西齐不齐。|mark:机器人

KC: 感知—决策—行动 :: 感知—决策—行动是机器人工作的基本循环：传感器收集环境信息，程序根据信息做决定，执行器完成动作，然后立刻开始下一轮循环。:: 生活里的例子 :: 你过马路也是这个循环：眼睛看来车（感知），判断能不能走（决策），迈步前进（行动）。
P: 这三样东西对应机器人的三大件：负责「感觉」的传感器，相当于眼睛和耳朵；负责「思考」的处理器和程序，相当于大脑；负责「动作」的执行器，相当于肌肉。少了任何一件，它就退化成普通机器——台灯没有传感器也不做决定，所以永远只是台灯。
FIG: 一台扫地机器人的剖面图：顶部画着碰撞条和摄像头标注「感知」，中间主板标注「决策」，底部两个轮子和滚刷标注「行动」，三个部分用箭头连成一个循环圈 :: 机器人的身体里住着一个不断旋转的循环：感觉、思考、行动，周而复始
P: 用这个标准去套身边的机器，会得出很多有趣的判断。空调能感测室温并决定开关压缩机，算半个机器人；自动门感应到人就打开，也有一点「感知加决策」；而普通自行车三样都没有，所以再贵也不是机器人。界限不在外形像不像人，而在会不会自己拿主意。
KC: 三大件清单 :: 判断一台机器是不是机器人，就看三样：传感器负责感觉，程序负责决定，执行器负责动作。缺任何一样都只是普通机器。:: 试一试 :: 用三大件标准给家里的电器分类：台灯、空调、扫地机各算什么？
CALL: 想一想 :: 家里的电饭煲能感测温度、决定什么时候跳闸保温，它算机器人吗？用三大件的标准说说你的理由。

S: 「会想」背后的真相
P: 机器人的「想法」其实是一段段程序。别失望，这恰恰是有趣的地方：因为想法就是程序，所以我们有机会读懂甚至编写它们。人类工程师给机器人写规则：「如果前方障碍小于二十厘米，就右转」，机器人就会严格执行，一次都不会忘。
P: 但真实世界比规则复杂得多。同样是「前方有障碍」，可能是墙角、可能是宠物、可能是突然蹲下的同学，合适的应对各不相同。简单规则很快不够用了，工程师于是发明了更聪明的组织方式——让机器人在几种行为模式之间切换，这就是第三章要讲的状态思路。
P: 还有一个贯穿全书的关键词先埋在这里：误差。传感器会读错，轮子会打滑，电池电压会影响马达力气。机器人每一步都带着小误差前进，聪明的机器人靠不断「边走边修正」来抵消它们，这门功夫叫反馈，第四章专门讲。
P: 这一章你只需要带走一张地图：机器人等于传感器加大脑加执行器，它的生活就是一个接一个的感知—决策—行动循环。接下来三章，我们逐个拆开这三大件，看看每个部件里藏着什么门道。
CALL: 动手观察 :: 找一段扫地机器人或送餐机器人的工作视频，试着指出哪一秒它在感知、哪一秒在决策、哪一秒在行动。你会发现三者切换得飞快。

S: 小结与预告
P: 回顾本章：机器人不是长得像人的机器，而是具备感知、决策、行动能力的机器；三大件各司其职，循环往复；「会想」的本质是程序，而程序的难点在于应付不完美的感觉和多变的现实。
P: 先从感觉说起。机器人的眼睛是什么做的？黑暗里它能看见吗？隔着一层玻璃还灵吗？下一章走进传感器的世界，你会看到机器的感觉既神奇又脆弱。
