T: 机器人的五官：传感器

S: 看不见的声波与光线
P: 蝙蝠在漆黑的山洞里飞行从不撞墙，靠的是发出超声波再听回声。机器人最常用的「眼睛」——超声波传感器，用的正是这招：发出一声人耳听不到的超声波，记录回声用了多久，声速乘以时间除以二，距离就算出来了。它不需要光，黑灯瞎火照样测距。|mark:超声波传感器
@kp=robot-sensor
KC: 传感器 :: 传感器是机器人的感觉器官，把光线、距离、温度、声音等物理信息转换成电信号，供机器人大脑读取和判断。:: 生活里的例子 :: 自动门顶部的装置感应到有人走近就通知门打开，它就是一种传感器在工作。
P: 另一位常用选手是红外线传感器。它的思路像玩手电筒：主动发射一束红外光，看反射回来的强弱来判断前方有没有东西、地面颜色深浅。扫地机器人识别深色地毯与浅色地板、循线小车沿着黑线走，用的都是红外反射的差异。它便宜、反应快，缺点是怕太阳光里的红外成分捣乱。
FIG: 对比图分上下两栏：上栏一只蝙蝠发出声波弧线碰到障碍物反弹回来，旁边画着超声波传感器同样以弧线测距并标注公式「距离 = 声速 × 时间 ÷ 2」；下栏一束红外线射向深浅两块地面，反射强度不同 :: 两种常用的「电子感官」：一个听回声量距离，一个看反光辨颜色
P: 摄像头则是信息量最大的感觉器官，一张照片里有百万个像素点。但信息多不等于好懂：人一眼认出同学的脸，机器人却要把像素交给复杂的识别程序去猜。所以工程上常做取舍——能测距离就用超声波，能看线条就用红外，非必要不上摄像头，够用就好。
CALL: 想一想 :: 让机器人判断面前是「一堵白墙」还是「挂着白床单」，超声波和摄像头各自会遇到什么困难？哪种组合更稳？

S: 感觉也会出错
P: 人的感觉会骗人：伸进温水的手觉得凉，伸进凉水的手觉得温。机器的感觉同样会出错，而且花样更多。强阳光下红外读数乱跳；光滑地面让超声波产生奇怪的回声；轮子沾了灰，里程估计就越走越偏。这些让读数不可靠的因素，工程师统称为噪声与干扰。|mark:噪声
@kp=noise-interference
KC: 干扰与噪声 :: 干扰与噪声指让传感器读数偏离真实值的因素，如强光、回声、震动、灰尘。好的机器人程序必须假设感觉不可靠，并想办法过滤。:: 生活里的例子 :: 在嘈杂的食堂里听不清朋友说话，人脑会自动聚焦对方声音，这正是对噪声的一种过滤。
P: 应对噪声的第一招叫多次确认。一次读数说前方十厘米，可能是真的，也可能是干扰；连续五次都报十厘米，可信度就高多了。第二招叫多传感器互相印证：超声波说有障碍，碰撞开关却没碰到，那就放慢速度再探一次。侦探式的交叉验证，机器人也在用。
P: 第三招来自设计阶段的功课：了解每种传感器的脾气，避开它的软肋。知道红外怕阳光，就把循线场地设在室内；知道超声波对柔软布料回声弱，就在床底清扫时加配碰撞条。好的机器人方案不是堆最贵的零件，而是让每个传感器都在它擅长的环境里干活。
P: 现在你应该能回答本章标题的问题了：机器的感觉既可靠又不可靠——在合适的环境里精确到毫米，换个场景就可能满盘皆错。真正可靠的从来不是某个传感器，而是「承认感觉会错、并且准备了后手」的系统设计。
CALL: 动手实验 :: 用手机下载一个分贝测试应用，分别在安静房间和操场测量同一句话的音量读数，体会环境噪声如何影响「感觉」。

S: 小结与预告
P: 回顾本章：超声波听回声、红外看反光、摄像头读像素，各有绝活也各有盲区；噪声与干扰无处不在，多次确认、交叉验证、扬长避短是三大应对法。感觉这一环摸清了，接下来轮到大脑登场。
P: 光有感觉不会做决定，等于睁着眼睛发呆。收到「前方二十厘米有障碍」这条消息之后，机器人究竟怎么决定往左绕还是往右绕？什么时候该刹车、什么情况可以慢慢通过？下一章我们钻进机器人的大脑，拆解决策规则的写法与门道。
