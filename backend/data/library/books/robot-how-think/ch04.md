T: 从指令到动作：执行与反馈

S: 机器人的肌肉
P: 决策完成，轮到身体出场。把电信号变成动作的部件叫执行器，机器人世界里最常见的三位：马达让轮子转，负责走；舵机转到指定角度，负责手臂和转向；喇叭和屏幕负责表达。它们就是机器人的肌肉——大脑再聪明，肌肉不给力也寸步难行。|mark:执行器
@kp=robot-actuator
KC: 执行器 :: 执行器是把电信号转换成物理动作的部件，如驱动轮子的马达、控制角度的舵机、发声的喇叭。它决定了机器人最终能做什么动作。:: 生活里的例子 :: 游戏手柄的震动马达收到信号就嗡嗡震动手掌，一个微型执行器在替游戏「做动作」。
P: 「向右转九十度」这条指令落地时比想象中曲折。程序先给左右轮不同速度制造速度差，车身开始偏转；理论上转够九十度就停，可现实是地面可能滑、电池电压可能偏低、两侧马达出厂就有快慢差异。结果往往是转了八十五度或者九十七度，误差就这么混进来了。
P: 开环控制指只发指令不看结果的干法——喊一声「转九十度」就完事。它简单，但误差会一路累积：每段路偏三度，十个路口后机器人已经背对目标了。要走得准，必须请出本章主角。
FIG: 对比图分上下两栏：上栏「开环」是单向箭头，指令飞向小车后不再回头，小车轨迹逐渐偏离虚线目标；下栏「闭环」是指令与传感器读数之间画着一个循环圈，轨迹不断被拉回虚线 :: 开环一条道走到黑，闭环边走边修正——差的就是那根从传感器绕回来的线

S: 边走边改：反馈的魔法
@kp=feedback-control
KC: 反馈控制 :: 反馈控制是用传感器实时测量行动结果，与目标比较后不断修正输出的控制方式。它的口头禅是：测量、比较、调整，循环往复。:: 生活里的例子 :: 你骑自行车歪了会下意识扶正车把——眼睛提供反馈，身体完成调整，全程无需思考。
P: 反馈控制的思路朴素得惊人：别指望一次到位，边走边看边修。想让机器人沿墙走二十厘米，就让它每前进一小段都测一次距离，偏左了往右带一点，偏右了往左带一点。单次修正很小，但每秒几十次的持续微调，能让轨迹像被磁铁吸住一样贴着目标线。
P: 反馈的威力在于它能吃掉误差。轮子打滑？距离传感器发现位置不对，立刻补回来。马达力气不足？控制器自动加大输出。只要「测量—比较—调整」这个循环转得足够快，各种小误差刚冒头就被摁下去了。工业机械臂能稳定重复万次同样的焊接动作，全靠这套功夫。
P: 不过反馈也有翻车的时候。如果修正总是用力过猛——偏一点就猛打方向，机器人会左右摇摆越晃越大，这叫超调失控；如果反应太迟钝，又会慢吞吞追不上目标。调校修正的力度和时机是门手艺活，工程师们花在这上面的时间远超想象。
CALL: 动手体会 :: 端着一杯满满的水走十米，盯着杯面随时减速纠偏，再试一次全程不看杯子。哪次洒得少？你刚刚亲身体验了有反馈和无反馈的区别。

S: 小结与预告
P: 回顾本章：执行器是机器人的肌肉，指令落地必然带着误差；开环控制一条道走到黑，反馈控制用「测量、比较、调整」的循环把误差当场消化；修正力度要拿捏，过猛会摇摆，过钝会掉队。至此三大件全部拆解完毕。
