T: 两把钥匙的秘密：RSA 与公钥密码

S: 密码学两千年的死结
P: 加密的老思路是对称密码：同一把钥匙加密也解密。凯撒大帝把字母表移位通信，二战德军 Enigma 用转子机器，本质相同——加密解密共用一个秘密。这个方案有个两千年无解的死结：怎么把钥匙安全地送到对方手里？ Courier 送钥匙可能被截，提前商量又需要另一条安全信道——死循环。
P: 一九七六年，两位学者与一位数学家给出了颠覆性答案：为什么两个人要用同一把钥匙？如果用两把呢？一把只能锁、一把才能开——这就是公钥密码：公钥大喇叭公开给全世界，私钥锁在保险柜里绝不示人。任何人（包括从未谋面的陌生人）都能拿你的公钥上锁发信，但全世界只有你的私钥打得开。密钥配送的死结，就此解开。|mark:公钥密码

KC: 公钥密码 :: 公钥密码使用数学上关联的一对密钥：公钥公开用于加密或验证签名，私钥保密用于解密或签署；从公钥推算出私钥在计算上不可行。:: 生活里的例子 :: 把打开状态的挂锁免费发放给所有人：谁都能扣上箱子，但唯一能打开的钥匙在你自己手里。
KC: 单向函数思想 :: 正向计算容易、反向还原极难的单向性是现代密码学的地基：大数分解、离散对数都是这样的「易做难反」的数学题。:: 生活里的例子 :: 把玻璃杯打碎只需一秒，把碎片复原成杯子至今无人做到。

S: RSA：挂在数学上的锁
P: 次年问世的 RSA 是第一个实用的公钥体制，名字来自三位发明者的姓氏首字母。它的挂锁由两个大素数锻造：取两个几百位的素数相乘得到一个更大的数 N，N 就是公开材料的一部分；而「这两个素数分别是什么」是绝密的私钥材料。加密解密的具体运算用到模幂（先乘方再除以 N 取余数），方向恰好相反：公开的数加密，保密的数解密。

S: 安全性的来源：一道不可逆的数学题
P: 为什么敢把半把钥匙公之于众？因为从 N 反推那两个素数，等价于大数分解问题——把一个六百多位的合数拆回两个素因子。正向相乘一秒完成，反向分解以人类现有算法和算力则需要宇宙年龄量级的时间。单向的「易做难反」，正是 RSA 安全性的地基。这种不对称性在数学里叫单向函数思想，它是整个现代密码学的基石。
P: 公钥密码还有个惊艳的逆向用法：数字签名。用自己的私钥处理文件生成签名，任何人用你的公钥验证——验证通过即证明两点：文件出自你手（只有你有私钥）、内容未被篡改（改一个字签名就失效）。合同签署、软件更新校验、区块链交易，背后全是这一机制。
CALL: 想一想 :: 数字签名为什么同时证明了「身份」与「完整性」？如果有人中途篡改了被签名的文件，验证时会发生什么？
P: 动手体验一次非对称流程（概念版）：与同学约定各自准备一个「开盒规则」（如结果减七），互相交换「装盒规则」（如结果加七）；你用对方的装盒规则封好一张字条传过去，只有对方能用他的开盒规则读出。体会一下：装盒规则可以公开，开盒规则绝不外泄。

S: 小结与预告
P: 回顾本章：对称密码困于密钥配送千年；公钥密码用「公钥上锁、私钥开锁」的非对称对一举破局；RSA 的锁具锻造自两个大素数，安全性立于大数分解的单向困难之上；私钥反向使用即为数字签名，同时锁定身份与完整。
P: 至此我们解决了两人之间的信任问题。但如果要在一万台机器之间协同计算一份海量数据，信任与效率的双重挑战又当如何？下一章请出云计算时代的奠基算法：MapReduce。
