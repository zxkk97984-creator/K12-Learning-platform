S: 四位大师同台
KC: 不变量锚点 :: 伟大算法都找到了问题中不变的东西作为锚点：关系结构、非负权重、数学规律——变化世界里的可靠设计始于寻找不变量。:: 试一试 :: 想一想交通规则里哪些是不变的锚点。
KC: 大道至简 :: 伟大算法的核心规则都能写在便签上，复杂能力来自简单规则的反复作用；易理解、可验证、可移植让它们流传数十年。:: 试一试 :: 找一个你觉得复杂的系统，试着写出它最核心的一条简单规则。
P: 复习四位主角的绝活。PageRank：全网链接投票迭代收敛，回答「谁重要」。Dijkstra：贪心扩张逐点确认，回答「怎么走最近」。RSA：单向数学函数锻造非对称双钥，回答「如何信任陌生人」。MapReduce：映射归并并行容错，回答「规模大了怎么办」。四个问题、四套方案，风格迥异却同为传世之作。

S: 气质一：抓住不变量
P: 伟大的算法都找到了问题中「不变的锚点」。PageRank 抓住的是：无论网页内容如何变化，「被重要页面指向」这个关系信号长期有效。Dijkstra 抓住的是：权重非负时，「已确认节点无需反悔」永远成立。RSA 抓住的是数学规律的不变——大数分解不会因时代而变容易。变化的世界里寻找不变量，是所有可靠设计的起点。

S: 气质二：拥抱不对称与取舍
P: 四个算法没有一个是「全面最优」的，它们的伟大恰恰来自聪明的取舍。PageRank 放弃了内容分析换取抗操纵性；Dijkstra 用「不反悔」的武断换来效率；RSA 用巨大的计算开销换取免配送的安全性；MapReduce 干脆放弃单机完美主义，拥抱会坏的普通机器。工程学的智慧不在消除代价，而在选择值得支付的代价——并且清楚地知道放弃了什么。
CALL: 想一想 :: 生活中哪些设计体现了「主动选择值得的代价」？比如自动挡汽车牺牲操控自由换省力，还有别的例子吗？

S: 气质三：简单规则涌现复杂能力
P: 最令人着迷的气质：四个算法的核心规则都简洁到可以写在便签上，涌现出的能力却支撑起万亿级产业。PageRank 的更新规则一行；Dijkstra 的骨架四行；RSA 的思想一句话；MapReduce 的接口两个函数。复杂不是堆出来的，而是从简单规则的反复作用中生长出来的——这与生命从简单细胞演化出万物，遵循同一种美学。
P: 这也解释了为什么这些算法能流传几十年而不朽：简单的规则容易被理解、被验证、被移植到新领域。相反，靠无数补丁堆砌的复杂方案，往往在环境变化时第一个崩塌。做学问、写代码、乃至做人，大道至简都是同一层境界。

S: 全书回顾
P: 从 PageRank 到 MapReduce，本书带你检阅了人类算法殿堂的四根支柱，也重温了一条思维主线：面对看似不可能的问题（给全网排名、算最短路、公开加密、万机协同），先找到问题的特殊结构，再设计利用该结构的简单规则，最后接受必要的取舍。算法如此，人生亦然。
P: 这些算法的发明者当年面对的都是「不可能任务」，他们赢在拒绝承认不可能。愿你带着这份底气走出本书：下一个改变世界的伟大算法，或许正等待此刻正在读这行字的你来书写。
