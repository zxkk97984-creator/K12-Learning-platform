T: 给整个互联网投票：PageRank

S: 一个价值千亿的排序难题
P: 互联网有几上百亿个网页，搜一个词可能命中几百万条结果。怎么把「最值得看的」排到前面？早期的搜索引擎靠数关键词：页面出现这个词越多越靠前——结果被垃圾网站钻了空子，标题塞满热词、正文空洞无物。两位斯坦福研究生提出了一个天才的想法：别看网页自己说什么，看别人怎么链接它。这个算法就叫 PageRank。|mark:PageRank
@kp=pagerank-intuition
KC: PageRank 直觉 :: PageRank 把网页间的每个链接视为一次投票：被越多页面指向的页面越重要，而来自重要页面的投票分量更重；分数通过反复迭代收敛稳定。:: 生活里的例子 :: 学术论文的引用次数与引用期刊的档次共同决定其学术地位。
FIG: 一张网络节点图：五个网页圆点用有向箭头互连，其中节点 B 被四个箭头指入故画得最大最深，两个小节点只指向 B 并标注「它们的一票也因指向 B 而更有分量」 :: 链接就是选票：得票多者大，强者的票更重
P: 这个思想有两层精妙。第一层：链接即投票——网站主愿意在自己的页面上放你的链接，相当于公开为你背书，这比自吹自擂可信得多。第二层更重要：票不等值。被无数网站指向的权威页面，它投出的一票远比无名小站的一票有分量。于是重要性开始「流动」和「传播」：大站推荐谁，谁就沾光。

S: 迭代：让分数自己稳定下来
P: 每个页面的分数取决于指向它的页面的分数，而这些页面的分数又取决于指向它们的页面……鸡生蛋蛋生鸡，看似无解。解法朴素而深刻：先给所有页面随便发一个相同的初始分（比如都是 1），然后按规则整体更新一轮——每个页面把自己当前的分数平均分给它链接的所有页面；重复这个更新几十次后，奇迹发生了：全网的分数不再变化，收敛成一组稳定的排名。
P: 用伪代码描述只有四行：「将所有页面的分数初始化为相同值；重复足够多轮——每个页面把分数均分给它指向的每个页面，每个页面的新分数等于收到的所有份额之和；最后输出收敛后的分数作为排名依据」。这个迭代求解的过程值得每位学习者反复体会：不直接计算答案，而是从粗略猜测出发反复修正，让答案自己浮现。
P: 这就是数学家所说的迭代求解：不直接算出答案，而是从一个粗略猜测出发反复修正，让答案自己浮现。工程上只需几十轮迭代全网分数就基本稳定——用可接受的计算量换来了覆盖全球的权威度评估。
CALL: 想一想 :: 手动模拟三个页面的小网络：A 链接到 B 和 C，B 只链接 C，C 只链接 A。凭直觉猜哪页分数最高，再按伪代码迭代三轮验证。

S: 现实世界的修正与启示
P: 理想模型有个漏洞：两个互相链接的页面会把自己的分数来回倒手，谁也不往外传，形成「分数黑洞」。工程解法叫阻尼因子：假设每位网民有百分之十五的概率不看链接、随机跳到任意页面，为全网注入一点「随机冲浪」的能量，保证每页至少有保底分数。一个小补丁，堵住一个大漏洞。
P: PageRank 的启示远超搜索。它证明了一件事：一个系统中每个个体的价值，可以由它与其他个体的关系结构计算出来——社交网络的账号影响力、论文的学术评价、电商店铺的可信度，背后都是同类思想的变体。学会「从关系结构中提取价值信号」，你就掌握了分析复杂系统的一把万能钥匙。
CALL: 动手推演 :: 构造一个五页面的迷你网络并手工迭代两轮 PageRank，观察分数如何从均匀分布逐渐分化；找出你网络里的「枢纽页」——理解了它，后面的学习会顺畅许多。。
KC: 迭代求解 :: 迭代求解不直接计算答案，而是从粗略猜测出发按规则反复修正，让结果逐步逼近并稳定在真值附近。:: 试一试 :: 从 1 开始反复取「一半加三」十次，观察数值走向稳定。
CALL: 动手挑战 :: 如果你是作弊者，想让自己的垃圾页面获得高分，你会怎么做？再站在搜索引擎角度设计一条反制措施——攻防两端都想一遍，才算真懂。

S: 小结与预告
P: 回顾本章：链接即投票、票不等值、迭代收敛是 PageRank 的三大支柱；阻尼因子修补分数黑洞；它的本质是从关系结构中提取价值信号，应用远超搜索领域——这个细节常常被初学者忽略。。
P: 排序解决「谁重要」，但生活中还有另一类问题：从 A 到 B 怎么走最省？下一章的主角 Dijkstra 算法，是导航软件心脏里的引擎——动手试过之后体会会更深刻——这一点值得每位学习者反复体会。。
