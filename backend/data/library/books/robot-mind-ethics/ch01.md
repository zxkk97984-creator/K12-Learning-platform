T: 从工具到伙伴：机器人伦理为何特殊

S: 锤子的伦理学不存在，机器人的存在
P: 我们从不讨论「锤子该不该砸人」——工具没有行为能力，责任全在使用者。但机器人不同：它能在无人实时指挥的情况下自主决定行动。当一台配送机器人为避让行人而撞翻货摊，责任在写代码的工程师、批准上路的运营方，还是「做决定」的机器本身？这种由自主性带来的责任模糊地带，正是机器人伦理的独特起点。|mark:机器人伦理
@kp=autonomous-decision-making
KC: 自主决策 :: 自主决策指机器在没有人工实时干预的情况下，依据程序与感知自行选择行动方案；决策越自主，「是谁干的」就越难回答。:: 生活里的例子 :: 自动驾驶等级越高，人类司机介入越少——出事时的角色也从操作者滑向旁观者。
FIG: 一条光谱轴：左端是锤子（完全受控、责任全在人），右端是一个自主行走的机器人（高度自主、责任模糊），轴上依次排列恒温器、扫地机、自动驾驶汽车，位置越靠右标注「责任归属越难」 :: 从工具到伙伴不是一步跨越，而是一条连续的光谱
P: 机器人的特殊还在于它作用于物理世界。聊天 AI 说错话顶多误导人；一台手术机器人出错则直接关乎生命。物理世界的错误不可撤销——这正是为什么机器人伦理的讨论总是从高风险场景开始：车、刀、武器。
CALL: 想一想 :: 把你家里的设备按「自主程度」从低到高排一条光谱：台灯、电饭煲、扫地机器人、智能音箱。你的排序标准是什么？

S: 三个真实的伦理现场
P: 现场一：仓库机器人把员工困在货架之间——事故调查发现安全协议被人为了赶工关闭。现场二：陪伴机器人对独居老人说「我永远是你的朋友」，老人逐渐拒绝真人探访。现场三：某国宣布研发自主选择目标的武器系统，引发全球科学家联名抵制。三个现场指向三种不同的伦理张力：安全与效率、真实与替代、力量与克制。
P: 这些现场共同说明：机器人伦理不是遥远的哲学思辨，而是正在发生的工程决策。每一份产品需求文档里的取舍，都是一次微型的道德立法。工程师写下「优先保护车内乘客」还是「平等保护所有道路使用者」时，他其实是在替整个社会回答伦理问题。
P: 动手建立你的分析框架。给每个伦理现场标注三要素：谁受益、谁承担风险、谁有权决定。完成三份标注后对比——你会发现多数争议的本质，是三者严重错位：受益的不担险，担险的无权决定。
KC: 伦理三要素分析 :: 分析机器人伦理争议的三要素框架：谁受益、谁承担风险、谁有权决定；多数争议的本质是三者的严重错位。:: 试一试 :: 用三要素分析「外卖平台算法压缩配送时间」事件。
CALL: 动手实践 :: 找一则近年的机器人相关新闻，用三要素框架写一份一百五十字的分析卡。

S: 小结与预告
P: 回顾本章：机器人的自主性造成传统「工具—使用者」责任框架的失灵；它作用于物理世界且不可逆，因此伦理讨论聚焦高风险场景；受益者、风险承担者与决策权的三方错位是争议的普遍结构。
P: 接下来四章深入四个最尖锐的现场。第一个就是那个被讨论了半个世纪、如今必须写进代码的问题：当刹车来不及，该撞谁——这个练习会揭示三要素错位的普遍性。
