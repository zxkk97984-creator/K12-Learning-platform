T: 手术台上的机器手：谁为医疗机器人负责

S: 一台机器的手术日记
P: 某三甲医院的手术室里，一台腔镜手术机器人正在辅助完成一台胆囊切除。机械臂在主刀医生的操控下精准缝合，震颤过滤功能让动作比人手更稳。手术很成功——但请思考一个假设性问题：如果机械臂在关键步骤出现异常移动造成损伤，该追责谁？医生？医院？设备厂商？还是算法？

KC: 医疗机器人问责 :: 医疗场景的责任链条须事先书面明确：医生对医疗决策负责，医院对使用规范负责，厂商对设备缺陷负责；「机器干的」不能成为任何一方的免责理由。:: 生活里的例子 :: 飞机自动驾驶时代，机长仍是安全的第一责任人——航空业的成熟经验正被医疗界借鉴。

S: 辅助与替代的天壤之别
P: 医疗机器人目前绝大多数处于「辅助」定位：医生决策、机器执行或建议。达芬奇手术系统的每一刀都由外科医生实时操控；影像 AI 给出可疑病灶提示，最终诊断由医生签字。这条边界至关重要：辅助模式下责任链清晰（医生主导）；一旦滑向替代模式（机器自主诊断并实施），现有法律与伦理框架都会失灵。
P: 为什么不干脆让机器替代？三个理由。其一，误判责任无人承担：AI 可以给出概率，但「是否手术」这种价值权衡必须由能负责任的人做出。其二，罕见情形缺乏训练数据，机器的自信可能建立在侥幸上。其三，患者知情权：你有权知道给自己开刀的是谁——包括那不是「谁」而是一台机器的情形。

CALL: 想一想 :: 如果一台诊断 AI 的准确率在特定人群中被证实偏低，医生还应该参考它的意见吗？参考到什么程度算尽到了责任？

S: 知情同意的新内涵
P: 传统知情同意告知的是「手术风险」；机器人参与后还要加一条：「这台手术将由医生操控机器人辅助完成」。这不是走形式——患者有权知道器械因素已被引入风险结构。同理，AI 参与读片时，报告应注明「AI 辅助阅片，医师复核」。透明本身就是一种治疗：知道流程的患者，信任度和配合度都更高。
P: 动手分析一个真实案例框架。某医院引进骨折手术导航机器人后发生一次固定位置偏差，患者要求赔偿。请列出调查清单：术前影像是否校准（医院）、设备当日状态与维保记录（厂商）、医生是否按规程确认了定位（医生）。你会发现三方的证据共同拼出真相——这正是事前明确责任链条的意义。
KC: 知情同意新内涵 :: 机器人参与医疗时，知情同意须额外告知器械的参与方式与相关风险；透明的流程描述本身就能提升患者的信任与配合度。:: 生活里的例子 :: 报告上注明「AI 辅助阅片，医师复核」让患者明白每一步由谁负责。
CALL: 动手实践 :: 为「AI 辅助阅片」设计一份给患者的知情同意要点清单，不超过五条，语言要让初中生也能看懂。

S: 小结与预告
P: 回顾本章：医疗机器人几乎全部处于辅助位，责任链须事先书面划分——医生管决策、医院管规范、厂商管设备；替代模式的三大障碍是责任真空、长尾风险与知情权；透明告知本身就有治疗效果。
P: 离开严肃的手术室，下一站是温馨的客厅：会陪聊天的机器人、哄老人的陪伴娃娃。它们带来安慰的同时，也带来了这本书里最柔软也最尖锐的问题——被机器安慰，算是被爱吗？
