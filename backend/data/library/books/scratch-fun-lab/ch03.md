T: 会说话的小猫

S: 给小猫一张嘴
P: 紫色分类里住着外观积木，今天的主角是「说 你好！2 秒」。把它拼在绿旗下面，点击绿旗，小猫头顶会冒出一个气泡框，显示你想让它说的任何话。把「你好！」改成「今天也要加油鸭」，它就替你说心里话。气泡框两秒后自动消失，数字可以随便改，想说什么全听你的。
P: 「说」旁边还有个兄弟叫「想」，用法一模一样，只是气泡框形状变成了云朵，像小猫在心里嘀咕。什么时候用「说」什么时候用「想」？表演台词用「说」，内心戏用「想」——你现在是导演，这些细节由你决定。
FIG: 舞台上的小猫头顶冒出两个气泡：一个是圆角方形的「说」气泡写着「你好呀！」，一个是云朵形状的「想」气泡写着「今天吃什么」，旁边配着「切换造型」积木让小猫摆出不同姿势 :: 说出来的是台词，想的是心事——两种气泡让你的角色更有戏
P: 小猫其实有两张「脸」：两个造型，一个张着嘴，一个闭着嘴。找到「换成 造型2」这块积木拼上，再点绿旗——咦，好像看不出变化？因为切换太快了！在两次换装之间加一块黄色的「等待 0.5 秒」，小猫就开始一开一合地「打拍子」了。
CALL: 想一想 :: 为什么中间要加「等待」积木？如果把 0.5 秒改成 0.1 秒，小猫的嘴巴会变成什么样？动手试试，观察快慢的区别。

S: 让实验室热闹起来
P: 光有画面没有声音怎么行？粉色分类是声音积木的家。「播放声音 喵」能让小猫真的叫一声；点左下角的声音标签页，还能给角色录音或从素材库里挑鼓掌、欢呼声。给跑步的小猫配上「喵」声，你的作品立刻从默片变成动画片。|mark:声音积木
P: 声音还能自己录！点开声音标签页里的录音小喇叭，对着麦克风说一句「你好呀」，这段录音就成了小猫的新台词。用自己录的声音做出的作品，拿给家人看时特别有面子——他们会惊讶程序里居然藏着你的嗓音。
P: 把今天的积木组合一下：绿旗开关、「重复执行 10 次」口袋里装上「移动 10 步」「碰到边缘就反弹」「播放声音 喵」「等待 0.5 秒」。点绿旗——一只边跑边叫的小猫满台乱窜，是不是特别有成就感？
P: 这里藏着一个重要的秘密，你发现了吗？口袋里的积木是一块接一块轮流干活的：先走一步，再检查边缘，然后叫一声，等半秒，再回到第一步。这种从上往下一块块执行的规矩叫顺序执行，它是所有程序的底层节奏。顺序变了，效果就完全不同——不信把「等待」挪到最前面试试。|mark:顺序执行

KC: 切换造型 :: 每个角色可以准备好几张「脸」，切换造型积木能让它在这些样子之间来回变换，快速连起来就像放动画一样。:: 试一试 :: 小猫自带两个造型，交替切换再加一块等待积木，它就开始一开一合地动嘴巴说话啦。
KC: 顺序执行 :: 顺序执行就是从上往下，一块积木做完再做下一块。就像做操口令：先抬左手，再抬右手，顺序乱了动作就不对劲。:: 生活里的例子 :: 泡面的步骤先烧水再放面，要是反过来，面可就泡不熟了。
CALL: 动手挑战 :: 编一段「小猫自我介绍」程序：走到舞台中央，说自己的名字，换个造型，再放一个掌声。想想哪块在前哪块在后，顺序能随便换吗？

S: 小结与预告
P: 今天小猫学会了说话、变脸和叫唤，你也收获了一个重要概念：积木是从上往下按顺序执行的，先后次序就是节目单。现在的实验室已经很热闹了，但小猫只会自己玩，不理人——你按空格键它也不理你。
P: 下一章我们让程序学会「看人下菜碟」：按下空格才跳，碰到苹果才得分。还会请出一位神秘嘉宾——记分牌！它会牢牢记住你得到的每一个分数，让游戏有了输赢的滋味。游戏的心脏就要登场了，请准备好你的双手和脑瓜。
CALL: 下一章预告 :: 程序学会做选择——如果…那么…积木加计分变量，真正的游戏要来了。
