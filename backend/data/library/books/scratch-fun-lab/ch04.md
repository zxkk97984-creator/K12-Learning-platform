T: 神奇的如果和重复

S: 程序也会看情况办事
P: 放学回家，你心里也在跑程序：如果作业写完了，就看电视；否则继续写作业。Scratch 里有一块一模一样的积木，橙色控制类别里的「如果…那么…」。它像一个带条件的小门：条件成立，门里的积木才运行；不成立，就悄悄跳过去。|mark:如果
P: 条件从哪来？绿色分类里有专门问问题的积木：「碰到 鼠标指针？」「按下 空格键？」它们不做事，只负责回答「是」或「不是」。把问题积木塞进如果积木的六边形缺口里，一套完整的判断就装好了：如果按下了空格，那么小猫跳一下。
FIG: 积木图：「如果 按下空格键？ 那么」的门里装着「将 y 坐标增加 50」，门外画着一条虚线路径标注「条件不成立时跳过」；旁边一个记分牌图标显示得分 0 :: 如果积木是一扇门：问题答「是」才放行，答「不是」就走旁边的路
P: 还有个升级版叫「如果…那么…否则」，它多了另一扇门：条件成立走这边，不成立走那边，两条路必走其一。比如：如果得分大于 10，说「你真棒」；否则说「继续加油」。有了它，程序就能对不同的情况给出不同的反应，聪明劲儿立刻不一样了。
CALL: 想一想 :: 红灯停、绿灯行，用「如果…那么…否则」该怎么写？条件是什么？两条路分别做什么？说给同桌听听。

S: 让小猫听你的指挥
P: 来做个小实验：拼上「如果 按下 → 键？那么 右转 15 度」，再拼一块「如果 按下 ← 键？那么 左转 15 度」。点击绿旗后按方向键——小猫居然听懂了你的遥控！这里有个新朋友要介绍：事件积木里的「当按下空格键」也能响应按键，但它俩脾气不同。
@kp=event-block
KC: 事件积木 :: 事件积木是程序的启动开关，像「当绿旗被点击」「当接到广播消息」。它一被触发，下面连着的积木就自动开始运行。:: 试一试 :: 把「当按下空格键」和「播放声音 喵」拼在一起，每次敲空格小猫都叫一声。
KC: 碰到与侦测 :: 「碰到 鼠标指针？」「碰到边缘？」这些问话积木负责替程序观察四周，回答永远只有两种：是，或者不是。它们自己不做动作，只负责把看到的情况报告给如果积木。:: 生活里的例子 :: 过马路前先看一眼左右，「有没有车来？」答案决定你迈不迈步。
P: 「当按下某键」是独立开关，平时待机，按键瞬间才干活，适合做一次性动作；而「如果按下某键」住在循环口袋里，每圈都要检查一遍，适合持续控制。想让角色一直被你操控，就把如果积木放进「重复执行」口袋里，让它一圈一圈不停地盯着你的手指。
P: 顺便认识最后一位主角的雏形：侦测。「碰到 鼠标指针？」「碰到边缘？」这些问话让程序长出了触角，能感知舞台上发生的一切。游戏里「苹果被碗接住了没有」，靠的就是「碰到」这类问题。感觉加判断加行动，你的程序已经像个小小的机器人了。
CALL: 动手挑战 :: 给小猫装上四个方向的遥控：上下左右键分别控制它朝四个方向移动。提示：移动可以用「将 x 坐标增加」和「将 y 坐标增加」。

S: 小结与预告
P: 今天你拿到了两件神器：如果积木让程序学会看情况办事，重复执行让程序不知疲倦地值守。两者组合——在循环里不停判断按键和碰撞——就是所有小游戏的心脏。万事俱备，只欠一个真正的作品。
P: 下一章我们正式开工：接苹果游戏！苹果从天上掉下来，你用碗左右奔跑去接，接住一个加一分，看谁的分数更高。别担心难度，前面四章学过的本领，一块积木都不会浪费，它们马上要一起上场表演了。
CALL: 下一章预告 · 全书大项目开工 :: 计分牌、下落的苹果、会动的碗——五分钟后你就是游戏制作人。
