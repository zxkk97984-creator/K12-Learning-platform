T: 你好，小猫！——认识新朋友

S: 认识你的新实验室
P: 打开 Scratch，你会看到一块大大的空白区域，它叫舞台。舞台就是表演的地方，所有好玩的事情都在这里发生。舞台上站着一只橘色的小猫，它是这里的第一个演员，名字叫角色。以后你还可以请恐龙、火箭、蛋糕上台，它们也都是角色。|mark:舞台
@kp=scratch-stage
KC: 舞台与角色 :: 舞台是程序表演的地方，角色是在台上活动的演员。每个角色有自己的积木脚本，谁拿到积木，谁就照着做动作。:: 生活里的例子 :: 舞台像学校的操场，角色像做操的同学，每个同学听自己的口令做自己的动作。
KC: 程序是什么 :: 程序就是写给计算机的任务清单，一条一条说清楚先做什么、再做什么。计算机只照清单办事，不会自己猜你的心意。:: 生活里的例子 :: 便条上写着「先写作业，再看动画片」，这就是妈妈给你下的一份程序。
P: 再认识两个好帮手。屏幕左边是积木仓库，各种颜色的积木按类别排好队：蓝色的管运动，紫色的管外观，黄色的管事件。屏幕中间是搭积木的地方，把积木拖过来拼在一起，程序就写好了。对，写程序在这里就是拼积木，不需要打字，也不会拼错单词。
P: 颜色还能帮你记功能呢。蓝色像天空，让角色飞来飞去；紫色像魔法斗篷，负责变脸和说话；粉色像小喇叭，专管声音；黄色像小闹钟，一有事情发生就喊大家起床。以后找积木时先想颜色，速度能快一大截——这可是实验室里人人都在用的小窍门。
FIG: Scratch 界面示意图：左侧是彩色积木仓库，中间是拼积木区，右侧大块区域是舞台，一只小猫站在舞台中央，右上角有一个绿色小旗子和红色停止标志 :: 三块宝地：左边挑积木，中间拼积木，右边看表演
P: 先来认识最重要的两块积木。黄色分类里有一块写着「当 ▶ 绿旗被点击」，它是程序的开关；只要有人点一下舞台右上角的绿旗，这块积木后面的所有积木就会立刻开工。没有它，你拼的积木再多也只是躺在那里睡觉。
CALL: 想一想 :: 为什么每段程序的头顶都要放一面「绿旗积木」？如果忘了放会怎样？动手试一试：随便拼几块积木，不放假绿旗，点绿旗看看有没有反应。

S: 第一次动手
P: 来做你的第一个程序吧，一共三步。第一步，从黄色分类里把「当 ▶ 绿旗被点击」拖到中间的拼积木区。第二步，从蓝色分类里找到「移动 10 步」，把它拖过来，轻轻靠在绿旗积木下面，听到咔哒一声就拼好了。第三步，点一下舞台右上角的绿旗。
P: 看到了吗？小猫向前走了一小步！再点一次，它又走一步。恭喜你，你已经会写程序了——真的，刚才那三步就是一个完整的程序：开关、指令、运行，一样不少。编程没有那么神秘，就是把你想让计算机做的事，用积木一条条说清楚。
P: 小提示：积木拼错了怎么办？把它拖回左边的仓库就拆掉了，或者点舞台上方的撤销小箭头，一切回到刚才的样子。Scratch 里没有真正的「搞坏」，只有还没调好的效果。所以别怕动手，每一位编程高手都是从乱点一气开始的。
P: 大胆玩一会儿。把 10 改成 100 会怎样？小猫一步跨出老远，甚至跑出了舞台边缘。改成 1 呢？它挪得比蜗牛还慢。数字是积木里的调味料，咸淡全由你定。别担心出错，改错了随时可以拖回仓库或点撤销，大胆乱点是学编程最好的方法。
P: 还有一件重要的事：记得保存。点菜单里的保存，给你的作品起个名字，比如「我的第一只小猫」。下次打开还能继续玩。程序员都有随手保存的好习惯，你也从今天开始养成吧。万一哪天电脑突然关机，保存过的作品还稳稳地待在硬盘里等你，那种安心的感觉，试过一次就忘不掉。
P: 今天你认识了舞台和角色，学会了用三步做出第一个程序，还知道了积木仓库按颜色分类的小秘密。这些看起来很简单，却是所有编程高手共同的第一步。下节课，我们要让小猫动得更帅：连续奔跑、原地转圈、还会在舞台边缘帅气掉头回家，敬请期待！
CALL: 动手挑战 :: 让小猫一次移动 50 步，再让它移动负 50 步（就是 -50）。观察两次有什么不同，猜猜负号是什么意思。

S: 小结与预告
P: 今天你认识了舞台和角色，学会了三步做出第一个程序：放绿旗开关、拼运动积木、点击运行。你还发现了 Scratch 最友好的一点——怎么试都不会坏。下节课，我们要让小猫动得更帅：走路、转圈、还会掉头回家。
