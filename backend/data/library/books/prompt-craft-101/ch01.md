T: 提示词是什么：和大模型对话的语言

S: 同一个问题，两种命运
P: 先看一场对比实验。同学甲输入：「帮我写个东西。」AI 回了一篇不痛不痒的通用段落。同学乙输入：「请用初中生能懂的语言，写一段八十字的短文解释什么是回声，举一个山谷喊话的例子。」AI 的回答准确、生动、长度刚好。同一个模型，输出天差地别——差别全在输入——这个输入有个正式的名字：提示词。|mark:提示词
@kp=prompt-definition
KC: 提示词定义 :: 提示词是你发给大模型的全部文字信息，包括问题、要求与背景说明。它相当于给模型的临时任务说明书，写得越清楚，回答就越贴近你的真实需要。:: 生活里的例子 :: 对裁缝说「做件衣服」和「做件蓝色校服裤，腰围二尺一」，成品自然不同。
KC: 概率靶心 :: 模型按概率续写：提示词越具体，候选答案的范围就越窄，好答案被顶到最前面；越模糊则可选空间越大，回答也就越平庸。:: 试一试 :: 分别用「写首诗」和「写一首关于秋日校园的四句押韵短诗」提问并对比。
FIG: 上下两路对照图：上路输入一句模糊的话「帮我写个东西」，箭头通向灰色问号输出；下路输入一段四行的详细指令，箭头通向一份结构工整的答案卡片 :: 输入决定输出：模型是面镜子，你给它什么清晰度，它还你什么清晰度
P: 为什么会这样？回忆语言模型的原理：它按概率续写。模糊的提示词对应着无数种可能的理解，模型只能挑最平庸的那种；具体的提示词大幅收窄了可能空间，好答案的概率被顶到了最前面。所以提示词不是玄学，而是给概率分布画靶心。
CALL: 想一想 :: 为什么「帮我写个东西」注定得到平庸回答？如果模型反问你「你想写什么」，这算不算一次自动的提示词改进？

S: 提示词是一门手艺
P: 有人把写提示词叫「咒语」，暗示念对字眼就有魔力——这个比喻要纠正。提示词的本质是沟通：把你脑中的任务讲清楚。凡是能提升人与人沟通质量的技巧（说背景、定标准、给例子），都能原样迁移到人与模型的沟通上。它是一门可学习、可练习的手艺，不是口诀。
P: 这门手艺的价值正在快速上升。会用 AI 的人与不会用的人，产出差距已经拉开；而拉开差距的关键变量恰恰是提示词水平。未来职场里，「会不会提问」很可能像「会不会搜索」一样成为基础素养。现在开始练，正是时候。
P: 不过先立一条使用底线：学校作业要遵守老师的规定。可以用 AI 帮你列提纲、检查语法、提供思路，但代替你完成的作业既违反诚信，也剥夺了你练基本功的机会。工具再强，成长无法代劳。
P: 光看不练假把式，这一章留了一个必做的观察作业。找一个你能使用的 AI 聊天工具，先后发送本章开头那两条提示词，仔细对比两次输出的差异，把观察记在本子上：哪一次更可用？差距体现在准确性、结构还是语气？这个五分钟的小实验，是全书一切技巧的共同起点。
CALL: 动手实验 :: 把「介绍一下光合作用」改写成一条能让回答适合讲给小学生听的提示词，动手试一试并记录改动前后的差别。

S: 小结与预告
P: 回顾本章：提示词就是发给模型的全部输入，其质量直接框定回答的上限；它的本质是把任务讲清楚的沟通能力；同时记得守住学术诚信的边界——把四要素、角色、示例这些关键词先记在心里，后面章节会一一展开。。
P: 既然「讲清楚」是核心，那到底怎样才算讲清楚？有没有可以套用的公式？下一章给出一个经过大量实践检验的答案：清晰指令四要素——它不神秘也不复杂，只要按图索骥，人人都能写出高质量的提示词。。
