T: 给 AI 一个身份：角色设定

S: 一句话改变整场对话
P: 在提问前先加一句：「你是一位有十年经验的初中科学老师。」然后再问「为什么天空是蓝色的」。对比不加这句的版本，你会发现两次回答的差别肉眼可见：后者更像百科词条，前者会举课堂例子、预判学生的疑惑点、语气也更循循善诱。这个前置的身份声明就是角色设定。|mark:角色设定
@kp=role-setting
KC: 角色设定 :: 角色设定是在提示词开头为模型指定一个具体的身份或观察视角，引导它调用该身份典型的语言风格、知识侧重与思考方式来完成当前任务。:: 生活里的例子 :: 让厨师和营养师分别点评同一道菜，两人开口的侧重点完全不同。
KC: 角色三细节 :: 好角色要做到三点：具体说明擅长领域、描述当前所处处境、并且与任务性质匹配；帽子戴错场子，回答就会明显跑偏。:: 试一试 :: 把「你是专家」升级成一句具体可用的角色设定。
FIG: 一顶帽子变形图：同一台机器人头顶依次戴上三顶帽子——「科普作家」「严格编辑」「幽默段子手」，每顶帽子下方对应一段风格迥异的同题回答片段 :: 换帽子即换风格：身份是调取不同语言模式的开关
P: 原理不难理解：模型读过海量文本，「资深教师如何讲解」与「百科全书如何陈述」在它的训练数据里本来就是两种分布。角色设定的作用是把回答拉进其中一种分布——相当于先选定参考书的书架，再从中取词。
P: 角色设定的三个高价值场景。第一，定专业度：「你是高中物理竞赛教练」比泛泛提问更容易得到深入解释。第二，定风格：「用轻松幽默的口吻」或「像给董事会汇报一样严谨」，一句话切换文风。第三，定立场：让它扮演辩论的反方帮你检验论证漏洞——这是准备辩论赛的利器。
CALL: 想一想 :: 为什么「扮演一位医生」可能给出更专业的建议，却不能替代真正就医？从训练数据的角度想想这种角色的能与不能。

S: 写好角色的三个细节
P: 第一，具体胜过宽泛。「你是一位擅长把复杂概念讲给中学生听的科普作者」远好于「你是一个专家」——前者自带风格与受众信息。第二，可以叠加任务相关的处境：「你正在批改学生作文，需要指出问题但保护写作热情」，处境会让输出更有分寸。第三，角色要与任务匹配：让「诗人」改代码就跑偏了，帽子别戴错场子。
P: 把角色设定与上一章的四要素组合，就能写出结构完整的专业级提示词。以修改作文为例：「你是一位中学语文老师（角色）。以下是我写的议论文（背景）。请指出论据不足的三处并说明理由（要求），用『原文引用＋修改建议』的格式逐条列出（格式）。」四要素加一顶帽子，一次到位的概率大大提高。
P: 动手试一场角色对比赛。选同一个问题，比如「怎样背单词更高效」，分别以三种角色提问：记忆研究专家、英语满分学长、幽默的脱口秀演员。收集三份回答做成对照表，观察专业侧重、语气和实用建议的差异，你会对「角色即视角」有直观体会。
CALL: 动手实验 :: 设计一个对你当前学习最有帮助的角色设定，写清专长、风格与受众三要素，用它连续完成三次真实提问并评估效果。

S: 小结与预告
P: 回顾本章：角色设定通过指定身份调动模型的不同语言分布；它能在专业度、风格与立场上快速切换输出；写好角色的关键是具体、有处境、与任务匹配；它与四要素组合构成完整的提示词骨架。
P: 骨架有了，还差一块高级积木：当你要模型稳定输出某种特定格式时，光描述往往不够，最好直接给它看几个例子。这就是下一章的主角——少样本示例。
