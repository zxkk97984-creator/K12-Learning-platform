T: 清晰指令四要素

S: 把「讲清楚」拆成四块
P: 「讲清楚」三个字太抽象，需要拆开。观察大量高质量提示词，会发现它们几乎都包含四个部分：任务——做什么；背景——基于什么信息；要求——有什么约束或标准；格式——输出长什么样。四要素就像搭积木的四块基础件，缺哪块，回答就往哪个方向跑偏。|mark:四要素
@kp=instruction-elements
KC: 清晰指令四要素 :: 清晰指令四要素指任务、背景、要求与格式：做什么事、基于什么信息、有什么约束标准、输出呈现成什么样子。:: 试一试 :: 用四要素检查你最近发给 AI 的一条消息，数数缺了几块。
KC: 缺啥补啥三问 :: 检查提示词时问自己三句：它知道背景吗？知道好坏标准吗？知道输出样式吗？哪问答不上来就补哪个要素。:: 试一试 :: 用三问找出「帮我改作文」缺失的要素。
FIG: 四块积木依次拼合：第一块「任务：写一段自我介绍」，第二块「背景：用于初中社团面试」，第三块「要求：突出绘画特长，一百字以内」，第四块「格式：分两段」；拼完上方出现一个对勾 :: 四块积木拼齐，模糊的愿望就变成了可执行的任务单
P: 看一组真实可复现的对照。只有任务：「帮我推荐一本书。」模型只能瞎猜你的口味。补上背景：「我是初三学生，刚读完《三体》很震撼。」立刻精准了许多。再加上要求：「推荐一本科幻经典，并说明和《三体》的异同。」最后限定格式：「用三句话回答。」四块齐了，输出基本一步到位。
P: 四要素不必每次全上，但越重要的任务越要配齐。判断缺哪块有个自查句式：把提示词读一遍，问自己三个问题——它知不知道具体情况（背景）？知不知道做到什么程度算好（要求）？知不知道交付物长什么样（格式）？哪问答不上来就补哪块。
CALL: 想一想 :: 「帮我改作文」这条提示词缺了哪些要素？至少找出两处，想想缺失分别会导致什么样的跑偏。

S: 要素的高级用法
P: 要求这块积木里藏着几个高价值技巧。给正反例：「避免使用『非常』『特别』这类空泛副词」比「写得生动些」有效得多——模型更擅长遵守具体禁令。设定受众：「讲给完全没接触过编程的高一学生听」会自动调整术语密度。限定长度与结构：「三点原因，每点不超过三十字」让输出稳定可控。
P: 背景的精髓是替模型省去猜测。你要它续写故事，就把前文梗概给它；要它分析成绩，就把数据贴给它。一个实用原则：凡是「你知道而它不知道」且影响任务的信息，都值得写进去。信息多给不扣分，漏给必跑偏。
P: 格式则决定了成果能不能直接使用。需要放进表格的内容，明确说「用表格输出，列名为名称、优点、缺点」；需要逐步讲解的，说「按步骤编号」。格式指令相当于提前验收，把「整理排版」这道工序从对话里省掉。
P: 动手组装一次完整指令。任务：为班级设计一份读书角海报文案。请按四要素写出完整提示词——背景里写明班级特点，要求里限定字数与语气，格式里规定标题加正文的样式。写好后实际发送，对照输出打分：每一要素都兑现了吗？
CALL: 动手挑战 :: 找一位同学互相出题：一人描述一个模糊需求，另一人用四要素把它改写成高质量提示词，最后对比两次输出的差距。

S: 小结与预告
P: 回顾本章：四要素——任务、背景、要求、格式——是把「讲清楚」操作化的框架；对照实验证明要素齐全与否直接决定输出质量；自查三问帮你快速定位缺失；高级用法在于给出具体的正反例与明确的受众和结构。
P: 四要素解决了「说什么」，但同样的话用不同身份说出来效果迥异。「你是一位资深科普作家」这短短一句话，为什么能显著改变回答的风格与深度？下一章揭秘角色设定。
