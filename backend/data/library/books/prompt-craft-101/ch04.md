T: 少样本示例：教它模仿

S: 描述一百遍，不如示范一遍
P: 想让 AI 把一堆句子改写成押韵标语，你写了三百字描述「要朗朗上口、对仗、有力量感」，结果它给的版本总是差点意思。换一种方式——直接给它两个改好的例子：「原句：保护环境人人有责 → 标语：绿水青山，你我共守。原句：按时作息身体好 → 标语：早睡早起，元气满格。」然后说「照这个风格改写下面的句子」。效果立刻判若两人。

KC: 少样本示例 :: 少样本示例是在提示词中附上两三个输入输出的完整示范，模型会从中归纳格式与风格规律并套用到新输入上，比纯文字描述更稳定。:: 生活里的例子 :: 老师批改作文时先贴一篇范文，学生照着结构写，比听十遍写作要领都管用。
FIG: 一张流程对照图：上路是长长的文字描述框指向歪歪扭扭的输出；下路是两个整齐的示例卡片加一句「照此办理」，箭头直指格式完全一致的输出 :: 描述靠猜，示例靠抄——模仿是人类和模型共同的快速学习通道
P: 为什么示例这么有效？回到模型的本质：它就是从海量文本中学习模式的机器，而示例正是最浓缩的模式表达。「输入长这样、输出长那样」的对应关系里，隐含了语气、长度、结构、用词偏好等全部细节，比任何文字描述都无损。描述会有歧义，示例不会撒谎。
CALL: 想一想 :: 给几个例子之后模型输出格式稳定了，但内容质量就一定高吗？格式与内容的控制分别靠什么手段？
P: 示例的数量与挑选都有讲究。通常两到三个足够，太多则提示词冗长且收益递减；例子之间要有差异性，覆盖不同情况（一个短句例子、一个长句例子），模型才能学到规则的边界而不是死记特例。最关键的一条纪律：示例本身必须是你真正满意的水平——模型会忠实复制你的毛病。

S: 进阶玩法
P: 少样本还有个兄弟叫零样本：不给例子，只给清晰的指令描述。什么时候用哪个？规则很简单：常规任务（总结、翻译、解释）零样本足够；需要特定格式或独特风格的任务上少样本。两者还能叠加——先角色设定，再四要素指令，最后附示例，这是处理复杂任务的标准三段式。
P: 示例的质量决定模仿的上限，这句话值得单独强调。你给的例子里如果有错别字，输出大概率也带着同样的错别字；例子结构松散，输出的结构也好不到哪去。所以动手写示例前先问自己：这两三个示范，经得起逐字推敲吗？
P: 一个实用场景演示：你想让 AI 帮你把课堂笔记整理成问答卡片。提示词可以这样写：「把笔记整理成问答卡。示例一：笔记原文『光合作用需要光』→ 卡片『问：光合作用的必要条件是什么？答：光。』示例二：『呼吸作用释放能量』→ 『问：呼吸作用释放什么？答：能量。』请照此整理以下三条笔记……」格式从此稳定复现。
P: 动手搭一次三段式。选一个你真实需要的任务——比如把英语错题整理成「错误原因归类表」。写一份含角色设定、四要素和两个手造示例的完整提示词，发送后检查：格式是否 100% 复现？若没有，先修示例再修描述，体会两者的不同杠杆。
KC: 零样本与少样本 :: 常规任务用零样本，清晰指令直接问；需要特定格式或独特风格时上少样本，附两三个示范让模型照着模仿。:: 试一试 :: 同一个任务分别用两种方式各跑一次，对比格式稳定性。

S: 小结与预告
P: 回顾本章：示例是最无歧义的任务说明，两三个有差异的好例子胜过长篇描述；示例数量宜精不宜多，质量必须达标；零样本与少样本按需选择，与角色设定、四要素组合成三段式标准打法。
