T: 三种学习方式：监督、无监督与强化

S: 先给「学习」下个定义
CALL: 本章目标 :: 学完这一章，你将能够说出监督、无监督、强化三种学习方式各自的训练信号，并判断一个具体任务该归入哪一类。
P: 上一本书你已经见过「从例子中找规律」的思想。这一章我们把它展开成一张完整的地图：机器学习按训练信号的不同分成三大流派——监督学习、无监督学习、强化学习。区分它们只需要问两个问题：有没有标准答案？有没有即时反馈？
@kp=supervised-learning
KC: 监督学习 :: 监督学习用带标准答案的样本训练模型：每条数据既有输入又有正确输出，模型的任务是学会从输入到输出的映射。:: 生活里的例子 :: 就像做带答案的习题册：题目是输入，参考答案是输出，对完答案才知道学得怎么样。
FIG: 一张横向对比图分三栏：左栏带答案标签画着「题目（输入）—答案（输出）—学映射」，标题「有答案·监督学习」；中栏画着一堆散点被自动圈成两堆，标题「只有数据·无监督学习」；右栏画着「智能体—动作—环境—奖励」的循环，标题「有奖励·强化学习」 :: 一张图分清三大流派：看的是答案、结构还是奖励 :: assets/learning-paradigms.svg
P: 监督学习是目前应用最广的一支。识别垃圾邮件、判断影像里有没有病灶、预估房价，背后都是「输入加标注答案」的训练。它的瓶颈也一目了然——标注答案要花钱花人力，医学影像还得请专家来标。数据越多越贵，这是监督学习的宿命。
CALL: 想一想 :: 你常用的应用里，哪些功能明显是监督学习的产物？试着为其中一个功能描述它可能的「输入」和「标准答案」长什么样。

S: 没有答案也能学
@kp=unsupervised-learning
KC: 无监督学习 :: 无监督学习只拿到数据本身，没有标准答案，任务是自行发现内在结构，最典型的任务是把相似样本聚成簇。:: 生活里的例子 :: 把一盒混装的扣子倒在桌上，没人告诉你分类标准，你自然会把相似的归成一堆。
P: 没有答案时机器在做什么？寻找数据的天然结构。电商把百万用户自动分成若干群组，运营再研究每个群组的共同特征；新闻网站把每天的海量报道聚成话题簇；异常检测则反过来——找到「不属于任何一堆」的离群点，用于发现信用卡盗刷或设备故障。
P: 第三支是强化学习，思路完全不同：不给答案，给奖励。智能体在环境里不断尝试动作，环境返回奖励或惩罚，它据此调整策略。下棋 AI 靠赢棋得分学会神之一手，机器人靠模拟器里的成功抓取学会拿东西，游戏 AI 甚至在电竞中击败人类顶尖选手。
P: 强化学习最迷人的地方在于延迟奖励：为了十几步后的胜利，当前一步可能需要「吃亏」。这要求智能体在眼前小利和长远回报之间权衡，也让训练变得不稳定而难调。它被视为通向更通用智能的一条路径，但样本效率低仍是硬伤——人类看两盘就会的游戏，AI 可能要玩上亿盘。
CALL: 想一想 :: 学骑自行车更像哪种学习？摔倒的疼痛算什么信号？为什么说它比「背交规」更接近强化学习？

S: 流派之间不是楚河汉界
P: 实际系统常常混合用兵。自动驾驶既用监督学习认路标（有人标注过图片），又用强化学习优化变道策略；大语言模型的训练更是三部曲：先用海量文本自监督地学语言规律，再用人工标注的偏好数据微调，最后用类似强化的方法对齐人类口味。
P: 选哪条路线，取决于你手里有什么：有高质量标注选监督，只有原始数据想探宝选无监督，能定义清楚奖励和试错成本选强化。工程师的第一课永远是盘点资源，而不是追逐最新潮的方法。
P: 地图画完了，接下来三章我们钻进监督学习的引擎室——因为它是理解其他流派的最好入口。引擎的核心只有一个问题：模型怎么知道自己错了？错多少？以及知道之后怎么改？先从「错多少」说起。
CALL: 动手归类 :: 把下列任务分别放进三张卡片：识别验证码图片、给全校同学按作息习惯分组、训练无人机悬停平衡。说说你的理由。

S: 小结与预告
P: 回顾本章：三大流派由训练信号划分——监督学习看标注答案，无监督学习找数据结构，强化学习追奖励信号；真实系统常三者混用；选择路线的本质是盘点手中的资源。
P: 下一章进入监督学习的核心装置：一个把「错得有多离谱」精确折算成数字的函数。别小看这一步翻译——有了可计算的数字，「学习」才第一次从比喻变成可以被机器执行的数学目标。
