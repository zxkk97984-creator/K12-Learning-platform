T: 太聪明也是病：过拟合与欠拟合

S: 两位学生的寓言
P: 备考的故事：学生甲把练习册背得滚瓜烂熟，模拟卷次次满分；高考换题就崩——因为他背的是题目本身而非解法。学生乙连基本公式都没记住，什么卷子都考不好。映射到机器学习：甲是过拟合——把训练数据的细节和噪声一并记下；乙是欠拟合——连基本规律都没抓住。|mark:过拟合
@kp=overfitting
KC: 过拟合 :: 过拟合指模型在训练数据上表现极好、在新数据上明显变差的状态，本质是把噪声当成了规律来记忆。:: 生活里的例子 :: 只见过白天鹅的模型断言「所有天鹅都是白的」，第一次见到黑鹅便彻底失灵。
FIG: 三张散点图并排：左图一条直线穿过数据云但两头翘起标「欠拟合」；中图一条平滑曲线贴合趋势线标「恰好」；右图一条疯狂扭动的曲线精确穿过每个点、点旁画着噪声标记「过拟合」 :: 拟合程度三态：不够弯、刚刚好、弯过头——最像学习的反而是中间那条克制的曲线
P: 过拟合为什么几乎必然发生？因为训练的目标就是压低训练损失，而「把每个训练样本都记住」恰恰是最省力的降损方式之一——尤其当模型容量巨大而数据相对稀少时，硬背比找规律容易多了。深度模型动辄亿级参数，记忆能力绰绰有余，缺的是「克制」的理由。
P: 诊断靠一双成绩对比的眼睛。把模型分别在训练数据和它没见过的数据上打分：两边都差是欠拟合；训练分漂亮、新数据分难看，就是过拟合实锤；两边都好且接近，才算真学会了。这张双成绩单是机器学习里最基础也最有信息量的体检报告。
CALL: 想一想 :: 为什么「在训练数据上继续降低损失」可能反而伤害真实性能？用背题学生的类比，把这个矛盾讲给一位没学过机器学习的朋友听。

S: 药方清单
P: 确诊之后开药。第一味药是加数据：见多识广后，个别噪声样本再也骗不动模型——这是治本的思路，但标注成本高。第二味药是数据增强：图片旋转裁剪、语音加背景噪声，不新增信息却逼模型关注不变的本质特征，性价比极高。
P: 第三味药是限制模型自由度：参数少一点、结构简单一点，想死记也没那个脑容量。第四味叫早停：盯着验证成绩，一旦开始变差就停止训练——好比发现学生开始刷怪题钻牛角尖时及时喊停。第五味正则化：给复杂模型加惩罚项，让「太复杂的解释」付出额外代价，引导优化偏向简洁方案。
P: 有意思的是，这些药方的哲学高度一致：给模型施加「保持简洁」的压力。这与奥卡姆剃刀一脉相承——能解释现象的最简理论往往是更好的理论。机器学习没有发明这条智慧，只是用工程手段把它自动化了。
P: 实践中的标准动作是一轮轮对照实验：改一味药，跑一次训练，看双成绩单变化，再决定下一味。耐心与纪律比任何单点技巧都重要——过拟合无法根治，只能持续管理，这是每个从业者的日常清醒剂。
KC: 欠拟合 :: 欠拟合指模型连训练数据里的基本规律都没学会，两边成绩都差；药方是加大模型容量、延长训练或补充更好的特征。:: 试一试 · 用直线去拟合抛物线形状的数据点，观察怎么都贴不上的窘态。
CALL: 动手诊断 :: 给你一份训练准确率 99%、新数据准确率 71% 的病历，请开出药方（至少两味），并说明每味药预期改善哪条指标。

S: 小结与预告
P: 回顾本章：过拟合是把噪声当规律的记忆病，欠拟合是连规律都没学会的贫乏症；诊断靠训练与测试的双成绩对比；五味药方殊途同归——用简洁性约束对抗记忆倾向。
P: 整套诊疗体系的地基其实还没铺：所谓「新数据上的成绩」，从哪来的？凭什么信它？下一章补上这块基石——如何科学地把数据分成考卷和教材，让评估经得起推敲。
