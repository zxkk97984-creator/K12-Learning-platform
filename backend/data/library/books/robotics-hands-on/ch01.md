T: 开箱：认识零件家族

S: 别急着拧螺丝
P: 拿到机器人套件的那一刻，多数人的冲动是立刻拼。先忍住——花十五分钟认识整箱零件，后面能少走几小时弯路。把零件摊开分分类，你会发现它们分属五个家族，各司其职，缺一不可。|mark:套件
@kp=robot-kit-anatomy
KC: 套件部件 :: 机器人套件的部件分五大家族：结构件搭骨架，动力件（马达）出力气，主控板当大脑，传感器做感官，线材与紧固件负责连接一切。:: 生活里的例子 :: 一台电脑也分机箱、电源、主板、外设和线缆——复杂设备都是家族分工的产物。
KC: 参数识读 :: 零件参数藏着脾气：马达转速高力量小，超声波有近距离盲区；学会读参数才能扬长避短地用零件。:: 试一试 :: 查一查你的马达额定转速并换算成小车速度。
FIG: 一张桌面俯视插画：五个托盘分别摆放梁式结构件、两颗马达、一块主控板、几枚红外传感器和一把螺丝线材，每个托盘上方挂着家族名牌 :: 开箱第一课：按家族清点，而不是按形状乱摸
P: 结构件家族包括各种长度的梁、板、连接件和轮子，它们决定机器人的身材与强度；动力件家族主要是马达，负责把电能变成转动；主控板是那块带芯片的方板子，相当于大脑加脊髓，所有指令从它发出；传感器家族是眼睛耳朵，常见成员有碰撞开关、红外、超声波；最后的线材螺丝看似不起眼，却是整个系统的血管神经。
P: 清点前还有一个小准备：在桌面铺一块浅色桌布或大白纸。深色小零件落在深色桌面上极难发现，一颗黑色螺丝钉能让人找上半小时——这是无数前辈弯着腰换来的血泪教训，听人劝，铺好布再开工。
P: 清点时给每个家族建一张「户口卡」：名字、数量、特征。比如马达两只、接口四个金属触点；红外传感器三枚、尾部两针接线。这张卡在第三章接线时会救你的命——面对一堆一模一样的插口，只有户口卡能告诉你哪根线该进哪个门。
CALL: 动手实践 :: 给自己的套件完成五大家族清点，为每件核心部件拍一张特写照并标注名称，整理成一页「开箱图鉴」。

S: 读懂数字背后的脾气
P: 零件包装上常印着参数，挑两个重要的学会读。马达的转速参数通常写作每分钟多少转，数字越大转得越快，但快不等于好——跑得快的车往往没劲，爬坡就趴窝。超声波传感器的探测范围写着几厘米到几百厘米，低于下限它反而测不准，这是很多新手的盲区。
P: 工具准备同样属于开箱环节：一套顺手的螺丝刀（通常套件自带）、几根扎带理线、一张白纸做记录。特别推荐准备一个小收纳盒专门放螺丝螺母——散落在地上的小五金件是机器人课桌上的头号事故来源，踩到一颗的痛感会让您终身难忘地养成随手收纳的习惯。
P: 主控板的接口也要认脸：马达接口通常较粗且成对出现，传感器接口较小且标有编号。编号很重要！程序里写的「1 号接口的马达全速前进」，如果线插在了 2 号口，机器人就会表演原地抽搐。接口与程序一一对应，是硬件项目的铁律。
P: 动手画一张你这套套件的「系统连接草图」：中间画主控板，左边连两个马达，右边连三个传感器，每条线上标注接口编号。现在它只是纸上的圈圈线线，第五章赛场上它会变成你最可靠的排错地图。
CALL: 动手挑战 :: 只看参数卡回答：如果你的马达额定转速是每分钟两百转，车轮直径六厘米，小车理论最快速度大约每小时几公里？（提示：先算车轮一圈的周长。）

S: 小结与预告
P: 回顾本章：套件零件分五大家族，各司其职；清点建卡是组装前的必修课；读懂转速与探测范围等参数才能扬长避短；接口编号必须与程序一一对应；一张连接草图胜过十次盲目试错。
P: 认识了演员，接下来搭舞台。机器人的身体结构决定了它的能力上限：重心歪了容易翻车，底盘软了会跑偏，轮距不对转弯就飘。下一章进入机械的世界。
