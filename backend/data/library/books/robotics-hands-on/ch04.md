T: 加上传感器：会反应的小车

S: 给车装上眼睛
P: 现在的小车像闭着眼睛背路线的演员——程序让它走三秒它绝不走两秒半，可一旦起点挪了位置，它就一头冲出剧本。真正的机器人需要实时感知世界。这一章我们装上两类最常见的感官：红外传感器负责看地面，超声波传感器负责看前方。|mark:红外传感器
P: 先认识红外的脾气。循线用的红外对管贴地安装，向地面发射红外线并检测反射强度：白色地面反光强，黑色线条吸光反光弱。传感器据此输出两种状态——见到黑线或见到白底。就这么一个二选一的简单信号，却是第五章循线竞速的全部信息来源。
FIG: 底盘前缘特写：两枚红外探头朝下对着一条黑线，左探头在白区显示绿色「1」，右探头压在黑线上显示红色「0」，旁边放大图解释反光强弱差异 :: 两只朝下的眼睛：黑白之间，藏着小车的整条跑道
P: 安装传感器也有讲究：红外探头离地面的高度直接影响读数稳定性，太高会误报，太低容易被地面刮蹭，说明书建议的高度值要拿尺子认真量。超声波则必须装在车头正中且前方无遮挡，歪一点整个防撞逻辑都会偏移。
P: 超声波则负责抬头看路。它的工作原理第二章提过：发一声听回声，用时间算距离。装上车头后，小车终于能在撞墙之前知道墙的存在。给它配一段最简单的防撞程序：循环检查距离，小于二十厘米就刹车后退。跑一次，看着它在墙前稳稳停下——那一刻的成就感无可替代。
CALL: 想一想 :: 为什么超声波传感器测不了太近的物体（比如五厘米以内）？提示：想想声波往返需要时间和盲区的概念。

S: 从执行到反应
P: 传感器的加入让程序结构发生质变。之前的程序是「剧本式」：第一步、第二步、第三步演完收工；现在变成「反应式」：无限循环里不断读取传感器，根据读数决定动作。写法上就是条件积木登场：「如果左红外见到黑线，就……否则就……」。
@kp=line-following
KC: 循线行驶 :: 循线行驶用两枚朝下的红外传感器夹住黑线两侧，哪边压线就往反方向修正，小车沿蛇形微调前进，整体看起来是沿线直行。:: 生活里的例子 :: 走夜路时脚一直踩在线的一侧，偏了就挪回来——不需要看清全路，只需盯住脚下。
KC: 剧本式与反应式 :: 无传感器的程序照剧本演完收工，有传感器后改为循环读取状态再决定动作的反应式结构，这是机器人智能的分水岭。:: 试一试 :: 用四句话写出循线行驶的判断规则。
P: 动手实现第一版循线逻辑：左右两枚传感器都在白区，直行；任一枚压到黑线，说明车头歪了，向另一侧修正转向；两枚同时见黑，可能是横线或终点，停车。把这四条规则翻译成条件积木，下载运行——小车摇摇晃晃但确确实实沿线走起来了！
P: 摇晃是正常的。初版逻辑本质是「冲出去再拉回来」，修正幅度一大就走成蛇形。优化方向有两个：降低修正时的转向速度差，让纠偏更温柔；提高传感器采样频率，发现偏差越早、纠正越小。这两味药下去，蛇形立刻收敛成轻微摆动。
CALL: 动手实验 :: 分别把修正速度差调成三十和八十各跑一次，录像对比轨迹平滑度与用时，找出你这条赛道的平衡点。

S: 小结与预告
P: 回顾本章：红外看黑白、超声波量距离，两类感官补齐了小车的感知；程序从剧本式进化为反应式的循环加条件；循线的核心是「哪边压线往反打」；修正幅度与响应频率决定走线质量。
P: 单项技能全部就位：底盘能跑、大脑有程序、眼睛会看线。最后一章，把这一切带到赛场——循线竞速赛见真章——赛场见真章，调试出真知——零件、程序与感知在赛场上缺一不可，最后一章见真章。
