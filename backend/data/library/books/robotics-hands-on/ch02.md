T: 机械传动：齿轮与结构

S: 马达不是直接装在轮子上的
P: 新手最常见的组装疑问：为什么马达不直接驱动轮子，中间非要垫几个齿轮？直接连不行吗？还真不行。马达转得飞快却没什么劲——直接连轮子的车，一上地毯就趴窝。齿轮的任务就是做这笔交易：用速度换力量。|mark:齿轮
@kp=gear-transmission
KC: 齿轮传动 :: 大齿轮带动小齿轮，转速升高力量变小；小齿轮带动大齿轮，转速降低力量变大。齿数比就是速度与力量的交换汇率。:: 生活里的例子 :: 山地车爬坡换大飞轮：踩得慢了，但每脚都更有劲。
KC: 底盘三要素 :: 重心低才稳，左右对称才走直线，结构刚性足传感器读数才不抖；装完底盘要用推一推、按一按的方式验收。:: 试一试 :: 故意拧松一侧轮子半圈，观察直行跑偏的效果。
FIG: 一组啮合的齿轮插画：左侧小齿轮（12 齿）驱动右侧大齿轮（36 齿），标注「转速除以 3，力量乘以 3」；旁边一辆小车分别画出直连轮与带齿轮组的两版动力结构 :: 齿数比就是汇率：想快付力量，想要劲付速度
P: 动手感受这笔交易。按套件说明搭两组传动：一组小带大（减速增扭），一组大带小（增速减扭），用手捏住输出轴对比阻力感。你会明显发现减速那组「攥不住」，力量大得多。竞速车要快选增速，越野爬坡要劲选减速——没有对错，只有匹配任务。
P: 底盘结构的三个关键词同样重要。重心：越低越稳，电池这类重件尽量放低；对称：左右两侧结构镜像，否则直行都会跑偏；刚性：晃晃悠悠的车架会让传感器读数抖动，该加固的地方一个螺丝都不能省。装完底盘做个测试：放在桌上轻推一下，它应该直线滑行一段而不是画弧线。
CALL: 动手实验 :: 把底盘电池从上层移到下层再推一次，对比两种重心的稳定性；再把一侧轮子拧松半圈试试跑偏效果——故意制造问题是最快的学法。

S: 轮距与转向的秘密
P: 两个驱动轮之间的距离叫轮距，它悄悄决定着转弯性格。轮距宽，转弯半径大但行驶稳定；轮距窄，掉头灵活却容易侧翻。竞速赛道弯多弯急时，很多队伍会收窄轮距换取过弯速度。没有完美参数，只有针对赛道的取舍——这句话请刻进工程师脑中。
P: 底盘搭建还有一个新手容易忽略的细节：走线整齐。马达线、传感器线如果不固定，行驶中晃荡着可能缠进轮子里，轻则停摆重则扯断接口。用扎带把线沿车架固定好并留出活动余量——整洁的走线是可靠性的隐形守护者。
P: 差速转向也值得提前理解：这套底盘通常不给前轮配转向机构，转弯靠左右轮转速差实现——左轮慢右轮快，车身自然向左偏转。原地掉头？让两边反转即可。理解了这一点，第三章的程序里那些「左轮速度、右轮速度」参数就不再神秘。
P: 动手完成底盘验收清单：正推直线滑行无偏移；按压四角无松垮；提起后空转轮子无异响卡顿；量出并记录轮距数值。全部通过后，给底盘拍一张定妆照——接下来它要迎接大脑和感官了。
CALL: 动手挑战 :: 用硬纸板自制一条两米长的简易赛道，含一个直角弯和一个缓弯，把你的底盘放上徒手推跑一圈，记录哪里容易冲出线——这些点位就是第五章调参的主战场。

S: 小结与预告
P: 回顾本章：齿轮是速度与力量的交易台，齿数比即汇率；底盘三要素为低重心、对称、刚性；轮距决定转弯性格；差速转向靠左右轮速差实现；验收合格的底盘才配进入下一关。
P: 身体就绪，还缺大脑和指令。下一章我们把主控板接上电源，写下第一段程序，让静止的底盘第一次自己跑起来——通电的那一刻，所有零件将第一次协同工作。。
