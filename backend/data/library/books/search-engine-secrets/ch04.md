T: 评估信息：这条结果可信吗

S: 排在第一不等于最可靠
P: 搜索引擎的排序衡量的是「相关与流行」，不是「真实与权威」。一条精心编造的谣言如果被大量转发链接，完全可能压过严谨的科学报道排到榜首。所以看到结果的第一反应不该是「排第一应该是真的」，而是启动评估流程。这套流程就叫信息可信度评估，只有三板斧，练熟之后每次只需十几秒。|mark:信息可信度评估
@kp=source-evaluation
KC: 信息可信度评估 :: 信息可信度评估三板斧：查来源（谁发布的内容、是否有专业背景）、看时间（信息是否过时）、交叉验证（多个独立来源是否一致）。:: 生活里的例子 :: 听到一个惊人消息先别转，问问「谁说的、什么时候说的、还有谁这么说」。
KC: 孤证不立 :: 只有一个来源支撑的说法默认存疑，多个互相独立的信源口径一致才可采信；交叉验证是对抗假消息最有力的一招。:: 试一试 :: 找一条只有单一出处的「惊人发现」，看看其他媒体是否跟进。

S: 第一板斧：查来源
P: 点开网页先看三处：网站是谁办的（域名与机构名）、作者是谁（有没有真名和专业背景）、内容有没有引用出处。政府机构、知名学术机构、大型正规媒体的可信度通常较高；个人博客和匿名论坛并非不能看，但需要更强的证据支撑其说法。一个快速信号：正经机构的内容敢署名担责，来路不明的内容往往连作者都找不到。
P: 来源还要和内容类型匹配。「某明星的爱好」这类娱乐消息，娱乐媒体说得还算对口；但医学健康问题就该优先看医疗机构和权威科普平台，而不是营销号。用对口的渠道查对口的事，是评估的第一层智慧。
FIG: 一张评估检查卡：三个勾选框分别是「来源可靠吗」「时间新鲜吗」「多源一致吗」，每个框后画着放大镜；卡片底部一行字「三关全过才采信」 :: 十几秒的三项快检，替你挡住绝大多数假消息

P: 来源评估还可以借助第三方工具：一些浏览器插件能显示网站的安全评级和所有者信息；学术类内容可以通过引用次数间接判断影响力；新闻类则可以查证发布机构是否有正规的采访资质。工具不是必需品，但知道它们存在会让你在面对可疑信息时多一分从容。

S: 第二板斧与第三板斧
P: 第二板斧看时间。网络上的内容不会自动过期，但事实会变化：「今年高考人数」搜出五年前的数据、「软件最新版本」点开是三年前的教程，都是常见事故。多数页面会标注发布或更新日期，优先选新鲜的；没有日期的内容默认按可疑处理。
P: 第三板斧交叉验证——这是最有力的武器。同一个说法至少找两到三个互相独立的来源核对：不同机构的报道、不同作者的文章。如果只有一家孤零零地说，其他地方全无踪影，再惊人的说法也要存疑；如果多家独立信源口径一致，可信度大幅上升。记住口诀：孤证不立，众口可参。
CALL: 动手演练 :: 搜索一条你感兴趣的科学新闻，用三板斧给它做体检并写一份五十字的评估结论：来源是什么？发布多久了？几家媒体报了？

P: 最后提醒一个容易被忽视的场景：搜索结果中的图片和视频同样需要评估。一张断章取义的照片、一段掐头去尾的视频，杀伤力有时超过文字谣言。对视觉内容的核实可以借助反向图片搜索工具——上传图片查找它的最早出处和使用记录。

S: 小结与预告
P: 回顾本章：排序不代表真实性；评估三板斧为查来源、看时间、交叉验证；来源要与内容类型匹配；孤证不立是最可靠的直觉。练熟三板斧，你就在真假难辨的信息海洋里有了自己的罗盘。
