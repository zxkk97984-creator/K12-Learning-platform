T: 选对关键词：搜索的艺术

S: 搜索不好用，先怪关键词
P: 十个搜不到结果的人里，九个的问题出在关键词上。「怎么写作文」这种问法太宽——几千万条结果里什么都有，等于没有；「初中议论文开头技巧」就精准得多。搜索引擎不懂读心术，它只认识你给的那串词。选词选得准，好结果自己跳出来；选不准，翻十页也是徒劳。|mark:关键词
@kp=search-keyword
KC: 搜索关键词 :: 搜索关键词是提交给搜索引擎的核心词语：先提炼问题的核心概念，再用具体名词替换模糊表达，词越精准结果越对口。:: 生活里的例子 :: 问图书馆管理员「有没有书」不如说「我想找恐龙百科」。不如说「我想找恐龙百科」。
P: 提炼关键词有个三步法。第一步抓核心：把问题压缩成一两个最关键的名词，「手机充电慢怎么办」的核心是「手机 充电慢」。第二步换专业词：口语换成行业说法，「电脑卡」换成「电脑 运行缓慢 解决方法」命中率更高。第三步加限定：「苹果 手机 充电慢 电池老化」——每加一个准确的限定词，范围就收窄一圈。
FIG: 三级漏斗图：顶层宽口写着「怎么写作文」（数百万条结果），中层收窄为「初中 议论文 写作技巧」，底层窄口标出「初中 议论文 开头 技巧 范文」（数十条精准结果） :: 关键词是漏斗的阀门：每加一个准确的词，噪音就少一层
CALL: 想一想 :: 为什么「最好的手机」是个注定失败的关键词？从「最好由谁定义、随时间变化吗」两个角度分析。

P: 选词还有一个进阶技巧叫换语言：某些技术术语的英文资料质量远超中文翻译版。比如搜「gradient descent tutorial」比「梯度下降 教程」能找到更多优质资源。双语搜索是进阶检索者的标配技能。

S: 高手的三条选词心法
P: 心法一：名词优于形容词和整句。「好看的电影推荐」不如「2024 高分科幻电影 片单」——名词承载信息量，形容词只带来噪音。心法二：独特词优先于常见词。搜索一个报错代码时，把错误提示里那串独一无二的编号原样贴进去，比描述现象有效百倍——独一无二的东西一查一个准。
P: 心法三：分次搜索代替一次到位。复杂问题别指望一条查询解决，先搜大方向锁定术语，再拿新学的术语发起第二轮更专业的搜索。比如先搜「灯泡不亮 原因」，发现术语叫「钨丝熔断」，再搜「钨丝熔断 更换教程」——两轮接力，直奔答案。

KC: 高级搜索技巧 :: 给关键词加英文引号可锁定精确短语不被拆分，加 site 冒号可限定只在某网站内搜索，加减号可排除干扰词。:: 试一试 :: 用引号搜一句歌词的原句，看结果如何聚焦。
P: 动手完成一轮搜索闯关。第一关：查「本校运动会照片」之外的一个具体问题——为什么天空是蓝色的，要求结果适合讲给小学生听。第二关：查一款你正在用的软件的官方教程，限定在官网内找。第三关：查一个你感兴趣的历史事件的确切日期。三关全过，你就出师了。
KC: 两轮接力搜索 :: 复杂问题用两轮接力：第一轮搜大方向锁定行业术语，第二轮拿新术语发起更专业的查询，直奔答案。:: 试一试 :: 先搜「灯泡不亮 原因」，再用查到的术语搜维修教程。
CALL: 动手挑战 :: 把下面这条烂查询改造成三条高质量查询：「学习英语」——分别面向背单词、练听力、准备考试三个目标。

P: 搜索词的选择还受语言习惯影响：同一件事在不同地区有不同的叫法。比如「土豆」「马铃薯」「洋芋」指的是同一种东西，搜不到时换个叫法试试。方言词汇、行业黑话、官方术语之间的转换能力，是高级搜索者的隐形武器。

S: 小结与预告
P: 回顾本章：搜索质量的上限由关键词决定；三步法是抓核心、换专业词、加限定；三条心法是名词优先、独特词优先、分轮接力；高级语法（引号锁短语、site 限站点）是随身利器。
P: 词选好了，结果页却还有陷阱等着：排在前面的未必是最好的，有些位置是花钱买来的。下一章教你一眼分辨广告与真结果——理解了它，后面的学习会顺畅许多。。
