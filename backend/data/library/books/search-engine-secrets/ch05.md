T: 进阶技巧：像侦探一样搜索

S: 三件语法神器
P: 搜索引擎支持几种高级搜索语法，学会其中最常用的三件就足以超越九成用户。神器一：英文引号锁短语。「"机器学习 入门"」加引号后，引擎只返回包含这个完整顺序短语的页面，词语不再被拆散匹配。查歌词、查报错原文、查名人名言，引号一锁一个准。|mark:高级搜索
KC: 反向图片搜索 :: 以图搜图功能能追查一张图片的最早出处与完整流传路径，是鉴别「旧图新用」类谣言的黄金组合技，配合关键词搜索效果更佳。:: 试一试 :: 用一张朋友圈热传的图片做反向搜索，看它最早出现在哪里。
KC: site 限定语法 :: 在关键词后面加上 site 冒号和指定域名，可以把搜索结果限定在那个网站之内，特别适合查官方教程或政策原文。:: 试一试 :: 用 site 限定在教育网站内搜索机器人竞赛资料。
P: 神器二：site 限定站点。「site:edu.cn 机器人竞赛」只在教育机构网站里搜索，「site:gov.cn 垃圾分类」只在政府网站里找政策。当你知道某类信息一定在特定网站上时，这一招能直接跳过海量噪音。神器三：减号排除。「苹果 -手机」会排除包含「手机」的结果——想搜水果公司历史而不是数码产品时特别好用。
FIG: 三张工具卡并排：第一张画着引号标「锁定完整短语」，第二张写着「site: 站点限定」，第三张是减号标「排除干扰词」；下方一条查询示范把三件神器串在一起使用 :: 三件神器可以自由组合：越组合越精准
CALL: 想一想 :: 「鲁迅 -纪念馆」这条查询想找什么？排除词的使用场景有什么规律？再设计两条你自己能用上的排除查询。

P: 视频搜索还有个实用功能叫关键帧预览：鼠标悬停在进度条上时，画面会显示对应时间点的内容缩略图。不用拖动进度条来回试就能快速定位想要的片段——这个细节能节省大量时间。

S: 图片与视频的检索
P: 信息不只有文字形态。图片搜索有两个实用玩法：一是以图搜图——上传或粘贴一张图片，引擎找出相同或相似的图片来源，适合鉴别图片真伪、追溯原图出处；二是按尺寸和颜色筛选素材。视频搜索则要善用平台自带的筛选：按时长（短视频还是长教程）、按发布时间排序，能省下大量翻找时间。
P: 以图搜图还有一个重要用途：验证图片真实性。社交平台上流传的「现场照片」，用反向图片搜索一查，常常发现它其实是几年前的旧图挪用。这项技能配合第四章的交叉验证，是对抗谣言图片的黄金组合。
CALL: 动手实验 :: 找一张朋友圈流传的「震撼照片」，用以图搜图追查它的最早出处，看看是否被移花接木。

S: 毕业实战：一次完整的深度检索
P: 综合演练开始。任务：「调查一个网络流行的健康说法是否可靠」（例如某种食物抗癌）。第一步选词：核心说法加「真相」「辟谣」等限定词。第二步分区检查：先看权威医疗机构的科普，再看正规媒体的报道，跳过广告区。第三步三板斧评估：来源、时间、多源一致性逐项打分。第四步输出结论：写一份两百字调查报告，附上你采信的两到三个来源链接。
P: 这套流程就是信息侦探的标准作业程序。走完这一次你会发现：搜索引擎给你的从来不是答案，而是线索；真正的答案由你的检索策略和判断力加工出来。工具越强大，使用者的头脑就越值钱。
CALL: 动手实战 :: 完整执行一次上述健康流言调查，并把你的四步过程整理成一页「检索报告」交给老师或家长评阅。

P: 检索技能的终极检验标准是：能否在五分钟内找到一条你之前不知道、但确实需要的信息。试着用今天学的全部技巧完成这个挑战——找一个你不了解的话题（比如某种深海生物），从零开始搜集三个关键事实并注明来源。能高效完成的人，就已经具备了自学任何领域的检索基础。

S: 全书回顾
P: 五章练成一套完整的检索功夫：懂得结果从哪来（爬虫索引排序），会用精准关键词（三步法加心法），分得清广告与自然结果，拿得稳可信度三板斧，玩得转高级语法与反向搜图。从此，搜索引擎在你手中不再是一个碰运气的黑箱，而是一件指哪打哪的精密工具。
P: 信息时代，会提问、会搜索、会验证的人掌握主动权。愿你带着这套功夫，在信息的海洋里永远做清醒的航海者，而不是随波逐流的漂流瓶——动手试过之后体会会更深刻。。
