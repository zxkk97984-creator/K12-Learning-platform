S: 一秒钟背后的三步工程
P: 在搜索框输入「恐龙为什么灭绝」，按下回车，不到一秒，几百万条结果整整齐齐排在眼前。这一秒里搜索引擎完成了三步大工程：派出爬虫收集网页、把网页做成索引库、按相关性排出名次。理解这三步，你就掌握了搜索结果的「出生证明」。|mark:爬虫

KC: 网页爬虫 :: 网页爬虫是搜索引擎派出的自动程序，它顺着网页上的链接日夜不停地访问新页面，把内容抓取回来存进数据库。:: 生活里的例子 :: 像图书馆的管理员跑遍全城书店，把每一本书登记造册搬回馆里。
KC: 索引库 :: 索引库是搜索引擎预先建好的超级目录：记录每个词语出现在哪些网页、出现几次、处于什么位置；查询时查的是目录而非网络本身。:: 试一试 :: 观察搜索框的自动补全建议，它们正来自索引库里的高频词。
P: 第一步由爬虫完成。互联网上有几十亿个网页，彼此用链接相连如同一张巨网。爬虫从一个页面出发，读到链接就顺藤摸瓜爬向下一个，如此循环不息。你发布的新网页，正是这样被它发现并收录的——这也是为什么刚建好的网站要过几天才能被搜到。
P: 第二步是建索引。几十亿个网页如果每次搜索都从头读一遍，等到天荒地老也出不来结果。所以引擎提前做好一本超级目录：把每个网页拆成词语，记录「这个词出现在哪些页面、出现几次、在标题还是正文」。你搜索时查的其实是这本目录，而不是网络本身。

CALL: 想一想 :: 为什么有些很新的消息搜不出来，而十年前的老帖却一搜就有？用爬虫和索引的概念解释这个现象。

S: 排序的秘密：谁排第一个
P: 第三步排序决定你先看到什么。当索引里有一百万个页面都包含你的关键词，谁排第一？主流思路综合两方面信号：一是相关性——关键词出现在标题里的页面通常比出现在角落的更对口；二是权威度——被很多其他网页链接引用的页面，通常更值得信任。
P: 权威度的经典衡量思路来自一篇著名论文：把每个链接看作一次投票。一个网页被越多网页链接，得分越高；同时重要网页投出的票分量更重。这套思想让搜索引擎的排序质量实现了飞跃，也是后续所有排名算法的鼻祖。
P: 不过排序并非只看这些技术信号——商业因素同样在场：商家可以付费购买更好的展示位置。这就是你在结果页顶部经常看到的带「广告」角标的条目，它们与按相关性自然排出的「自然结果」是两套体系。两者的区别与识别方法，第三章专门细讲。
CALL: 动手观察 :: 搜索任意一个常见词，数一数第一页有多少条带广告标识的结果，把它们的位置记下来——这是你与真实搜索机制的第一接触。

S: 小结与预告
P: 回顾本章：搜索结果来自三步工程——爬虫抓取建库存、索引目录加速查询、排序算法定先后；排序综合考虑相关性与权威度，商业广告则另占山头。知道了原理，你就知道该在哪一步发力改善自己的搜索效果。
P: 三步工程里，唯一完全由你掌控的是输入的那串词。同样的工具，不同的关键词带来完全不同的世界——下一章我们就练这门手艺：选词的艺术——这一点值得每位学习者牢记在心。。
