T: 看懂结果页：广告与自然结果

S: 结果页是一座双面舞台
P: 搜索结果页看起来是一份公正的榜单，实际上更像一座双面舞台：台上既有凭实力入选的自然结果，也有花钱租下前排座位的赞助结果。搜索引擎公司的主要收入正来自这些广告位——你每次搜索，都是一次潜在的商业机会。|mark:赞助结果
@kp=sponsored-results
KC: 赞助结果 :: 赞助结果是商家通过竞价付费获得的优先展示位，通常带有「广告」角标；它的排序依据是出价与质量分，而非纯相关性。:: 生活里的例子 :: 电视节目中间插播的广告不会因为是「最贵的」就比节目本身更好看。
FIG: 一个搜索结果页的示意图：顶部两条结果带黄色「广告」小标，下方十条无标识的自然结果按序号排列；一条虚线把页面分成「商业区」和「自然区」两个区域 :: 学会分区看结果页：先认广告区，再看自然榜

P: 还有一类特殊结果叫知识面板——搜索框右侧或顶部的信息卡片，直接展示答案摘要而非链接。它们来自结构化数据库而非网页排名，信息密度高但也可能过时。学会分辨「这是摘要卡片还是网站条目」也是读结果页的基本功。

S: 为什么必须区分两者
P: 广告不是坏东西——很多正规服务商也买广告位。但你要清楚一个事实：自然结果的排序逻辑是「尽量匹配你的需求」，赞助结果的排序逻辑是「谁付的钱多且质量达标」。两者的目标函数不同，内容质量自然没有可比性。尤其涉及医疗、贷款、培训这类高客单价领域时，前排广告的可靠性需要额外打量。
P: 识别方法很简单：看角标。主流引擎都会给广告标注「广告」「赞助」或「推广」字样，通常出现在链接下方或末尾。可惜角标往往又小又淡，很多人从未注意过。从今天起养成一个动作：打开结果页先扫一遍有没有角标，把广告区和自然区在心里划清界限。
P: 还有一种更隐蔽的形态叫 SEO 过度优化：一些网站研究排序规则，堆砌关键词、批量制造内容，只为挤进自然结果前排。它们没花广告费，但内容质量同样存疑。识别线索是「标题党加空洞正文」的组合——点进去发现全是车轱辘话的页面，果断返回换下一条。
KC: 过度优化页面 :: 有些网站研究排序规则、堆砌关键词批量造页，只为挤进自然结果前排；识别线索是标题党加空洞正文的车轱辘话组合。:: 试一试 :: 找一条点进去全是废话的搜索结果，总结它的三个特征。
CALL: 动手实验 :: 分别搜索一款热门游戏和一个疾病名称，对比两类查询中广告的比例差异。想想：为什么有些词的广告位竞争特别激烈？

S: 小结与预告
P: 回顾本章：结果页由广告区与自然区组成；赞助结果按出价排序、带角标标识，与自然结果的目标函数不同；还要提防不花钱但堆砌关键词的过度优化页面。看清舞台结构，才不会被站位迷惑。
P: 分清了广告，剩下的自然结果也不全是金子：过时的旧信息、以讹传讹的错误、立场偏颇的内容都在其中。下一章我们练信息时代最核心的本领——评估一条结果到底可不可信。
