T: 好游戏的三样宝贝

S: 换一双眼睛看游戏
P: 你玩过很多游戏，但今天要做一件不一样的事：不再只当玩家，而是当设计师。设计师看游戏时眼睛里看到的东西完全不同——他们会问：这个游戏让玩家追求什么？玩家能做什么、不能做什么？做对了有什么好处？这三个问题的答案，就是好游戏的三样宝贝。|mark:设计师
@kp=game-goal
KC: 游戏目标 :: 游戏目标是玩家努力想要达成的事情，比如得到高分、到达终点或救出朋友；没有目标的屏幕活动只是玩具，不是游戏。:: 生活里的例子 :: 跳绳比赛的「一分钟内跳最多」就是目标，它让简单的动作变成了比赛。
FIG: 三块宝石排成一排：第一块刻着旗帜标「目标」，第二块刻着尺子标「规则」，第三块刻着星星标「奖励」，下方一只手正把它们拼进一张游戏设计图 :: 设计师的三颗宝石：先想清楚这三样，再打开电脑
P: 第二样宝贝是规则。规则规定玩家可以做什么、不可以做什么：跳棋里只能走对角线，足球里不许用手（守门员除外）。规则看起来是限制，其实是乐趣的来源——正因为不能直接飞到终点，一步步闯关才有意思。没有规则的游戏很快就会无聊。
P: 第三样宝贝是奖励。做对了事情要有反馈：加分、音效、庆祝动画都算。奖励像小糖果，告诉玩家「你做得对，继续」。好的游戏会把大目标切成一串小奖励：接住一个苹果加一分，凑满十分升级，每级换新背景——玩家一路都有盼头。
CALL: 想一想 :: 挑一个你最爱的游戏，找出它的目标、规则和最让你开心的奖励各是什么。下节课我们要用这三样宝贝设计自己的作品。

S: 用三样宝贝分析一个反例
P: 光看好例子不够，还要会看坏例子。想象一个「游戏」：屏幕上有个小球随机乱飘，碰到什么都没有反应，也没有分数。玩三十秒你就想关掉了，为什么？对照三样宝贝检查：没有目标（不知道要干嘛）、没有规则（碰什么都无所谓）、没有奖励（做对了也没反应）。三样全缺，所以不好玩。
P: 反过来，哪怕画面很简陋的游戏，只要三样宝贝齐全也会让人上瘾。经典的小蜜蜂打飞机游戏，画面只有几个色块，但目标明确（消灭敌机保住基地）、规则清楚（被打中就输）、奖励密集（击落有分、过关有新阵型）——好玩与华丽没有必然关系，结构才是关键。
P: 动手做一个分析表。选三个你玩过的游戏，画一张三列表格写下每个游戏的目标、核心规则和最喜欢的奖励。写完观察一下：三样宝贝在不同类型的游戏里长得一样吗？你会发现赛车游戏和消除游戏的宝贝内容完全不同，但骨架一模一样。
KC: 游戏规则 :: 游戏规则明确规定玩家可以做什么、不可以做什么；规则带来的限制恰恰是闯关乐趣的来源，没有规则就没有挑战。:: 生活里的例子 :: 足球不许用手（守门员除外），这条规则让比赛变得紧张刺激。
CALL: 动手挑战 :: 给「石头剪刀布」这个古老游戏增加一条新规则或一种新奖励，让它变得更有趣。把你的改动说给同学听听是否成立。

P: 设计师笔记 · 本章做的东西里，最让你有成就感的是哪一步？把它记在笔记本上——下次卡住的时候翻回来看，你会发现原来自己已经走了这么远。这种记录进步的习惯，比任何技巧都更能支撑你走完创作全程。
P: 游戏设计还有一条黄金法则叫「易于上手，难于精通」：新手三十秒就能开始玩，但玩一百小时仍有进步空间。俄罗斯方块和消消乐都是典范。设计你的游戏时也想想：第一分钟玩家能获得什么体验？第一百分钟呢？两个答案都要有吸引力。

S: 小结与预告
P: 回顾本章：从今天起你的身份正式升级为游戏设计师。好游戏的三样宝贝是明确的目标、清楚的规则和及时的奖励；三样宝贝齐全的简陋游戏，胜过三样全缺的华丽游戏——这个判断标准将贯穿整本书的创作旅程；好游戏的三样宝贝是明确的目标、清楚的规则、及时的奖励；三样齐全的简陋游戏胜过三样全缺的华丽游戏。
