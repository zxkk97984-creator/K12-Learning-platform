T: 音效与动画的魔法

S: 「叮」的一声值千金
P: 做个对比实验：接住星星时只加分不发声，玩两分钟；再加上一声清脆的「叮」，再玩两分钟。第二次明显更上头——声音反馈是游戏爽感的一半来源。Scratch 的粉色声音积木区自带几十种音效：pop、cheer、 laser 一应俱全，挑一个喜欢的拼在加分的积木旁边就行。|mark:音效
P: 挑音效有两条小原则。第一，重要事件用响亮独特的声音：得分、胜利、失败各配不同的音，玩家闭着眼也知道发生了什么。第二，频繁事件用轻柔短促的声音：飞船移动不需要每次都「咻」个不停，否则一分钟就吵翻天。好音效像做菜的盐——适量提味，过量毁锅。
FIG: 一个游戏画面截图：飞船接住星星的瞬间，星星旁边跳出「+1」气泡和一颗音符图标，舞台底部音量滑块旁列出三行已启用的音效名称 :: 加分的那一秒：视觉气泡加一声叮响，快乐立刻翻倍
CALL: 动手实验 :: 给同一个动作分别配上三种不同音效试玩对比（比如 pop、bell、zoop），请家人盲选哪个听着最舒服。
P: 背景音乐是气氛的大管家：紧张的追逐配急促鼓点，悠闲的收集配轻快旋律。Scratch 的声音库里可以挑选循环乐曲，「播放声音 等待播完」改成「开始播放声音」（不等待）就能一边放歌一边打游戏。注意音量别盖过关键音效——背景是布景，主角永远是那声「叮」。

S: 让角色活起来
P: 动画的核心技巧你在入门书里见过：切换造型。给星星准备两个造型（亮与暗），在循环里每隔零点二秒切换一次，星星就开始一闪一闪；被接住时快速切三次造型再隐藏，就有了「吸收消失」的效果。造型加等待，就是最朴素的动画公式。
@kp=playtesting
KC: 反馈动画 :: 关键事件配上短暂的造型变化或大小缩放，能让玩家瞬间感知「刚才的操作生效了」，这叫反馈动画。:: 试一试 :: 飞船吃到星星时放大百分之一百二十再弹回原样，手感立刻变脆。
P: 还有一招提升手感的秘技：让飞船移动时轻微倾斜。「将旋转方式设为左右翻转」，配合按键时改变方向造型，飞船转向时会自然掉头。这些小细节单看都不起眼，叠在一起就是「大厂手感」和小作坊作品的差别——游戏设计师的功力全藏在这些看不见的地方。
P: 动手给你的游戏做一次全面包装：接住加音效、失误加低沉提示音、星星闪烁、飞船转向翻转、胜利时来一段欢呼。全部装好后完整玩三局，感受和第三章的版本有什么不同——同样的规则，包装过的版本快乐至少翻倍。
KC: 背景音乐 :: 背景音乐负责气氛，用「开始播放」积木可以边放音乐边游戏；音量要低于关键音效，别让布景抢了主角的戏。:: 试一试 :: 给紧张的下落关卡换一段急促鼓点，感受气氛变化。
CALL: 动手挑战 :: 给游戏录一段你自己喊的「必杀技台词」，在得分达到二十分时播放。用麦克风录音功能就能实现，试试看！

P: 设计师笔记 · 本章做的东西里，最让你有成就感的是哪一步？把它记在笔记本上——下次卡住的时候翻回来看，你会发现原来自己已经走了这么远。这种记录进步的习惯，比任何技巧都更能支撑你走完创作全程。
S: 小结与预告
P: 回顾本章：音效是游戏的爽感开关，重要事件响亮独特、频繁事件轻柔短促；造型加等待是最朴素的动画公式；倾斜、缩放等微细节叠加出手感；背景音乐管气氛但别抢戏。
P: 视听包装完成，你的作品已经相当能打了！但设计师的路还差最后一站：把作品交给别人玩，听听他们的意见。下一章学习游戏测试——好游戏都是改出来的。
