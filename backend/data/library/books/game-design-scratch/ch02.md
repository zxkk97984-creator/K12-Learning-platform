T: 设计你的第一个关卡

S: 先拿铅笔再拿鼠标
P: 职业游戏设计师有个共同习惯：关卡设计开工前先在纸上画草图。为什么不用电脑直接做？因为纸上改起来快——擦掉重画只要五秒，电脑里删积木调参数要五分钟。设计阶段要的是大胆尝试，铅笔是最好的工具。|mark:关卡设计
P: 我们的第一个作品定为「太空接星星」：小飞船在屏幕下方左右移动，星星从天而降，接住一颗得一分。规则简单但三样宝贝齐全：目标是高分，规则是只能左右移动、星星落地不扣分但漏掉太多就输，奖励是每颗星星的闪光和音效。这个框架你将在后面几章逐步实现。
FIG: 一张手绘关卡草图：方框代表屏幕，下方画着三角形飞船，上方散布几颗星，旁边标注「飞船：左右键控制」「星星：从顶部落下」「接住加一分」 :: 关卡草图三要素：角色在哪、怎么动、发生什么
P: 动笔画你的草图吧！可以照着太空接星星画，也完全可以改成自己的创意：海底接贝壳、草地接苹果、夜空接月亮都行。草图上必须标清三件事：有哪些角色、各自怎么动、玩家做什么算成功。画完给同学看一眼——如果对方一眼能看懂玩法，你的设计就合格了。
CALL: 想一想 :: 如果想让游戏更难一点，可以在草图的哪些地方动手脚？比如星星落得更快？飞船变小？还是同时落下坏东西？

S: 把草图搬进 Scratch
P: 打开 Scratch 新建项目。第一步换背景：点右下角背景区选择太空主题，或用绘制功能自己涂一片深蓝色星空。第二步准备角色：主角飞船可以用库里的小火箭，星星用五角星造型；把飞船拖到舞台底部中央，星星放到顶部待命。两分钟，纸上的草图就有了立体的雏形。
P: 第三步写运动脚本：给飞船拼上「当按下右键，将 x 坐标增加 10」和「当按下左键，x 坐标减少 10」。运行测试——飞船听话地左右移动了！注意这里用的是「当按下某键」事件积木而不是循环检测，因为移动是即时反应，按键触发一次动一次刚刚好。

KC: 移动边界 :: 给移动角色加上「碰到边缘就反弹」或坐标判断，能防止它跑出画面；好游戏的角色永远待在该待的地方。:: 试一试 :: 让飞船移动时加上「将 x 限定在 -220 到 220 之间」的保护。
P: 动手完成本章任务清单：换好星空背景、摆好飞船和星星的位置、写好左右移动脚本、测试按键手感（太灵敏就把 10 改成 8）。全部完成后再对照草图检查一遍——恭喜，你的关卡骨架正式立起来了！
KC: 草图三要素 :: 关卡草图必须标清三件事：有哪些角色、各自怎么动、玩家做什么算成功；能被别人一眼看懂的草图才是合格的设计。:: 试一试 :: 把你的草图给家人看，问他们能不能猜出玩法。
CALL: 动手挑战 :: 给星星加一段简单的下落脚本试试看（提示：重复执行里让 y 坐标慢慢减小）。下一章我们让它真正从天上掉下来。

P: 设计师笔记 · 本章做的东西里，最让你有成就感的是哪一步？把它记在笔记本上——下次卡住的时候翻回来看，你会发现原来自己已经走了这么远。这种记录进步的习惯，比任何技巧都更能支撑你走完创作全程。
S: 小结与预告
P: 回顾本章：设计师先用纸笔后用鼠标；草图必须标清角色、动作、成功条件三要素；Scratch 里用事件积木控制飞船移动，用坐标限制防止出界。关卡的壳已经搭好。
P: 但现在的星星还不会掉，游戏没有挑战就没有心跳。下一章我们让星星满天飞，并给游戏装上生命条和输赢判定——真正的游戏从这里开始——这一点值得每位学习者牢记在心。。
