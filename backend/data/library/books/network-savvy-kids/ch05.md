T: 做网络好公民：友善、举报与求助

S: 屏幕放大了什么
P: 网络有个奇特的放大效应：善意传得快，恶意也传得快。一句玩笑话在教室里只伤一个人，发到群里可能引来几十条跟风嘲讽。隔着屏幕看不见对方的眼泪，人就容易说出当面绝不敢说的话——心理学管这叫去抑制效应，它是网络欺凌的温床。

KC: 举报与求助 :: 遭遇或目睹网络欺凌时，正确步骤是：不参与回骂，截图保存证据，拉黑屏蔽骚扰者，向平台举报，并把事情告诉信任的大人。:: 生活里的例子 :: 把恶意评论截图存好再删除拉黑，证据在手，平台和家长才帮得上忙。
P: 如果你被卷入欺凌，记住三个「不」：不回骂——对喷只会把事态拖进泥潭，还可能让自己从受害者变成参与者；不忍瞒——沉默会让欺凌者得寸进尺，告诉信任的大人不是打小报告，而是给自己请外援；不自责——错的永远是施暴者，不是「不够大度」的你。
FIG: 流程图：起点「收到恶意攻击」分出两条路：上方红色路径「对骂→升级→两败俱伤」被打上叉；下方绿色路径「截图取证→拉黑→举报→告诉大人→平台处理」通向「恢复平静」 :: 正确的应对是一套动作组合，而不是情绪的第一反应
P: 更常见的处境是旁观者。看到别人被围攻时，跟风起哄一条、点个赞，都是给欺凌添柴；反过来，一句「别说了」的评论、一次私下问候「你还好吗」，往往就能让当事人撑住。研究校园生态的人都懂一个规律：旁观者的态度，决定欺凌能烧多大。
CALL: 想一想 :: 为什么在群里第一个跟风嘲笑的人特别关键？如果当时有人先泼一盆冷水，结局会不会完全不同？回想一个你见过的实例。

S: 举报是你的正当武器
P: 很多人嫌举报麻烦，或者觉得「没用吧」。实际上平台的举报系统是真实起作用的：辱骂内容会被删除，情节严重的账号会被禁言封号。举报时附上清晰的截图和说明，处理效率更高。这不是打小报告，而是每个用户维护社区秩序的权利与责任。
P: 举报之外，还有一层更硬的保护网：现实中的求助链。家长、班主任、学校心理老师，必要时还有网警报警渠道。提前想清楚「我的求助链上有谁、怎么联系」，真遇到事就不会大脑空白。建议你现在就写下三个名字和一个电话，存在手机里。
P: 做个练习：假设有同学在群里被造谣，请写出完整的处置流程——谁该截图、谁去私聊安慰、谁来报告老师、群里其他人该做什么。你会发现，好的结果从来不靠某位英雄，而是靠一群知道自己该干什么的人。
KC: 求助支持网 :: 提前想清楚「遇到麻烦可以找谁」：家长、班主任、心理老师、平台举报渠道、报警电话。名单越具体，真遇事时反应越快。:: 试一试 :: 现在就写下三个名字和一串电话，存进手机。
P: 五章走完，做个总复习。账号密码守身份，隐私分级护宝贝，急链要识骗局，三秒法则管足迹，举报求助有后盾。这五件装备不是让人害怕网络，而是让你玩得更尽兴——知道边界在哪里的人，才敢放心奔跑。
CALL: 动手总结 :: 把五章的五件核心装备各写成一张卡片（一句话加一个例子），拼成你的《网络生存卡》，贴在书桌前。

S: 全书回顾
P: 这本小册子教的从来不是恐惧，而是从容。网络世界值得探索：那里有知识、友谊和无限创意；而安全意识就像骑车的头盔，戴上它不是限制你，而是让你敢骑得更远更快。
P: 最后送你一句话作为全书压轴：在网上做你线下愿意签名负责的那个人——发言前想想敢不敢署真名，转发前想想愿不愿当面说。守住这条底线，你就是一名合格的网络公民，愿你的数字生活既精彩又安心！
