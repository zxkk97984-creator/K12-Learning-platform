S: 拼图游戏：信息如何拼出你
P: 先做个思想实验：单看「我喜欢打篮球」，你猜不出我是谁；再加上「每周六上午出现在区体育馆」；再加一张穿校服的照片；再知道我姓王、读初二。四块碎片一拼，一个活生生的人几乎站在你面前。个人信息就是这样一块块拼图，单独看无害，凑齐了危险。|mark:个人信息
@kp=personal-information
KC: 个人信息边界 :: 姓名、住址、学校班级、证件号、行程安排、正脸定位照片等能定位真实身份的内容都属于个人信息，公开分享前必须三思。:: 生活里的例子 :: 校服照加校名牌，等于告诉陌生人你就读的学校和姓名。
FIG: 四张卡片从左到右排列：「喜欢篮球」「周六在体育馆」「穿二中校服的自拍」「初二·小王」，每张卡单独无害，一条红线把它们连向右侧一张写有「完整身份」的档案卡 :: 信息像拼图：每一块都平平无奇，拼起来就是你的全部底细
P: 有同学会反驳：我晒个照片而已，哪有那么多坏人？绝大多数时候确实没事——但隐私保护防的是小概率大后果事件。信息一旦发出去，就脱离了你的控制：截图、转发、存储都不需要你同意。保护隐私就像过马路看车，不是不信司机，而是把安全握在自己手里。
CALL: 想一想 :: 「定位打卡+美食照片」看起来人畜无害，连续一个月每天打卡同一类地点，会暴露什么？这类内容该发在公开平台还是仅好友可见？

S: 给自己的信息分级
P: 与其纠结每条信息能不能发，不如先给信息分三级。红色级：永远不公开——身份证号、家庭住址、银行卡与密码、行踪计划（比如「下周全家去三亚五天」）；黄色级：谨慎分享——学校名称、正脸照、实时定位，只对认识的人可见；绿色级：可以分享——兴趣观点、作品成果、不涉及身份的日常。
P: 分级的好处是判断变快了：遇到任何内容先归级，红色直接不发，黄色想想再发，绿色放心发。有了这把尺子，纠结「能不能发」的时间从几分钟缩短到几秒钟。
P: 分级之后还要会用工具。主流社交应用都有隐私设置：谁能看我的动态、谁能加我好友、是否允许被搜索到。花十分钟逐项检查一遍，把默认的「所有人可见」改成「好友可见」，等于给宝贝柜上了锁。设置不是一次性的，每次应用更新后最好再扫一眼。
P: 还有一个容易被忽略的出口：群聊和二维码。拉群截图可能带出别人的发言，转发前想想当事人愿不愿意；扫码领奖品常以交出手机号为代价，问自己一句——这个礼物值多少个骚扰电话？养成「先看要什么，再决定给不给」的反射，比任何技巧都管用。
P: 隐私保护还有一个常被忽略的角度：帮家人把关。爷爷奶奶最容易相信「客服来电」，随手就把验证码念出去；他们转发的养生文章里可能藏着收集信息的链接。把本章的红黄绿分级讲给他们听，你就是家里的隐私小卫士。
P: 轮到你了。请做两件事：第一，打开你最常用的社交应用，按红黄绿三级自查最近三个月的发帖，发现越级的就删除或改权限；第二，检查应用的隐私设置清单，至少调整两项默认值。做完你会发现，原来自己曾把这么多宝贝敞开放着。
KC: 隐私设置 :: 隐私设置是应用提供的开关：谁能看我的动态、谁能加我好友、是否允许被搜索。花十分钟逐项检查，等于给宝贝柜上锁。:: 试一试 :: 打开常用应用的设置页，把「所有人可见」改成「好友可见」。
CALL: 动手实践 :: 和同学互相扮演「信息侦探"，只根据对方公开发布的内容，试着拼出对方的作息与喜好，最后交流：哪些内容让你后背发凉？

S: 小结与预告
P: 回顾本章：个人信息是可拼接的拼图，红黄绿三级帮你快速判断能不能发；隐私设置与扫码警惕是两件随身武器。守住信息，就是守住现实生活的入口。
P: 不过，就算你守得滴水不漏，骗子还会主动上门——伪装成老师发来消息、伪装成官方发来链接。下一章我们研究他们的剧本，让你一眼认出戏服下的套路。
