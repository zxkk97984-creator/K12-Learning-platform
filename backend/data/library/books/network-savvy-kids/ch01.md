T: 你的数字身份：账号与密码

S: 账号就是网上的你
P: 打开游戏、聊天软件、学习平台，几乎每个应用都先问你要账号。账号为什么这么重要？因为它就是你在网络世界里的身份证明：别人看到的头像、昵称、等级和发言，全都挂在账号上。账号丢了或被盗，等于网上这个「你」被别人冒名顶替。|mark:账号
P: 守护身份的第一道大门是密码。很多人觉得随便设一个就好，反正「谁会来偷我的号呢」——这个想法要更新了：坏人偷号大多不是冲着某一个人来的，而是用程序在全网批量尝试。你的账号可能被拿去发垃圾广告、骗你的同学，甚至登录支付工具，后果远比「丢个小号」严重。
@kp=strong-password
KC: 强密码 :: 强密码足够长（十二位以上）、混合大小写字母数字和符号、不含生日姓名等个人信息、并且不同网站不重复使用。:: 生活里的例子 :: 「wang2008」一秒就被破解，「蓝鲸-跳过-7个月亮!」既好记又难猜。
FIG: 对比图：左边一把细纸片做的锁，标签写「123456」，旁边画着一只手轻轻撕开；右边一块厚重的合金门锁，标签写「长口诀加符号」，旁边的小偷图标撞门弹回 :: 密码的结实程度，直接决定账号这扇门好不好推
P: 怎么造一把又强又记得住的密码？试试口诀法：挑一句只有你懂的话，取每个词的首字母再混入数字符号。比如「我每周三打两次篮球」可以变成「w-mz-sd2c-lq！」。长度上去了，含义只有你自己知道，安全性远胜一串无意义的乱码。
CALL: 想一想 :: 为什么「不同网站不用同一个密码」这条规矩如此重要？提示：想象最常用的那个网站的数据库泄露了，接下来会发生什么连锁反应。

S: 给大门再加一道锁
@kp=two-step-verification
KC: 两步验证 :: 两步验证指输入正确密码后，还需要第二道动态验证码（如手机短信或验证器生成的六位数）才能登录。:: 试一试 :: 在常用应用的账号安全设置里找到「两步验证」或「登录保护」开关并打开。
P: 就算密码再结实，也有万一泄露的可能，所以现代账号普遍配上了第二道锁：两步验证。开启后，新设备登录除了输密码，还要当场输入一条几分钟内有效的动态验证码。坏人就算拿到了你的密码，拿不到你手里的手机，照样进不来。
P: 这道锁的原理值得看一眼：验证码通常由时间参与计算生成，每三十秒换一次，服务器和你手机上的小程序像对暗号一样核对数字。它把「你知道什么」（密码）升级成「你知道什么加上你带着什么」（手机），安全级别完全不同了。
P: 动手时间到。请完成三件事：第一，检查你最常用的一两个账号，把弱密码换成口诀法造的新密码；第二，给最重要的那个账号打开两步验证；第三，把这些密码记在纸质本子或家长认可的密码管理工具里，唯独不要存在聊天记录里。十五分钟的投资，换来长期安心。
P: 密码还有一位低调的搭档——密码管理工具。它像一个上了多重锁的笔记本：你只记一把主密码，其余账号的密码由它生成和保管，登录时自动填充。几十个互不相同的高强度密码从此不用背。暂时不想用工具的话，写在纸上锁进抽屉也是可接受的老派方案——黑客隔着屏幕偷不走纸。
P: 最后记住一条应急常识：如果收到「你的账号正在异地登录」的提醒，先别慌，立刻改密码并查看登录记录；如果发现自己登不进去，马上通过官方渠道找回并通知亲友别上当。反应越快，损失越小。
CALL: 动手挑战 :: 用口诀法为三个常用账号各设计一个互不相同的新密码，写在纸上让家人评价：哪个最难猜？哪个最好记？能不能兼得？

S: 小结与预告
P: 回顾本章：账号是网络世界的你，密码是它的第一道门；强密码要够长、够独特、不重复使用，两步验证再加一道动态锁。守好身份，才谈得上后面的所有玩法。
P: 门锁好了，接下来要看管屋里的宝贝——你的姓名、学校、住址、照片这些个人信息。它们平时不起眼，攒在一起却能暴露你的全部生活。下一章我们聊聊隐私的边界在哪里。
