T: 数字足迹：发出去就收不回

S: 网上的你有一份永久档案
P: 沙滩上走路会留下脚印，涨潮就抹平了；网上发帖也会留下脚印，却多年不消。你发过的动态、点过的赞、留过的言、被上传的照片，统统沉淀成一份档案，这就是数字足迹。它有个可怕的特点：你以为删了的东西，可能早已被截图、缓存或转发。|mark:数字足迹

KC: 数字足迹 :: 数字足迹是你在网络上一切行为痕迹的总和，包括主动发布的内容和被动收集的数据，它比大多数人想象得更长久、更完整。:: 生活里的例子 :: 多年前随手发的中二发言，会在几年后被同学翻出来当谈资。
FIG: 一条时间轴从左延伸到右：起点贴着「今天的帖子」，中途多个节点标着「被截图」「被转发」「进搜索结果」，时间轴尽头站着「未来的你」回头张望 :: 你今天留下的每个足迹，未来的你都会路过并重新看见
P: 足迹分两种。主动足迹是你亲手发的：动态、评论、昵称头像；被动足迹是别人替你留的：同学上传的合照、平台记录的浏览偏好。很多人精心打理主动足迹，却忘了被动足迹同样构成「别人眼中的你」——管不了别人拍你之前，至少可以决定哪些场合允许拍照。
CALL: 想一想 :: 搜索一下你自己的常用网名（在家长陪同下），能找到什么？这次小小的「自我人肉」让你对被动足迹有什么新的认识？

S: 发布前的三秒法则
P: 好习惯其实只需要三秒。发任何内容前问三个问题：第一，五年后的我愿意让现在的老师、同学、家人都看到它吗？第二，它会不会伤害或让别人难堪？第三，如果它被截图传到我控制不了的场合，我能接受吗？三问全过再发送，任何一问犹豫就先存草稿。
P: 为什么强调「五年后」？因为中学生时代正是口味变化最剧烈的几年：今天觉得酷的梗图、口无遮拦的吐槽，两年后自己都会脸红。网络档案不会陪你一起成长——它定格的是当时的你。给未来的自己留一点余地，是最划算的自我投资。
P: 平台的行为记录是第三种足迹，最隐蔽也最庞大：你停留在哪条视频久了、深夜搜过什么、反复比价哪款球鞋——即使一条动态不发，画像也在悄悄成形，推送随之越来越「懂你」。应对之道是主动打破：关注几个不同观点的账号，定期清理浏览记录，遇到推送内容先问一句——它是我想看的，还是它想让我看的？
P: 还有一条容易被忽略的边界：别人的足迹也不归你管。未经同意把同学的糗照发到群里、把私人聊天记录公开示众，哪怕内容真实，也可能构成侵权和欺凌。己所不欲勿施于人，在网络世界同样成立，而且有校规和法律背书。
P: 动手整理一次你的足迹吧：翻出半年前发的动态，用三秒法则逐条重审，删掉或隐藏不再想展示的内容；顺手检查有没有不该出现在网上的定位、证件、车票照片。这不是掩耳盗铃——减少可见面，就是在缩小未来风险敞口。
KC: 三秒法则 :: 发布前用三个问题快速安检：五年后的我愿意被看到吗？会伤到别人吗？被截图外传我能接受吗？三问全过再发送。:: 试一试 :: 把这三个问题写在便签上贴在电脑边，发帖前扫一眼。
CALL: 动手实践 :: 给三个月后的自己写一条「发布守则"，包含三条你在本章学到的检查项，设成手机备忘录置顶。

S: 小结与预告
P: 回顾本章：数字足迹是一份不由你独控的永久档案；三秒法则——五年后的我、是否伤人、能否承受外流——是发布前的快速安检；同时记得尊重他人的足迹。管好输出之后，最后一课要处理输入端的难题：当网络上有恶意冲你来时怎么办？
