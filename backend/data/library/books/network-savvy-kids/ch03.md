T: 骗局识别术：钓鱼与诈骗

S: 钓鱼为什么总能钓到鱼
P: 收到过这样的消息吗？「您的账号存在异常，请立即点击链接验证，否则将被冻结」。点进去是一个和官方网站几乎一模一样的页面，输入账号密码后——它们落进了骗子口袋。这类伪装成可信来源骗取信息的把戏叫钓鱼，名字取得形象：愿者上钩。|mark:钓鱼
@kp=phishing-scam
KC: 钓鱼诈骗 :: 钓鱼诈骗通过伪装成官网、客服或熟人的消息，诱导你点击假链接或交出密码验证码。识别的核心永远是核对来源，而不是看页面像不像。:: 生活里的例子 :: 假充值页面做得和真的一模一样，唯一区别是网址多了两个字母。
FIG: 一条消息气泡被放大镜检视：表面写着「官方通知·紧急冻结」，镜片下方显出三处破绽标注——「制造紧迫感」「陌生短链接」「索要验证码」 :: 骗子的话术再逼真也藏不住三个马脚：急、链、要
P: 钓鱼消息有三个高频特征，可以编成口诀「急、链、要」。急：制造恐慌或兴奋，让你来不及思考，「两小时内不处理将清空账户」「恭喜中奖速来领取」；链：给你一条来路不明的链接或二维码；要：最终目的都是套走你的密码、验证码或转账。三者占齐，基本可以判定为骗局。
P: 为什么这些话术屡屡得手？因为它们攻击的不是电脑漏洞，而是人的情绪漏洞。人在紧张或狂喜时判断力会大幅下降，骗子要的就是你「先点了再说」。所以防骗的第一反应不是学技术，而是给自己立一条铁律：凡是涉及账号钱财的消息，先冷静三十秒再行动。
CALL: 想一想 :: 「急」这一招为什么对大人和小孩都有效？回忆一次你自己被「来不及了」推着走的经历，当时如果多等半分钟会怎样？

S: 三步核实法
P: 立完铁律，再学一套标准动作。第一步查发送方：邮箱地址逐字母看清楚，骗子最爱用形近字伪装，比如把官方域名里的字母 o 换成数字 0；聊天软件里冒充班主任的账号，头像昵称都能盗用，但你可以换个已知渠道打电话确认。
P: 第二步不点链接、自己走正门：收到「账号异常」就手动打开官方应用去查看，而不是顺着消息里的链接走。真通知永远在官方应用里等你，假链接才需要你去送。第三步守住终极防线：验证码和密码是最后的门钥匙，任何正规机构都不会索要，开口要的一定是假的。

KC: 举报与求助 :: 收到诈骗信息时：不点击、不回复、截图保存证据，然后使用平台的举报功能，并告诉家长或老师；涉及钱款的损失应及时报警。:: 试一试 :: 在常用聊天软件里找到「投诉举报」入口，看它支持哪些类型。
P: 别觉得「我年纪小，骗子看不上我」。学生恰是热门目标：游戏皮肤低价出售、明星粉丝群抽奖、帮好友解冻账户……剧本年年翻新，内核都是同一套。把本章口诀带在身上，你已经比大多数成年人更难被骗到了。
CALL: 动手演练 :: 和同学互相出题：一人编写一条仿真钓鱼消息（可以是虚构的游戏场景），另一人用「急、链、要」口诀找出全部破绽，角色互换再来一轮。

S: 小结与预告
P: 回顾本章：钓鱼攻击的是情绪而非系统；口诀「急、链、要」帮你快速定性；三步核实法——查来源、走正门、守死验证码——帮你安全处置；遇事举报加求助，让骗子无处下钩。
P: 学会了防住别人上门，还有一件事同样重要：管好自己主动发出去的东西。你在网上留下的每条动态都会沉淀成一份档案，它比你想的更长寿，也比你想的更容易被翻出来看。下一章聊聊数字足迹。
