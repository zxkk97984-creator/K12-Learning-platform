# 一台造图机器

传统绘画的成果是一幅画，代码艺术的成果往往是一台「造图的机器」：写好的程序每次运行都能生成画面，改一个参数就衍生出无数变体。这类创作被称为生成艺术。艺术家设计规则，计算机执行规则，最终作品诞生于两者的合作——它不是一张图，而是一个图形系统。

# 随机性是第一位合作者

在程序里引入随机数，作品立刻拥有独一无二的生命。「import random」之后，random.randint(1, 10) 每次给出不同的整数。把它用在花瓣数量、线条颜色或起笔位置上，同一个程序每次运行都是新作品。许多生成艺术家公开的程序里，最核心的一行往往就是那个随机函数——确定性带来结构，随机性带来惊喜。

# 对称与重复的美学基础

人类视觉偏爱对称和节奏，而这恰恰是循环最擅长制造的：旋转叠加小弧线得到花朵，平移复制多边形得到烟花带，嵌套两层循环得到曼陀罗式的层层对称。生成艺术的基本功因此可以概括为一句话——用循环制造对称与重复，用参数制造变化，用随机制造意外。

# 参数即风格

同一套画花程序，弧度四十五度加八次循环是八角花；改成六十度加六次变成六瓣；弧度超过九十度则出现交叠的曼陀罗效果。参数就是风格旋钮：调参的过程就是艺术探索的过程。成熟的创作者会为满意的作品记录「配方」——每个参数的取值清单，就像香水师保存配方表。

# 分享文化的力量

生成艺术社区有个温暖的传统：公开分享源代码。艺术家们把自己的「配方」贴在网上供人学习和改编，改编者通常会注明灵感来源。这种开放让新手能站在高手的肩膀上起步——读懂一段优秀代码，比自己瞎摸索三个月进步更快。你也可以加入这个循环：把作品和代码一起分享出去，附上一句「欢迎改编」。创造因分享而生长，这是代码艺术世界最迷人的规则。

# 从模仿到原创的路径

入门建议从复现开始：找一幅喜欢的简单几何图案（雪花、波纹、网格），拆解它的构成规则，再用循环翻译成代码。复现几幅之后你会自然开始「如果把这个参数改成……会怎样」的尝试——那一刻你就从临摹者变成了创作者。保持每次只改一个小变量的纪律，你将建立起参数与效果之间精确的直觉地图。


# 你的第一幅作品建议

入门创作推荐「参数烟花」：写一个画多边形的循环函数，然后在外层循环里不断改变边数、颜色和位置，让十几个不同形状的图形铺满画面。这个练习只需用到已学的循环、换色和平移三个本领，成品却常常惊艳全场。完成后把代码和作品一起分享给同学，并附上一句「欢迎改编我的参数」——生成艺术的快乐，一半来自创造，一半来自分享。
