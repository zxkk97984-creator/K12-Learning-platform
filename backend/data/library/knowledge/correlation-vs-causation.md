# 一组奇怪的数据

统计某城市多年的月度数据，会发现一个惊人的规律：冰淇淋销量越高的月份，溺水事故也越多，两者几乎同涨同跌。难道冰淇淋导致溺水？当然不是。真正的幕后推手是气温：夏天热，买冰淇淋的人多；夏天热，去游泳的人也多，溺水事故随之上升。冰淇淋和溺水只是「同班同学」，它们一起变化，是因为都坐在「高温」这把椅子上。

# 两个词的差别

两个量一起变化，叫相关：一个涨另一个也涨（正相关），或一个涨另一个跌（负相关）。其中一个真的导致了另一个，才叫因果。相关很容易用数据发现——把两组数字摆在一起看走势就行；因果却难证明得多，需要弄清作用机制，或者做对照实验。

从相关跳到因果，是数据世界里最常见的逻辑陷阱。除了「第三个因素」这种情形，还有一种更简单的可能：纯属巧合。数据足够多时，总能找到两组碰巧同步变化的数字，比如人均奶酪消费量与某类意外发生率曾长期同步——它们之间什么关系都没有。

# 怎么判断能不能下因果结论

给你三个追问。追问一：有没有可能是巧合？换一批时间、地区的数据再看，规律还在吗？追问二：有没有隐藏的共同原因？找到那个同时推动两者的第三因素了吗？追问三：有没有机制解释？说得清「A 是怎么一步步导致 B」吗？

三个追问都过了，因果结论才有资格成立。科学上最硬核的手段是对照实验：随机把对象分成两组，只改变一个因素，其他条件全部相同。新药试验、化肥对比田用的都是这个思路——因为随机分组能把隐藏因素的作用抵消掉。

# 新闻里怎么用这个武器

掌握了相关与因果的差别，你看新闻的角度会不一样。「研究发现常喝咖啡的人更长寿」——先别急着买咖啡机。爱喝咖啡的人是不是也更有钱、更注重体检？这些隐藏因素都可能才是真正的原因。几天后另一家媒体报道「控制收入和健康状况后，咖啡的效果消失了」，你就明白发生了什么。

这不是说研究没用，而是说每一项研究都是拼图的一块。科学家自己最清楚这一点，所以他们说话总是留有余地：「可能」「有助于」「与……相关」。反而是把「相关」直接说成「因果」的标题党，最值得警惕。

# 动手练一练

判断下面的说法错在哪里：「统计发现，带手表的学生平均成绩更高，所以戴表能提分。」先想想有没有隐藏因素——愿意给孩子买手表的家庭，是不是普遍更重视教育？再想想怎么验证：找两所情况相近的学校，一所推广戴表、一所不推广，一学期后对比成绩。学会这样追问，你就不会被任何「研究表明」轻易带走。
