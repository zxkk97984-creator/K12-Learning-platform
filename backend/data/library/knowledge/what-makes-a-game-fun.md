# 三样宝贝的秘密

你玩过的每个好游戏，都藏着三样宝贝。第一样叫目标：玩家努力想要达成的事——得到高分、到达终点、救出朋友。没有目标的屏幕活动只是玩具，有了目标才叫游戏。第二样叫规则：什么可以做、什么不可以做。跳棋只能走对角线，足球不许用手，规则的限制恰恰是乐趣的来源。第三样叫奖励：做对了就有反馈——加分、音效、庆祝动画，像一颗颗小糖果告诉你「做得对，继续」。

# 一个反例的启示

想象一个游戏：小球在屏幕上乱飘，碰到什么都不发生，也没有分数。玩三十秒你就想关掉了。用三样宝贝一检查就明白了：没目标（不知道要干嘛）、没规则（碰什么都无所谓）、没奖励（做对也没反应）。三样全缺，所以无聊。

反过来，画面很简陋的游戏只要三样宝贝齐全也能让人着迷。经典的小蜜蜂打飞机只有几个色块，但目标明确、规则清楚、奖励密集——好玩和华丽没有必然关系。

# 奖励的小学问

好游戏会把大目标切成一串小奖励：接住一个苹果加一分，凑满十分升一级，每级换新背景。这样玩家一路都有盼头，就像爬楼梯时每一层都有窗外的风景。如果通关要玩十小时才能看到一点变化，大多数人早就放弃了。

# 动手当一回分析师

选三个你最喜欢的游戏，画一张表格写下：它的目标是什么？最重要的规则是什么？你最开心的一个奖励瞬间？写完你会发现：赛车游戏和消除游戏的宝贝内容完全不同，但「目标加规则加奖励」的骨架一模一样。看懂这个骨架，你就迈出了游戏设计师的第一步。

# 用三样宝贝评价一款游戏

现在轮到你当分析师了。选一款你最近玩的游戏，用三样宝贝给它打分：目标清楚吗（一到十星）？规则有趣吗（一到十星）？奖励让人上头吗（一到十星）？写下一句总评。做完这个练习你会发现：你不再只是玩游戏的人——你已经能用设计师的眼睛看穿它的骨架了。
