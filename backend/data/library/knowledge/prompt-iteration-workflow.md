# 首轮回答只是草稿

高手与新手的差距不在首轮提示词，而在之后的操作。新手看到不满意的结果就下结论「AI 也就这样」；高手把首轮回答当草稿，开始精准追问：「第二点展开讲，其余删掉」「语气改成同学聊天的感觉」「举一个校园里的例子」。两三轮之后结果脱胎换骨。这套功夫叫迭代改进，它是提示词技巧中最具杠杆效应的一环。

# 有效反馈的关键词：具体

「写得好一点」是无效指令——好没有标准。「把开头改成疑问句制造悬念」才是可执行的修改。一次只提一类修改也是纪律：同时要求改结构、语气和例子，模型容易顾此失彼；逐项推进反而收敛更快。这与人类协作的道理完全一致：反馈越聚焦，修改越到位。

# 三段式标准打法

处理复杂任务有一套经过验证的组合：先用角色设定确定专业度与风格（如「你是一位擅长给高中生讲历史的老师」）；再用四要素搭好任务骨架；最后视需要附上少样本示例锁定格式。首轮不理想时，逐轮追加具体反馈。把这套流程用熟，大多数任务都能在五轮对话内达到可用状态。

# 两个必须避开的陷阱

陷阱一：诱导性提问。「为什么吃冰激凌会导致溺水？」在问题里预设了假因果，模型倾向顺着框架编造理由而非先纠正前提。防御方法是把「为什么」换成「是否」，并主动邀请批判：「请检查我的问题本身是否成立。」陷阱二：过度信任流畅的长答案。篇幅长、结构美、语气笃定都不代表内容可靠，涉及事实清单与精确数字的内容必须逐条核实——这是任何提示词技巧都无法豁免的步骤。

# 建立自己的提示词库

迭代出来的优质提示词是劳动成果，值得沉淀成个人资产。建一个文档，按用途分类保存你打磨成熟的提示词模板：写作类、复习类、翻译类、纠错类。每条模板旁注明适用场景和一句使用心得。下次遇到同类任务直接调出微调，效率数倍于从零开始。更进一步，把模板分享给同学组成提示词互助组——每个人贡献一条，全组就拥有一个不断生长的武器库。

# 动手实战

选一个真实的小任务（如整理一份复习要点），完整走一遍流程：四要素加角色写出首版；针对不满意处逐轮追问至少三次；最后人工核实全部事实性内容。保存完整的对话记录并标注每一轮改动解决了什么问题——这份记录就是你的提示词作品集第一页。


# 一条实用的追问句式库

积累几条万能追问句式能让迭代如虎添翼：「请把第三点展开成一段完整的论述」「换一种更口语化的说法重写」「给每条建议配一个具体例子」「如果只能保留两条，你会留哪两条？为什么？」这些句式适用于几乎所有任务，把它们抄在便利贴上贴在屏幕边框，用不了一周就会内化成你的本能反应。
