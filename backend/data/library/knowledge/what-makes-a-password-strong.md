# 密码是怎么被猜中的

很多人以为偷密码的坏人会坐在电脑前一条条试。真实情况是：他们用程序每秒尝试上亿次组合。纯数字六位密码只有一百万种可能，一眨眼就被穷举完；而「生日加姓名」这类看似私密的组合，攻击者会用你的公开信息生成猜测清单，同样不堪一击。密码被攻破的第一大原因不是黑客厉害，而是密码本身太弱。

# 结实密码的四条标准

第一，够长。长度是对抗穷举的最有效武器：每多一位，破解难度翻几十倍，十二位以上是当前公认的起步线。第二，够杂。大小写字母、数字、符号混着用，别让程序看出规律。第三，不含个人信息。生日、姓名拼音、手机号都在攻击者的候选清单里。第四，不重复使用。这一点最容易被忽视，也最致命。

# 一号多用的连锁灾难

设想你在某个小论坛注册时用了和邮箱相同的密码。论坛安全防护薄弱，数据库泄露了，你的「用户名+密码」成对流入黑市；坏人拿着这串组合去登录你的邮箱——成功了。接下来，用邮箱可以重置你几乎所有账号的密码。这就是「撞库」攻击：一个弱环节拖垮全部防线。不同网站用不同密码，等于给每个房间配独立钥匙。

# 口诀法：又强又好记

担心复杂密码记不住？试试口诀法。挑一句只有你懂的话，取每个词的首字母，再掺入数字和符号。「我每周三打两次篮球」可以变成「w-mz-sd2c-lq！」。它对你是有意义的一句话，对程序则是毫无规律的乱码。也可以选四个互不相干的词拼成长口令，比如「蓝色-闪电-跳过-七个月亮」，越长越好记。

# 密码管理工具了解一下

不同网站不同密码，几十个账号怎么记得住？职业玩家的答案是密码管理工具：它像一个上了多重锁的笔记本，你只需记住一把主密码，其余密码由它生成并保管，登录时自动填充。选择口碑好的知名产品，开启主密码的两步验证，安全性远胜把密码写在便签或存在聊天记录里。如果暂时不想用工具，纸质本子锁进抽屉也是可接受的方案——听起来老派，但黑客隔着屏幕偷不走纸。

# 两步验证：最后的保险

再结实的锁也该配第二道门闩。两步验证在输入正确密码后，还要求输入手机短信或验证器生成的动态验证码。验证码几分钟更换一次，坏人即使拿到密码，没有你的手机照样进不来。请今天就为最重要的邮箱或游戏账号打开这个开关——它通常藏在「账号安全」设置里。

# 动手做一次安检

现在花五分钟给自己的账号做个体检：列出你最常用的三个密码，对照四条标准打分；把不及格的换成口诀法新密码；确认最重要的账号开启了两步验证。记住，密码管理是一场持久战，定期检查比一次到位更重要。
