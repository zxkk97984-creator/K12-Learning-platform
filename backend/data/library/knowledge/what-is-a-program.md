# 从一个生活问题开始

你想吃番茄炒蛋，但今天家里没有人做饭。于是你写了一张纸条给会做菜的表哥：先洗两个番茄，切成小块；打三个鸡蛋搅匀；热锅倒油，先炒鸡蛋，盛出来；再炒番茄，最后把鸡蛋倒回去一起翻匀。表哥照着纸条一步步做，一份番茄炒蛋就成功了。

这张纸条，本质上就是一个「程序」：把一件事拆成一步一步的明确指令，交给执行者照着完成。程序员每天做的事情，和写这张纸条没有本质区别，只不过读纸条的不是人，而是计算机。

# 程序的三条铁律

第一，指令必须精确。「炒到差不多」对人有效，对计算机无效——它不知道什么叫差不多。所以真正的程序里，每一步都要写成计算机能准确理解的形式。

第二，顺序很重要。先盛饭还是先煮饭，结果完全不同。程序默认从上往下逐条执行，顺序错了，结果就错。

第三，执行者不猜心思。计算机不会因为觉得「你可能想放盐」就自动放盐。你没写的，它就不做。这既是缺点也是优点：只要步骤正确，它每次都能一丝不差地重复同样的过程，比任何人都可靠。

# 让程序会拐弯、会重复

只会从头做到尾的程序还不够聪明。真实任务里充满了「看情况」和「再来一次」。

「看情况」靠条件判断：如果下雨就带伞，否则戴帽子。程序里的 if 语句就是岔路口，它会检查一个条件是否成立，然后选择走哪条路。

「再来一次」靠循环：抄一百个单词，人要抄一百遍，程序只需要说「把这句话重复一百次」。循环让计算机把大量重复劳动一口气干完，这正是它最擅长的事。

条件判断加上循环，再加上从上到下的基本顺序，合起来叫作程序的三大结构。有趣的是，无论手机游戏还是火箭控制软件，再复杂的程序都是用这三样东西搭出来的，区别只是搭法更巧妙。

# 编程语言与解释器

计算机看不懂中文纸条，只认自己的机器语言——一串串由 0 和 1 组成的信号。让人类直接写 0 和 1 太痛苦了，于是人们发明了编程语言，用接近人类语言的写法描述指令，再由专门的翻译程序把它变成机器语言。

Python 就是目前世界上最流行的编程语言之一。它的特点是写法简单、接近英语，特别适合初学者入门，也被广泛用于人工智能、数据分析等领域。负责现场翻译 Python 的程序叫解释器：你每写完一段代码，解释器就从上往下逐行阅读、逐行执行。

# 动手试一试

在纸上写下「教同学叠一只纸青蛙」的步骤，越具体越好。然后请一位同学严格按照你的步骤操作，看看能否成功。如果失败了，检查是哪一步不够精确——这个小游戏让你提前体验了编程最重要的思维：把模糊的想法拆解成精确的步骤。学会这种拆解，你就已经推开了一半的编程之门。
