# 一张表格改变的世界

一九七八年，两位程序员发明了第一个电子表格软件，从此会计们告别了纸账本和计算器。今天，全世界上亿人每天在使用电子表格：公司用它记账发工资，科学家用它记录实验数据，球队用它统计球员表现，学校用它管理成绩和图书。可以说，电子表格是现代办公真正的地基。

# 它比纸质表格强在哪

纸质表格写上一个数字就定型了，改一个数要擦掉重算所有相关结果。电子表格的革命在于「活」：单元格之间可以建立公式关系，B6 等于 B2 到 B5 之和——只要任何一个分数改动，总和瞬间刷新。数据一变、结果全变，这是它和纸质记录的本质区别。

第二个优势是规模。纸质表格几十行就翻不动了，电子表格轻松容纳百万行数据，而且排序、筛选、求平均都只是一两次点击的事。第三个优势是图表：选中数据一键成图，柱状图折线图随选随换。

# 表格思维是一种通用能力

会用电子表格的人有一个共同点：他们习惯把信息整理成「一行一条完整记录、一列一种属性」的规整结构。这种结构化思维让查找、统计、对比都变得容易，也是后续学习数据库和编程的地基。反过来说，乱结构的表格（把多个信息挤进一个格子）是数据分析一切麻烦的源头。

# 无处不在的隐藏表格

很多你以为不是表格的东西，背后都是表格：手机通讯录是一张表（姓名列、电话列），音乐播放器的歌单是一张表（歌名、歌手、时长），甚至游戏里的装备背包也是一张表。学会用表格思考，就是学会了用计算机组织信息的基本方式。

# 表格软件怎么选

市面上主流的表格工具功能高度相似，选择哪个都不影响学习。学校机房常见的微软 Excel 功能最全面；国产的 WPS 界面友好且免费版足够教学使用；开源阵营的 LibreOffice Calc 完全免费且跨平台。在线表格如腾讯文档、飞书表格的优势是多人协作——全班同时编辑同一张表的体验相当神奇。本册书讲的所有概念在这些软件里全部通用，学会一个等于学会全部。

# 动手开始第一张表

打开任意一款表格软件（学校电脑常见的 Excel、WPS，或免费的 LibreOffice 都行），花十分钟建一张「个人书籍借阅记录」：三列表头分别是日期、书名、状态。填入五条真实记录，试着把其中一行复制到别处，再试试按书名排序。完成这四个动作，你就推开了数据世界的大门。


# 表格的历史小趣闻

电子表格软件的发明还有一段传奇：一九七九年，两位美国程序员为了帮哈佛商学院的朋友完成繁琐的财务计算，写出了史上第一款电子表格 VisiCalc。没想到这款工具意外火爆，很多人为了用它专门购买一台个人电脑——个人电脑产业的第一次爆发，某种程度上是被一张表格点燃的。今天你随手打开的表格软件里，藏着的正是改变计算机历史的那个创意。
