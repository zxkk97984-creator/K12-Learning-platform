# 从一团雪花点开始

文生图模型凭一句话就能画出一幅画，这个过程像魔术。拆开看，它是一场精心引导的去噪之旅：起点不是画布而是一团纯粹的随机噪声——就是老电视没信号时的雪花点。模型的任务是从这团混沌中一步步「雕刻」出清晰图像。

# 两幕训练戏

训练分两幕。第一幕学加噪：把百万张真实照片逐步掺入随机噪声，直到变成纯噪声——让模型明白噪声是怎么一步步侵蚀图像的。第二幕学去噪：给模型看「加了轻度噪声的图和原图」的成对样本，让它学会预测并移除那一点点噪声。两幕练熟后反过来演：从纯噪声出发逐步减噪，画面从混沌中浮现。

# 提示词是导演

去噪的每一步都会参考你的文字提示词来决定方向：往「海边」靠还是往「雪山」靠？水彩笔触还是油画质感？文字被编码成对去噪方向的持续牵引力。这就是为什么描述越具体、越结构化（主体、环境、风格、光线分开描述），结果越贴合想象；也解释了为什么同一提示词每次生成的图都不同——去噪起点是随机的。

# 进阶控制旋钮

负面提示词：明确列出不想出现的元素（多余的手指、模糊文字），质量立刻提升。引导强度：决定模型多严格地遵循文字——太高则僵硬死板，太低则自由过头。局部重绘：只重绘画面某区域而保留其余，适合微调细节而不推倒重来。这些旋钮组合使用，才能实现商业级的精确控制。

# 能力的边界

当前模型的经典弱项要有数：手部和细小文字容易出错（六根手指、乱码招牌）；复杂空间关系常摆错位；真实人物与新闻场景不可靠——它是在按统计规律「编」，不是在还原事实。因此涉及真实人物、事件的内容务必标注为 AI 生成，这也是相关法规的要求。

# 动手观察一次进化

选一个文生图工具，用同一句提示词生成四张图并排对比：注意构图相同而细节各异——这正是「同一方向、不同去噪路径」的可视化证据。再把提示词删减到只剩两个词再生成一次，对比可控性的差异。两次实验做完，扩散模型对你来说就不再是黑箱。


# 写在最后

技术会不断迭代，但思考的框架是长久的。把本章的方法用到你自己的场景里试一次——无论是完成一次真实的检索、做一份小报告，还是和家人讨论一个观点。用过的知识才是真正掌握的知识，而所有的工具，最终都是为了让生活变得更清楚一点。


# 与其他技术的对话

扩散模型并非唯一路线：早期有 GAN（两个网络对抗进化），现在还有自回归模型（像文字接龙一样逐块生成图像）。每条路线各有优劣——了解多种方案的存在，能帮你理解为什么不同工具的画风和可控性差异巨大。技术没有终极答案，只有不断被超越的当前最优解。
