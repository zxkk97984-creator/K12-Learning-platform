# 不用打字的编程

一提到编程，很多人想到满屏的英文代码。Scratch 完全不一样：它是麻省理工学院专门为小朋友设计的编程工具。在这里，写程序就像搭乐高——把一块块彩色的积木拖过来、拼在一起，舞台上的角色就照着做了。不用打字，也不会拼错单词，怎么试都不会弄坏东西。

# 舞台和角色

打开 Scratch，你会看到一大块空白区域，叫舞台，所有好玩的事都在这里发生。舞台上站着的小猫叫角色，它是演员。你还可以请恐龙、火箭、蛋糕上台，每个角色都能领到自己的积木脚本。

屏幕左边是积木仓库：蓝色的管运动，紫色的管外观，粉色的管声音，黄色的管事件。中间是拼积木的地方，右边是看表演的舞台。挑积木、拼积木、看表演——三步就是一次完整的编程。

# 积木也有性格

有一块黄色的积木特别重要：「当绿旗被点击」。它是程序的开关，点一下舞台右上角的绿旗，它后面的积木就全部开工。没有它，拼再多积木也只是躺着睡觉。

蓝色运动积木让角色移动和转弯；紫色外观积木让角色说话、换造型；粉色声音积木让它唱歌叫唤；黄色控制分类里藏着两件神器——「重复执行」能让动作一口气做十次，「如果…那么」能让程序看情况办事。所有复杂的游戏和动画，都是用这几类积木搭出来的。

# 认识几个积木朋友

黄色事件积木里有块「当绿旗被点击」，它是程序的开关。蓝色运动积木让角色移动转弯；紫色外观积木让它说话换造型；粉色声音积木给它配上喵喵叫和掌声。

还有两位特别重要的小伙伴。橙色的「重复执行」像传送带，把装进去的积木反复运行指定次数——想让小猫跑一百步，不用拼一百块积木，改个数字就行。另一个「如果…那么」像带条件的小门，条件成立门才打开。将来你做的每个游戏，都是靠它们俩转起来的。

# 从玩开始，越玩越深

Scratch 最友好的地方是可以随便试：数字改大改小、积木拆了重拼，出错了点撤销就行。很多厉害的作品就是这么「玩」出来的。在 Scratch 的社区里，全世界的小朋友分享了几千万个作品：跑酷游戏、电子贺卡、互动故事、音乐动画……你也可以把作品放上去，接受大家的点赞和建议。

更重要的是，你在不知不觉中学会了程序员的思考方式：把大目标拆成小步骤，一步一步说清楚，发现重复就交给循环，出了问题一块一块耐心排查。这套本领不只属于电脑，写作文列提纲、策划班级活动、安排一次全家旅行，用的都是它。
