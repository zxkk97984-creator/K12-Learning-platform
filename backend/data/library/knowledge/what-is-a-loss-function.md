# 「让模型变准」没法执行

「把模型训练得更准」这句话听起来是目标，实际无法操作——「准」不是机器能计算的概念。训练的第一步是把模糊的愿望翻译成一个具体的数字：预测与正确答案差多少。承担这项翻译工作的就是损失函数：喂给它预测值和标准答案，它吐出一个非负的数，数越大代表错得越离谱。训练的全部目标，就是让这个数尽可能小。

# 为什么偏爱平方

回归任务最常用的损失是平方误差：先把每个样本的偏差自乘，再取平均。为什么偏偏用平方？两个理由。其一，消除符号干扰：偏高五度和偏低五度若直接相加会互相抵消成「零误差」，平方后都变成正数，谁也赖不掉。其二，放大离谱错误：偏差 2 的惩罚是 4，偏差 10 的惩罚是 100——模型会把优化火力优先投向最刺眼的大错。

分类任务用的是另一族损失（如交叉熵），直觉同样朴素：模型对正确选项给出的信心越高损失越小，信心给错了地方则惩罚陡增。你不需要背公式，只需要带走核心观念：训练目标必须被翻译成可计算、可比较、可缩小的数。

# 损失如何驱动学习

有了损失，「学习」就有了严格定义：不断调整参数使训练数据上的损失变小。整个流程可以写成一段极简伪代码：「重复很多轮——用当前参数对每个样本做预测；计算预测与答案之间的损失；根据损失微调参数，方向是让损失变小」。第三行的具体做法（往哪调、调多大）由梯度下降负责，那是另一个精彩的故事。

# 读曲线听诊

损失的数值本身不重要，重要的是变化趋势。工程师把每轮的损失画成曲线来监控训练健康度：健康的学习像下坡路，稳步走低后趋于平缓；曲线剧烈震荡说明步子太大；居高不下说明模型太弱或数据有问题。学会看这条曲线，等于拿到了训练过程的听诊器。

# 一个重要的伏笔

必须清醒：我们优化的只是训练集上的损失，而真正想要的是模型在新数据上也表现好。这两个目标大部分时候同向，却并不总是一致——当模型开始把训练数据的噪声也「努力降低」时，训练损失还在降，真实性能却在崩。这种分歧出现的那一刻，就是过拟合登场的时刻。

# 动手体验

和同学玩「猜数字温度」游戏：他心里定一个数，你每次猜完只被告知一个数字——「偏差折合几度」。几轮能锁定目标？你会自发地总结出策略：先猜中间，再按反馈缩小范围。恭喜，你刚刚凭损失下降完成了一次手动优化。
