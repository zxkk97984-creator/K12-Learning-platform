# 电风扇为什么不算机器人

电风扇通电就转，扫地机器人却会自己规划路线、绕开障碍、没电了还能回充电桩。区别在哪？电风扇只会一根筋地执行，扫地机器人却能感觉环境、自己做决定。判断一台机器是不是机器人，不看它长不像人，而看三样东西齐不齐：能感知的器官、能思考的大脑、能行动的肌肉。

# 三大件各司其职

负责感知的叫传感器，相当于机器人的眼睛和耳朵，把光线、距离、温度变成机器能读的电信号。负责思考的是处理器和程序，工程师把「遇到什么情况怎么做」写成规则或算法装进去。负责行动的叫执行器，如驱动轮子的马达、控制手臂角度的舵机，它们是机器人的肌肉。

三者连成一个永不停歇的循环：传感器收集信息，程序根据信息做决定，执行器完成动作，然后立刻开始下一轮。这个「感知—决策—行动」循环每秒可能转几十次，快到我们看起来机器人像是在流畅地连续工作。

# 会想的本质是程序

机器人的「想法」其实是一段段程序。这听起来不浪漫，却恰恰是好消息：因为想法就是程序，我们能读懂、编写、改进它。给机器人写一条「如果前方障碍小于二十厘米就右转」，它就会严格执行，绝不遗忘。

但真实世界比规则复杂。同样是「前方有障碍」，可能是墙角、宠物或突然蹲下的同学。所以聪明的机器人程序会把行为分成几种模式——巡逻、避障、返回——根据情况在模式之间切换。此外，传感器会读错、轮子会打滑，误差无处不在；好的机器人靠不断测量和修正来抵消它们，这门功夫叫反馈。

# 从科幻到日常

很多人对机器人的想象还来自电影：人形、会对话、有感情。真实的机器人大多长得不像人，因为外形只服务于功能：扫地机是扁的，因为它要钻床底；机械臂像象鼻，因为它要灵活转弯。设计师不追求像人，只追求把活干好。

机器人正在快速走进日常生活。工厂里的机械臂组装手机，医院里的机器人运送药品和样本，餐厅里的机器人端菜送饭，农田里的机器人识别杂草精准喷药。它们没有电影里那样万能，却在一件件具体的小事上越来越可靠。理解它们的原理，你就不会高估也不会低估这个正在到来的伙伴。

# 动手观察

找一段扫地机器人或送餐机器人的工作视频，试着逐秒标注：哪一刻它在感知（停顿、转向探测），哪一刻在决策（原地思考般犹豫），哪一刻在行动（直线前进）。你会发现三大件的切换快得惊人——这就是那个隐藏的循环在工作。
