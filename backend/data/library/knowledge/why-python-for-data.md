# 数据世界的通用语

打开任何一份数据分析岗位的招聘要求，几乎都能看到同一个词：Python。这门语言凭什么统一了数据世界？答案可以浓缩成三点：语法接近自然语言、生态里有现成的工具箱、以及一个庞大的社区在你身后。

# 语法友好：把精力留给问题

Python 的写法非常接近英语和数学表达。「sum(scores) / len(scores)」读出来就是「分数之和除以个数」。对比需要提前声明变量类型、手写内存管理的语言，Python 让初学者把注意力放在「要分析什么」而不是「怎么伺候语言」上。对数据工作来说，这是实打实的效率——思路到代码的距离越短，尝试想法的速度越快。

# 一个真实项目的样子

把视野放远一点，看看职业选手的工作流：读入数据（pandas 三行）、检查缺失与异常（两行统计）、清洗修正（按策略几行）、分组聚合（一行 groupby）、可视化（一行图表调用）、输出报告。每个环节对应本章讲过的一个概念，只是工具换成了更强大的版本。概念是骨架，工具是肌肉——先在纯 Python 里练出骨架的人，上手任何框架都只需要几天；反过来则寸步难行。这也是本书坚持先用标准库的原因。

# 第一步怎么迈

如果你还没装 Python，最省事的起点是官方安装包或 Anaconda 发行版（后者自带数据科学生态）。写代码推荐从交互式环境起步：每一行输入立刻看到结果，试错成本低到令人愉快。第一个练习不必贪大——读入一份十几行的 CSV，打印总行数和一个总和，就算成功上线。记住这条学习曲线的规律：每次只加一个小概念，跑通了再加下一个。

# 两件核心容器正好够用

数据的收纳无非两种需求：按顺序排队、按名字取货。列表管前者，「scores[0]」取第一个元素；字典管后者，「prices["牛奶"]」按名字拿价格。更妙的是它们能组合使用：「一串带标签的记录」就是列表里套字典，这正是 CSV 表格文件读进程序后的天然形态。两件容器玩熟，大部分数据装填问题就解决了。

# 标准库与生态：不重复造轮子

读表格文件？标准库的 csv 模块几行搞定。算平均数中位数？statistics 模块现成。往专业方向走一步，生态的力量更加明显：pandas 提供了像操作电子表一样操作百万行数据的能力，matplotlib 一行命令出图，NumPy 把数学运算加速到飞起。这些工具全部开源免费——你站在整个社区的肩膀上工作。

# 迭代聚合：一个模式打天下

数据分析的核心计算模式少得惊人：循环遍历每条记录，逐条累加数值或计数。统计总支出是它，分类汇总是它，找最高频也是它。「counts[key] = counts.get(key, 0) + 1」这一行值得练到肌肉记忆——学会它，你就掌握了从流水账到结论报表的转换器。

# 动手验证

用十行以内的 Python 完成一个小任务：读取一份包含「日期、项目、类别、金额」的消费 CSV；打印总条数和总金额；按类别汇总并找出花销最大的类别。如果卡壳，检查三个点：是否用了 csv.DictReader、是否处理了空值、是否用了字典累加。跑通这个任务，你就亲身体会到了「为什么是 Python」。
