# 数字没错，图在骗人

某产品月销量从 1000 台涨到 1100 台，增长 10%，只能算平稳。可宣传海报上的柱状图里，第二根柱子猛地蹿出两倍高，观感完全变成「销量暴涨」。海报伪造数字了吗？没有。它只做了一件事：把纵轴从 950 开始画，而不是从 0 开始。图表说谎的套路，几乎都藏在这种「展示方式的选择」里。

# 套路一：砍掉的底座

柱状图的柱子高度代表数量多少，所以底座必须从零开始。一旦纵轴被截断，高度差异就被人为放大：真实差 10% 的两根柱子，可以画出十倍的气势。折线图略有不同——它关注走势而非总量，为了看清细节允许放大刻度，但负责任的制图者会明确标注。

对付这招只需一个动作：看到柱状图，先找纵轴最下沿是不是 0。不是的话，在脑中把图形压回真实比例再下结论。

# 套路二：膨胀的面积

比较两个数字，本该用高度表示，有人却把整个图形的长和宽一起放大：数值差一倍，图形面积差四倍——因为面积等于长乘宽。人眼对面积的感知既感性又迟钝，四倍大的图标天然显得「严重得多」。记住一句口诀：比大小，看高度，别看体积。

# 套路三：缺席的样本

最隐蔽的一招是让关键数据干脆不上场。「用户满意度 95%」的精美图表，唯独不提调查对象是从售后好评名单里挑的两百人。图本身没画错一个像素，但缺席的样本让整张图失去意义。正规的统计图会注明来源、时间和样本量，缺了这三样，可信度就该打折。

# 为什么有人故意画歪

想一个问题：谁从「看起来暴涨」的图表里获益？可能是想让销量曲线更漂亮的销售总监，可能是需要证明政绩的部门，也可能是无心的编辑随手选了默认设置。并非所有失真都出于恶意，但无论动机如何，后果都一样——读者被误导了。

反过来想，读懂这些套路也是自我保护。下次家里长辈被一张「投资收益对比图」打动准备掏钱时，你可以先问一句：纵轴从几开始？样本有多少人？这两个问题不花一分钱，却可能守住一个家庭的积蓄。识图能力，就是数字时代的防身术。

# 五项检查清单

给你一张随身清单，每项十秒：标题说的是这件事吗？柱状图从零开始了吗？刻度均匀吗？面积有没有被双重放大？来源和样本量交代了吗？五项全过，这张图才获得进入你大脑的资格。

值得深思的是，以上所有手法都没有伪造数字——每个数值都真实，谎言藏在选择里：选哪个起点、哪种比例、哪批样本。所以读图时真正该问的不是「数字对不对」，而是「为什么偏偏这样展示」。学会这一问，你就有了数据时代最值钱的本领之一。
