# 一张照片的旅程

你在班级活动上拍了一张合照，发到了群里。接下来它可能被谁看到、保存、转发？如果某个应用要求「扫描相册以提供智能分类」，你的照片还会被送去训练模型吗？数字时代，个人信息像水一样流动，而「知情同意」是控制水流的第一道阀门：任何组织想收集或使用你的数据，都应当先让你知道并征得同意。

# 什么是真正的「知情同意」

知情同意有三个关键词。看得懂：用清楚的语言告知用途、范围和保存方式，而不是三十页法律术语里藏着一句「或将用于改进服务」。可选择：不同意就不该被强制退出服务，更不该被默认勾选。可撤回：今天答应了，明天改变主意时能方便地退出并删除数据。

对照这三条，很多常见做法立刻现形：密密麻麻的条款加一个默认勾选，不是同意，是套路；「不同意则无法使用基本功能」，是绑架；注册一时爽、注销找不到入口的，是陷阱。

# 法律站在你这边

我国个人信息保护法确立了多项与你直接相关的权利：知情权与决定权——有权知道谁在处理你的信息、怎么处理；限制权与拒绝权——有权拒绝自动化决策和过度推送；删除权——处理目的已实现或你撤回同意后，有权要求删除。「最小必要」原则也写进了法律：收集的范围应当限于实现目的的最小限度，要你通讯录才能点外卖的应用本身就涉嫌越界。

# 实用的自保动作

第一，学会抓关键词：注册或授权时重点看三处——用途（拿去做什么）、共享（给谁看）、期限（存多久）。第二，定期清理：翻一翻手机里各应用的权限列表，关掉与功能无关的定位、通讯录、麦克风授权；卸载不用的应用。第三，敏感场景多留心：涉及人脸、身份证号、家庭住址的服务，宁可麻烦一点也要确认对方靠谱。

# 给家人做一次讲解

学到的知识最好的用法是分享出去。很多长辈对隐私条款毫无戒心：扫个码注册领鸡蛋、把身份证照片发给「客服」、所有密码统一用一个。挑一个周末，用今天学的三关键词（用途、共享、期限）帮他们检查一遍手机里的应用权限，讲清楚为什么陌生链接不要点、验证码为什么打死不能告诉别人。能把这些事讲明白，说明你自己真的懂了——教是最好的学。

# 动手做一次权限体检

打开手机的设置，找到应用权限管理页，逐个检查你最常用的五个应用：它们各自拿了哪些权限？哪些权限和它的功能毫无关系？把多余的关掉，再把一份应用的隐私政策找出来，试着用三句话向家人概括它拿你的数据做了什么。完成这次体检，你就完成了从「默认勾选的人」到「知情的数字公民」的转变。
