# 八成时间在洗数据

业内流传一句名言：数据科学家八成的工作时间花在清洗数据上，只剩两成用来做真正的分析。初听夸张，做过一次就懂了。真实世界的数据永远不完美：金额一栏有空缺、日期写成「周8」、同一客户的名字出现三种拼写、测量仪器偶发故障记下离谱数值。带着这些脏数据直接分析，结论再漂亮也是空中楼阁。

# 脏数据的常见类型

缺失值：某些字段空着，可能是漏填也可能是设备故障。重复值：同一条记录被录了两次甚至多次。格式错乱：日期有「2024/1/5」「2024-01-05」「1月5日」多种写法。异常值：身高一米七写成了一米七零——单位错误或手滑多打个零。不一致：同一类别被写成「饮品」「饮料」「drinks」。

# 处理策略没有标准答案

每种脏数据都有多种处理方式，选哪种取决于问题本身。缺失的金额：可以跳过该行（但必须计数并报告），可以用均值填补（适合缺失比例低且分布均匀的场景），也可以标记为特殊值单独研究。异常值：先核实是录入错误还是真实现象——把真实的高消费当噪声删掉，会得出错误的节俭结论。原则只有一条：宁可明说扔了什么，不可假装一切干净。

# 顺序纪律：先切分再处理

如果数据要用于训练模型，还有一条铁律：所有基于统计量的清洗（如用均值填补）必须在划分训练集与测试集之后、只对训练集计算统计量，再套用到测试集。顺序反了，测试集的信息就提前泄露给了训练过程，评估成绩会虚高。这是新手最常踩、也最难察觉的坑。

# 一份清洗清单

动手前先备好一张标准清单，逐项过一遍：缺失比例多高？哪些字段该是数字却在存文字？有没有明显超出现实范围的数值（年龄两百岁）？类别拼写是否统一？时间格式是否一致？把每个问题的答案记录在案，清洗就不再是随手抹灰，而是有据可查的整理。团队协作时，这份清单还是交接工作的最佳说明书——接手的人一眼就能看懂你做过什么、为什么这么做。

# 留下诚实的痕迹

清洗不是偷偷修饰数据，而是公开的整理过程。好的习惯是输出一份体检报告：「共读入 30 条记录，有效 28 条；跳过缺失金额 2 条，其中 1 条日期格式异常」。这份报告让读者自行判断结论的可信边界。数据分析的可信度，恰恰建立在对缺陷的坦诚之上。

# 动手练一次

准备一份自己一周的消费记录 CSV，故意埋三颗雷：一行金额留空、一行日期格式写错、一行金额多打一个零。写程序读入并逐条检查，捕获全部三颗雷，最后打印体检报告。完成之后你会由衷认同：清洗不是分析的准备工作，它就是分析的一部分。
