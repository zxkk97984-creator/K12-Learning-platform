# 从一只机械乌龟说起

上世纪六十年代，教育家西摩·佩珀特和同事们发明了一种接在电脑上的小型机器人乌龟，它能前进、转弯、落笔画线。孩子们通过给乌龟下指令，第一次感受到「我在指挥一台机器」。这个创意后来演变成 Logo 编程语言，再后来被 Python 吸收为内置的 turtle 模块——今天你敲下「import turtle」召唤的，是六十年的教育智慧。

# 两招走天下的绘图观

海龟画图的核心指令只有两个：forward（前进）与 left 或 right（转弯）。看似简单，组合起来却能画出一切由直线构成的图形：前进加左转九十度重复四次是正方形；每次转的外角等于三百六十度除以边数，改个数字就能画出任意正多边形。复杂图形的秘密不在更多指令，而在「简单指令乘以循环」。

# 三个必备辅助命令

抬笔 penup 与落笔 pendown 控制移动时是否留痕，是从「会画」到「会构图」的关键——没有它们，所有线条连成一团；有了它们，才能在画面各处分别起笔。circle 命令按半径画圆或圆弧，圆心在海龟左侧，第二参数可指定只画多少度的弧。speed 命令调节速度，调试时调慢观察过程、出作品时拉满提速。

# 循环是海龟的翅膀

两条指令很快会遇到瓶颈：画正方形要重复八行相似代码，画八边形要十六行。这时编程最强大的偷懒神器登场——for 循环。「前进一百、左转九十」重复四次的结构可以压缩成三行循环代码，改一个数字还能变成五边形六边形任意多边形。更深一层，每次转弯的角度等于三百六十度除以边数，这条几何规律配上循环，一个模板通吃所有正多边形——数学和编程在这里握手言和。

# 常见坑位提示

新手最容易踩的两个坑：其一，窗口一闪而过是因为程序跑完自动退出，在结尾加上保持窗口的语句即可解决；其二，转角方向搞反导致图形歪斜，记住 left 是逆时针、right 是顺时针，多试两次就有体感。遇到画错不用慌，clear 清空画面、reset 重置位置，代码在，作品随时重现。

# 动手画第一幅作品

按顺序完成四个小任务：画一条一百像素的横线；画一个字母 L；用循环画一个正方形；把正方形的边长改成变量并依次设为五十、八十、一百二十画三个嵌套图形。全部完成后截图保存。你会发现编程最迷人的反馈方式：每一行正确的代码，都立刻变成看得见的美。


# 为什么全世界都用它入门

海龟画图从诞生至今六十多年，被翻译成几十种编程语言版本，始终是最受欢迎的编程启蒙工具。原因有三：反馈即时——每敲一行代码立刻看到变化；错误友好——画错了也只是图难看，不会系统崩溃；成就感可见——从一条线到一幅作品的成长轨迹清晰可见。学编程最难跨过的坎是「看不见努力的效果」，而海龟画图把效果直接画给你看，这正是它历久弥新的秘密。
