# 一个价值千亿的排序难题

互联网有数百亿个网页，搜一个词可能命中几百万条结果，怎么把最值得看的排到前面？早期搜索引擎靠数关键词出现次数，结果被垃圾网站钻了空子：标题塞满热词、正文空洞无物照样登顶。一九九八年前后，两位斯坦福研究生提出一个天才想法：别看网页自己说什么，看别的网页怎么链接它。这个算法叫 PageRank，它是一家搜索巨头的立身之本。

# 链接即投票

核心思想分两层。第一层：网页间的每个链接视为一次投票——网站主愿意放上你的链接，等于公开背书，比自吹自擂可信。第二层更精妙：票不等值——被无数网站指向的权威页面投出的一票，远比无名小站的一票有分量。于是重要性在链接结构中流动与传播。

# 迭代收敛的解法

每个页面的分数取决于指向它的页面，而这些页面的分数又取决于指向它们的……鸡生蛋蛋生鸡？解法是迭代：给全网页面发相同的初始分（比如各为一），然后按规则整体更新——每个页面把分数均分给它指向的所有页面；每个页面的新分数等于收到的份额总和。重复几十轮后分数不再变化，收敛为稳定的排名。伪代码四行足矣：初始化、循环均分与汇总、判断稳定、输出。

# 一个小补丁堵一个大洞

理想模型有个漏洞：两个互相链接的页面会把分数来回倒手形成黑洞。工程解法是阻尼因子：假设网民有小概率不看链接而随机跳转到任意页面，为全网注入保底能量。一个小参数，堵住一个大漏洞。

# 启示远超搜索

PageRank 证明了一件事：系统中个体的价值可以由关系结构计算出来。社交网络的影响力评估、论文的学术评价、电商店铺的可信度评分，都是同一思想的变体。学会「从关系结构中提取价值信号」，你就掌握了分析复杂系统的万能钥匙。
