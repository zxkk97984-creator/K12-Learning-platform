# 一个自欺欺人的实验

某同学训练了一个「预测期末成绩」的模型，然后拿同一批数据评估，宣布准确率百分之百。问题在哪？模型可能只是背下了这批答案——用练习册当考卷，满分毫无意义。评估的铁律由此而来：考核数据必须是模型从没见过、没参与过学习的。

# 划分的基本法

标准做法是把数据随机分成两份：训练集供模型学习（常见占比七八成），测试集在训练完全结束后才用于打分。只有测试成绩才代表真实水平。随机打散是前提——若恰好把最难的样本划进测试集会低估成绩；按类别分层抽样能保证两边的人群构成比例一致。

更稳健的做法是交叉验证：把数据轮流切成几份，每份各当一次考卷，取平均成绩，抹平单次划分的运气成分。

# 数据泄露：看不见的作弊

隔离原则最大的敌人叫数据泄露——测试信息以隐蔽渠道渗入训练。典型场景：划分数据之前就做了「用全体数据的平均值填补缺失」这类预处理；特征里混进答案的影子，比如预测「是否违约」时留着一列违约后的处理结果。泄露不报错、不警告，只悄悄送你一份虚假的高分。

防泄露的核心纪律是流程顺序：先切分，再做一切。所有统计量、标准化参数、特征筛选只在训练集上计算，再把同样的规则套到测试集上。

# 时间数据的特殊纪律

预测股价、天气这类带时间顺序的任务必须按时间先后切分：用过去预测未来。若让模型提前见到下个月的数据再回头预测本月，成绩会漂亮得可疑——这不是本事，是穿越。凡是自带时间轴的数据，慎用随机划分。

# 别忘了基线

上线复杂模型前先跑一个笨办法当参照：「永远猜多数类」或一条简单规则。新模型若只比笨基线好一点点，它的复杂度就不值当。基线像一把标尺，专治「为炫技而建模」的行业通病。评估的最后一步永远是追问：和什么比？

# 分层抽样小课堂

随机划分还有一个精细版本叫分层抽样：按类别的比例分别抽取。比如数据里及格与不及格的比例是七比三，划分时就让训练集和测试集各自保持七比三。为什么重要？想象一个极端情况：一千条数据里只有二十条稀有样本，纯随机划分可能测试集只分到一两枚甚至零枚——评估成绩立刻失真。分层保证了「考卷的题型分布和教材一致」，这是处理不平衡数据的入门功夫。

# 动手审计

某同学声称他的模型准确率百分之九十九，允许你提问三次来查证。你会问什么？参考方向：数据是怎么切分的？预处理有没有在切分之前做？这个成绩和什么基线比较过？三个问题问下来，真功夫还是纸面神话一目了然。
