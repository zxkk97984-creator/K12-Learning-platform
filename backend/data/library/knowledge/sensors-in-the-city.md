# 城市的神经系统

如果把智慧城市比作巨人，传感器网络就是它遍布全身的神经系统。十字路口、公交站台、公园灯杆、河流桥下——成千上万台监测设备全天候工作，采集着交通、环境、能耗等运行数据。它们体积小到常被忽略，却是城市「感知世界」的全部感官。

# 三个观测站点

第一站：十字路口。地面埋着地磁线圈，车辆碾过引起磁场变化即可统计车流；杆件上的摄像头识别排队长度；部分路口还有噪声和气象探头——一个路口就是一座迷你观测站。第二站：公交地铁。刷卡机的每次嘀声都是出行数据，匿名汇总后能画出全市客流热力图，指导加开班次。第三站：公园街道。空气质量微站每小时报告 PM2.5；智能垃圾桶的满溢传感器提醒清运车「我饱了」；井盖下的水位传感器在暴雨天预警内涝。

# 数据的三跳旅程

传感器数据去哪了？三跳完成：通过移动网络或物联网专网传到汇聚点；平台清洗整理——去掉错误读数、统一格式；存入数据库供分析调用。全程自动、秒级完成，千万个传感器因此能够协同。

# 上报频率的工程智慧

不是所有数据都要实时上传。垃圾桶满了才发一次通知，比每分钟汇报一次「还没满」省电百倍；而红绿灯配时数据需要每几秒更新一次。工程师按决策需求设计上报频率——变化慢的少报，变化快的多报。好系统的聪明之处，在于知道什么值得说。

# 动手做一次城市侦察

上学路上留心观察，记录你发现的所有可疑设备：路口的地磁凸起、灯杆上的白色小盒子、站台顶部的摄像头。为每个设备写下你的猜测：它在感知什么？数据可能被用来做什么？一周后对照资料验证你的猜想。当你能叫出这些设备的名字时，这座城市在你眼中就不再只是风景，而是一张可以读懂的网络。
