# 一个等号改变一切

在电子表格里输入「85」，这个格子里住的是一个死数字；输入「=B2+B3」，格子里住的是一条活算式。表面上两者都显示结果，本质完全不同：前者是数值，后者是公式。公式的价值在数据变化时显现——把 B2 从 80 改成 90，所有引用它的公式瞬间自动刷新，而手算的数字需要你逐个找出重算，漏一个就埋下一处错误。

# 公式的写法规矩

所有公式以等号开头，这是告诉软件「后面是算式」的信号。四则运算直接用加号、减号、星号（乘）、斜杠（除）。更强大的是引用：用单元格地址（如 B2）代替具体数字参与运算，公式因此与数据位置绑定——数据更新，结果自动跟进。区间用冒号表示，「B2:B10」读作「B2 到 B10 这一整段」。

# 五个最常用的函数

函数是打包好的常用公式。SUM 求和、AVERAGE 求平均、MAX 找最大值、MIN 找最小值、COUNT 数个数。「=AVERAGE(B2:B31)」一行就得出三十天消费的平均值。这些函数覆盖了日常统计的绝大多数需求，而且全部支持自动填充——写好第一行往下拖，整列瞬间完成。

# 常见报错速查

公式出错时表格会显示简短代码，认识三个最常见的就够了：NAME 错误说明函数名拼写有误；VALUE 错误说明参与计算的内容不是数字（混进了文字）；REF 错误说明公式引用的格子已被删除。看懂报错比背公式更重要——它直接指出修复方向。

# 相对引用：公式的复制魔法

公式还有一个精妙设计叫相对引用：把写好公式的单元格往下拖动填充时，公式里的地址会自动平移——C2 的公式是 B2 加一倍，拖到 C3 就自动变成 B3 相关。这背后的思想是「位置关系比具体地址更重要」：公式记录的是邻居关系，搬到哪都能找到新的邻居。自动填充、批量计算都建立在这个设计之上，它是表格软件效率的真正来源。

# 动手验证一字之差

新建一张表，A 列填五个数字。第一个实验：在 C1 直接输入它们的总和（用心算或计算器得到），然后把 A 列某个数改掉，观察 C1 纹丝不动——错误依旧。第二个实验：删掉 C1 的内容，改输求和公式，再改 A 列数字，看 C1 实时更新。做完这组对照实验，「该用公式而不是硬算」就不再是道理，而是你亲手验证过的事实。


# 函数的智能提示

担心记不住这么多函数？表格软件早就替你想好了。在单元格里打出等号和字母 S，屏幕立刻弹出以 S 开头的函数候选列表；选中 SUM 后还会显示参数提示，告诉你括号里该填什么。就像输入法的联想功能——你只需要知道想算什么，拼写的事交给软件。大胆尝试各种函数吧，提示面板永远是你身边的说明书。
