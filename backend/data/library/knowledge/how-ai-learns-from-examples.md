# 一个不用写规则的办法

想让计算机分辨垃圾邮件，你会怎么做？最直觉的思路是写规则：包含「中奖」就拦截、有奇怪链接就拦截。可骗术千变万化，规则永远追不上。另一种思路完全不同：不告诉计算机任何规则，只给它看成千上万封已经标好「垃圾」或「正常」的邮件，让它自己找规律。这就是从例子中学习，也是机器学习的核心思想。

# 学习是怎么发生的

以识别手写数字为例。一开始，模型的参数是随机的，看到数字 7 可能猜成 1。每猜一次，程序就把猜测和正确答案对照，计算一个「错得有多离谱」的分数，然后朝着让分数变小的方向微调参数。这个「猜测—对照—调整」的循环会重复几万甚至几百万次。

每一次调整都微不足道，但累积起来，准确率会像爬坡一样稳步上升。训练结束后还要一场大考：用模型从没见过的数据测试。如果只认得课上见过的原题，说明它靠的是死记硬背；换新题也能答对，才算真正学会了规律。这种举一反三的能力叫泛化。

# 数据就是教材

从例子中学习有一个绕不开的前提：例子要够多、够好。就像学生需要教材，模型需要数据。数据里有什么偏向，模型就会学出什么偏向——只用城市照片训练的模型，可能连乡村土路都不认识；只用某类人群声音训练的语音助手，听其他口音就费劲。所以工程师常说：数据的质和量，决定了模型的上限。

# 训练之外还有一步

很多人以为数据喂进去就万事大吉，其实训练只是中间环节。训练前要清洗数据：删掉重复的、修正标错的，就像把教材里的错别字挑出来。训练中要盯着进度：如果模型在练习题上越来越好、新题上却原地踏步，说明它在死记硬背而不是找规律，工程师会及时调整。

训练后还要持续观察。模型上线后遇到的新情况，会暴露训练时没发现的盲区。所以 AI 产品不是「训练一次管终身」，而是像学生一样需要不断复习和补课。理解了这条完整链条，你就能看懂新闻里「某模型重新训练后偏见减少」之类的报道到底在说什么。

# 动手体会一下

玩一个课堂游戏：一位同学在心里想一条「好作文」的规律，但不许说出来；其他同学轮流报出作文片段，他只回答「好」或「不好」。几十轮之后，大家根据这些反馈猜他心里的规律。你会发现，例子越多、越典型，猜测就越接近真相——这正是机器学习的全部秘密：用足够多的带答案例子，逼出藏在背后的规律。
