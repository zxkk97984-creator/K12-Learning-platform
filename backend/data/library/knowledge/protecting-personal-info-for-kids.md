# 小雨和神秘弹窗的故事

小雨正在玩搭积木游戏，屏幕角落突然跳出一个亮闪闪的弹窗：「恭喜被选中！免费领取限定皮肤，只需填写姓名和爸爸妈妈的手机号！」小雨的手指刚碰到键盘，家里的智能音箱开口了：「小雨，先别急！网上送东西的陌生人，就像街上递糖果的陌生人。」

妈妈陪她一起检查那个弹窗，发现了三个可疑之处：真正的游戏不会在弹窗里要家长手机号；大字广告下面藏着一行小字「注册即同意接收推广信息」；官方渠道查不到这个活动。这是个钓鱼的假弹窗！小雨在日记里写道：今天我差点把小秘密送出去，幸好问了大人们。

# 哪些是小秘密

五样信息属于小秘密：你的全名、就读的学校和班级、家庭住址、照片、爸爸妈妈的电话号码。单独看每一样都平平无奇，拼起来却危险——知道名字加学校加班级，坏人就能在校门口准确认出你；有了家长电话，就能冒充熟人打诈骗电话。小秘密像拼图，一块块凑齐，坏人就画出你的完整地图。

还有更隐蔽的打探方式：假装同龄人的网友聊天时问「你放学一般几点回家呀？」听起来像闲聊，其实也在收集拼图。记住原则：网上的朋友再聊得来，小秘密也一个都不能说。

# 三句拒绝魔法话

遇到有人打听小秘密，可以练习三句应对：第一句，「这是我的小秘密哦」；第二句，「我要先问问妈妈」；第三句最干脆——不回复，直接关掉对话去找大人。拒绝陌生人不需要礼貌周全，保护自己永远排第一位。

# 求助永远不晚

如果已经不小心泄露了信息怎么办？首先别慌张自责，然后立刻做三件事：告诉大人事情经过；根据大人的建议修改密码或加强账号保护；留意后续有没有异常来电或消息。大人有比你更多的处理经验和资源，越早介入越能把影响降到最小。记住这句话：泄露不可怕，隐瞒才可怕——安全小卫士也会遇到打不过的怪兽，呼叫后援团是聪明而不是丢脸。

# 动手做一张小秘密清单

和家人一起写下属于你的五样小秘密，画上一把锁，贴在书桌旁。然后玩一个角色扮演游戏：一人扮演网上的陌生叔叔或阿姨，变着花样打听信息；另一人练习用三句魔法话应对。演完交换角色再来一轮。练熟之后你会发现，拒绝其实一点都不难——因为你心里清清楚楚知道什么该守住。


# 网络世界的红绿灯

把判断标准做成一盏交通灯贴在心里。绿灯行：分享自己画的画、写的故事、喜欢的动画片——这些不涉及身份信息。黄灯等一等：发照片、提到学校和班级之前，先想想发给谁看、有没有风险，拿不准就问大人。红灯停：姓名住址电话密码、家庭行程安排、任何陌生人的打听请求——坚决不说，马上报告。三盏灯一亮，该不该说一目了然。
