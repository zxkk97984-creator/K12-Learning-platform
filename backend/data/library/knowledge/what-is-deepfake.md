# 凭空造出的「你」

深度伪造（Deepfake）是用 AI 合成以假乱真的图像、声音和视频的技术。只需要几张照片，程序就能生成一段某人「开口说话」的视频；几秒钟的语音样本，就能克隆出近乎真人的声音。技术上，它是让一个模型学习目标人物的大量特征，再驱动生成的产物；效果上，普通人肉眼几乎无法分辨。

# 危险用在哪里

技术本身无善恶，但深度伪造已被大量用于伤害：冒充熟人声音的电信诈骗（「我是你领导，明天来我办公室」）、伪造名人言论的谣言视频、未经同意合成他人形象的恶意内容。它的可怕在于同时偷走了两样东西——当事人的形象，以及公众「眼见为实」的信任习惯。

# 为什么练眼力靠不住

网上流传许多「识别假视频」的技巧：看眨眼、看光影、看牙齿边缘。这些方法在早期粗糙的伪造品上有效，但技术每月都在进化，今天的头部产品已经能通过多数人工检查。把安全寄托在肉眼鉴别上，是一场注定输掉的军备竞赛。正确的思路是换赛道：不纠结「这条视频像不像真的」，而核实「这条视频从哪里来」。

# 核实三步法

第一步，查来源：这段内容首发于哪里？是官方账号、正规媒体，还是来路不明的转发？第二步，交叉验证：其他可信渠道有相同报道吗？重大事件通常有多家独立来源，只有孤证的要打问号。第三步，走可靠通道确认：收到亲友的求助语音或视频，挂断后回拨对方常用号码核实——真伪立辨。

# 平台与法规在行动

单靠个人警惕不够，治理体系正在跟上：我国已明确规定 AI 生成内容需要显著标识；各平台部署检测工具筛查疑似伪造内容；恶意使用深度伪造实施诈骗、诽谤的行为可依据刑法追究责任。技术与反技术会长期赛跑，但「造假要标注、害人要负责」的制度框架已经立起来了。

# 声音克隆的警示

声音克隆是深度伪造家族里最容易上手的成员：几秒钟语音样本就能合成以假乱真的新话术。诈骗分子已经用它冒充亲人借钱、冒充老板要求转账。家庭防线的筑法很简单：约定一句只有家人才知道的暗号，接到涉及钱款的语音电话先对暗号；再养成「挂断回拨」的习惯——打到对方常用号码确认，而不是回复来电。两道手续花不了两分钟，却能挡住绝大多数声音骗局。

# 动手演练

设想场景：班级群里出现一段某同学的「不当发言」视频，画面声音都很像。按照核实三步法写出你的处置流程：先查什么？再问谁？在真相查明前应该怎么做（不转发、不评论、不站队）？练熟这套动作，你就拥有了假视频时代的自保护身符。
