# 一个问题：游戏怎么记住你的分数？

玩跳跃游戏时，你每跳过一个障碍，屏幕上的分数就加一分。奇怪的是，计算机并没有「黑板」，它凭什么一直记得你得了多少分？答案是：程序把分数存进了变量。变量是编程里最重要的基础概念之一，理解了它，你就理解了程序是如何「记住」世界的。

# 变量：贴着标签的储物格

把计算机的内存想象成一排巨大的储物格。每个格子可以存放一份数据，格子外面贴着一张名字标签，这张标签就是变量名。往格子里放数据的动作叫赋值，写成代码就是「score = 0」：创建一个叫 score 的格子，把数字 0 放进去。

之后你每跳过一个障碍，程序就执行一次「score = score + 1」。这行代码读作：从 score 格子里取出当前的值，加上一，再放回同一个格子。等号在这里不是数学里的「相等」，而是「把右边的值装进左边的变量」，方向永远是右边流向左边。

给变量起名字也有讲究。名字只能由字母、数字和下划线组成，不能以数字开头；更重要的是要见名知意——存分数就叫 score，存年龄就叫 age。半年后回看代码，好名字能让你一眼明白当初的想法。

# 数据类型：不同种类的数据

格子里能放的东西五花八门：整数、小数、一段文字、一个真假判断。计算机按种类给数据分类，这就是数据类型。初学阶段最常见的有四种：

整数（int）：不带小数点，比如 13、-7、1024。
小数/浮点数（float）：带小数点，比如 3.14、-0.5。
字符串（str）：用引号包住的一段文字，比如 "你好"。
布尔值（bool）：只有 True 和 False 两个值，表示真和假。

为什么要分类型？因为不同类型的数据能做的事情不同。整数和小数可以做加减乘除；字符串擅长拼接，"3" 加 "5" 得到的不是 8 而是字符串 "35"，因为加号在文字世界里表示首尾相连；布尔值则是条件判断的燃料，「分数大于等于 60」这种比较运算的结果正是一个布尔值。

# 类型转换：字符串变数字

还有一个新手必踩的坑值得单独提醒：程序从键盘接收输入时，拿到的永远先是字符串。你输入 13，程序看到的是字符"1"和字符"3"，而不是数字十三。想把它当数字用，必须做类型转换，比如「int("13")」会把字符串变成真正的整数 13。少了这一步，比较大小或做算术时就会报错。反过来也有办法：str() 能把数字变成字符串，方便和文字拼在一起显示。转换就像在不同语言的词汇之间查词典——类型对了，运算才能顺利。

# 动手试一试

打开任意 Python 运行环境，试着完成这个小实验：先写「name = "小明"、"age = 13」，然后用一行 print 把它们一起打印出来；接着把 age 更新为明年的年龄再打印一次；最后试试「print(type(age))」和「print(type(name))」，看看计算机分别报出什么类型。做完这四步，变量和数据类型就真正属于你了。
