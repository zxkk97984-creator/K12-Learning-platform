# 向蝙蝠学来的绝技

机器人要在黑暗中「看见」障碍，靠的不是眼睛，而是一位生物老师——蝙蝠。超声波传感器发出一声人耳听不到的声波，等它撞到物体反弹回来，记录总共花了多久。已知声音速度约每秒 340 米，用「声速乘以时间除以二」就能算出距离。这招不需要光线，黑灯瞎火照样精确测距，扫地机器人的避障大多靠它。

# 各有所长的感官家族

红外线传感器像玩手电筒：主动发射一束红外光，看反射回来的强弱判断前方有没有东西、地面颜色深浅。循线小车沿黑线行驶、扫地机区分地毯与地板，用的都是反射差异。它便宜、反应快，缺点是怕太阳光里的红外成分捣乱。

摄像头是信息量最大的感官，一张照片包含百万个像素点。但信息多不等于好懂：人一眼认出同学的脸，机器却要把像素交给复杂的识别程序去猜。碰撞开关则是最朴素的感官——撞上了才知道有东西，胜在绝对可靠，常作为最后防线。

# 感觉也会出错

机器的感觉并不总可靠。强阳光下红外读数会乱跳；光滑地面让超声波产生奇怪回声；轮子沾灰后，里程估计越走越偏。这些让读数偏离真实值的因素统称噪声与干扰。就像在嘈杂食堂里你听不清朋友说话，机器的「耳朵」也会被环境淹没。

# 感官组合拳

真实项目里很少只用一种传感器。送餐机器人是典型例子：超声波负责提前发现前方的人，碰撞开关兜底防止万一，底部的光电编码器记录轮子转了多少圈来估算走过的距离。三种感官各管一段，互相补充盲区。

这种组合背后是一笔精细的账：每种传感器都有价格、功耗和响应速度的取舍。工程师的任务是在预算内搭出最可靠的「感官套餐」，就像配菜——不求最贵，但求营养均衡。下次看到机器人身上的小圆点和小凸起，不妨猜猜它们各自是什么感官、负责哪一路信息。

# 三招应对不可靠的感觉

第一招叫多次确认：一次读数可能是干扰，连续五次一致就可信得多。第二招叫互相印证：超声波说前方有障碍、碰撞开关却没触发，那就放慢速度再探一次——侦探式的交叉验证。第三招在设计阶段就动手：了解每种传感器的脾气，避开它的软肋，比如知道红外怕阳光就把任务安排在室内。

好的机器人方案不是堆最贵的零件，而是承认感觉会出错，并为每一种可能的出错提前准备好后手。这份对「不完美」的清醒与坦诚，正是工程思维里最迷人、也最容易被忽略的部分——真正的可靠，从来都建立在承认不可靠之上。
