# 排在第一不等于最可靠

搜索引擎的排序衡量的是相关与流行，不是真实与权威。一条被大量转发的谣言完全可能压过严谨的报道排到榜首。所以看到搜索结果的第一反应不该是「排第一应该是真的」，而是启动一套快速评估流程。好消息是：这套流程只有三板斧，练熟之后每次只需十几秒。

# 第一板斧：查来源

点开网页先看三处。网站是谁办的：政府机构、知名学术单位、大型正规媒体的可信度通常较高；匿名论坛和个人博客并非不能看，但需要更强的证据支撑。作者是谁：正经内容敢署名担责，来路不明的内容往往连作者都查无此人。有没有出处：引用了数据和研究的内容，比纯情绪表达更值得信任。

# 第二板斧：看时间

网络内容不会自动过期，但事实会变化。「今年高考人数」搜出五年前的数据、「软件最新版本」点开是三年前的教程，都是常见事故。多数页面标注发布或更新日期，优先选新鲜的；没有日期的内容默认按可疑处理。

# 第三板斧：交叉验证

这是最有力的武器：同一个说法至少找两到三个互相独立的来源核对。如果只有一家孤零零地说，其他地方全无踪影，再惊人也要存疑；如果多家独立信源口径一致，可信度大幅上升。口诀是八个字：孤证不立，众口可参。

# 三个加分习惯

习惯一：来源与内容要匹配——医学问题优先看医疗机构，娱乐八卦看娱乐媒体，别让营销号替你回答专业问题。习惯二：警惕完美故事——细节丰富、情绪饱满、结论惊人的内容最值得多查一步，因为造假者正是靠这些元素抓眼球。习惯三：保留怀疑的权利——「先存疑再核实」不丢人，转发假消息才丢人。

# 动手做一次信息体检

找一条你在家庭群里看到的养生说法，按三板斧完整体检一遍：它出自谁？发布多久了？还有哪些独立来源说过同样的话？最后写一份五十字的评估结论贴在家庭群里。从今天起，做家里那个「等等，让我查查」的人。


# 写在最后

技术会不断迭代，但思考的框架是长久的。把本章的方法用到你自己的场景里试一次——无论是完成一次真实的检索、做一份小报告，还是和家人讨论一个观点。用过的知识才是真正掌握的知识，而所有的工具，最终都是为了让生活变得更清楚一点。


# 给年轻研究者的话

这套三板斧不只用于搜索，也适用于听讲座、读公众号、刷短视频。信息评估的本质是一种思维习惯：遇到任何说法先问三个问题，答案自然浮现。从今天起做那个「让我查查」的人吧——你的每一次较真，都在让信息环境变得更好一点。
