# 为什么同一句话问出天壤之别

把「帮我写个东西」和「请用初中生能懂的语言写一段八十字短文解释回声，举山谷喊话的例子」分别发给同一个大模型，前者得到一篇不痛不痒的通用段落，后者得到准确、生动、长度刚好的回答。模型没有变，变的是输入。大模型按概率续写：提示词越具体，候选答案的范围越窄，好答案被顶到最前面；越模糊则可选空间越大，回答自然越平庸。

# 四要素框架

高质量的提示词几乎都包含四个部分。任务：说清要做什么事，如「写一段解释文字」。背景：提供它不知道的信息，如「读者是初中生」「我已经学过声音的反射」。要求：设定约束与标准，如「不超过八十字」「必须有一个生活例子」「避免使用术语」。格式：规定输出的样子，如「一段成文」或「分点列出」。四要素不必每次全上，但越重要的任务越该配齐。

# 一个自查句式

判断提示词缺哪块有个快捷方法，读一遍后问自己三个问题：它知道具体情况吗（背景）？它知道做到什么程度算好吗（要求）？它知道交付物长什么样吗（格式）？哪一问答不上来就补哪一块。「帮我改作文」用三问一查就现出原形：什么作文、改到什么标准、改成什么样，全都不知道。

# 两个高价值技巧

技巧一：给正反例。「避免使用『非常』『特别』这类空泛副词」比「写得生动些」有效得多，模型更擅长遵守具体的禁令与示范。技巧二：指定受众。「讲给完全没接触过编程的高一学生听」一句话就能自动调节术语密度和解释深度。

# 角色与示例：两件高级武器

在四要素之外还有两件提升明显的高级武器。第一件是角色设定：在提示词开头加一句「你是一位擅长把复杂概念讲给中学生听的科普作者」，模型的语气、知识侧重会立刻切换到该身份的典型分布——具体、带处境的角色远胜于笼统的「你是专家」。第二件是少样本示例：与其用三百字描述想要的格式，不如直接给两个「输入对输出」的示范让模型照葫芦画瓢；示例之间要有差异以覆盖不同情况，且示例本身的质量必须经得起推敲，因为模型会忠实复制你的毛病。

# 动手练习

选一个你真实需要的任务，先写下自己的第一版提示词，再按四要素逐块检查补齐，前后各发送一次对比输出差异。把两版提示词和回答截图存档——这份对照记录就是你提示词手艺的第一份成长档案。记住：提示词不是玄学咒语，而是把任务讲清楚的沟通能力，而沟通能力永远值得刻意练习。
